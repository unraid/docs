# 使用 Unraid 安装程序

Unraid 安装程序在目标机器上启动，并为 Unraid 安装准备一个设备。它可以创建 USB 闪存启动设备或内部启动设备。

当你直接在目标机器上操作，或通过远程或虚拟控制台操作时，请使用此工具。对于大多数在笔记本电脑或台式机上创建 USB 驱动器的用户，请改用 [Unraid USB Creator](https://unraid.net/download)。

:::note[Unraid 7.3 and later]

Unraid 安装程序支持在 Unraid 7.3 中引入的内部启动工作流程。

:::

## 何时使用 Unraid 安装程序

选择与你的安装路径相匹配的工具：

| 工具                 | 适用时机                                 | 运行位置        |
| ------------------ | ------------------------------------ | ----------- |
| Unraid USB Creator | 你想要从笔记本电脑或台式机准备一个 USB 驱动器。           | 你的笔记本电脑或台式机 |
| Unraid Installer   | 你想在目标机器上准备启动设备、使用内部启动，或在远程或虚拟化环境中安装。 | 目标机器        |

USB Creator 在准备 USB 驱动器时不需要服务器上的显示器。Unraid Installer 需要访问目标机器的显示器或控制台，因为你必须在该机器上启动并使用安装程序。

## 开始之前

请准备以下项目：

1. 一台可访问显示器或控制台的目标机器。
2. 来自[最新稳定版 Unraid Installer 发布](https://github.com/unraid/bootable-unraid-installer/releases/latest)的安装程序资源。
3. 用于安装程序的 USB 驱动器或虚拟介质。
4. 一个可以擦除的目标磁盘。
5. 如果你使用在线安装程序并需要在安装期间下载 Unraid OS ZIP，则需要网络访问。

在选择目标磁盘之前，请先备份任何你需要的数据。

:::caution[The 安装程序会擦除已选磁盘]

**创建闪存启动** 和 **创建内部启动** 操作会擦除所选的目标磁盘。请在确认操作前读取磁盘名称和大小。

:::

## 选择安装程序资源

发布页面提供用于 ISO 和 USB 启动路径的资源：

| 资源                                                             | 适用时机                                      | 网络要求                        |
| -------------------------------------------------------------- | ----------------------------------------- | --------------------------- |
| `unraid-installer-\<version>-online.iso`      | 你将通过虚拟介质或远程控制台启动安装程序。                     | 当目标下载 OS ZIP 时，它必须能够访问发布服务。 |
| `unraid-installer-\<version>-online.img.zip`  | 你将把安装程序映像写入 USB 驱动器。写入 IMG 文件前，请先解压 ZIP。  | 当目标下载 OS ZIP 时，它必须能够访问发布服务。 |
| `unraid-installer-\<version>-bundled.img.zip` | 你希望安装程序介质已经包含 OS ZIP。写入 IMG 文件前，请先解压 ZIP。 | OS ZIP 已经位于安装程序介质上。         |

当目标具有网络访问时，请使用在线安装程序以获得更小的下载量。当目标在安装期间无法下载 OS ZIP 时，请使用捆绑安装程序。

发布页面还为可下载资源提供校验和文件。当你的下载或镜像工具支持校验和验证时，请使用它们。

## 启动安装程序

1. 从[最新稳定版发布](https://github.com/unraid/bootable-unraid-installer/releases/latest)下载一个安装程序资源。
2. 如果你下载的是 IMG ZIP，请先解压。
3. 从安装程序启动目标机器：
   - 通过虚拟介质或虚拟机控制台挂载 ISO。
   - 使用磁盘映像工具将 IMG 文件写入 USB 驱动器，例如 Rufus 或 Balena Etcher。
4. 在目标机器的启动菜单中选择安装程序设备。
5. 等待 **Unraid ISO Installer** 菜单出现。

:::caution[Writing IMG 文件会擦除 USB 驱动器]

请选择整个 USB 设备，而不是分区。在写入安装程序映像前，请断开其他可移动驱动器。

:::

## 使用安装程序菜单

安装程序菜单提供以下操作：

| 菜单操作                | 用途                                       |
| ------------------- | ---------------------------------------- |
| **下载 ZIP**          | 下载一个 Unraid OS ZIP，并保存它以供启动操作使用。         |
| **设置内部启动大小**        | 在创建内部启动设备之前，设置内部启动池的大小。                  |
| **创建内部启动**          | 准备一块或两块内部磁盘用于 Unraid 启动。两块磁盘会创建一组镜像启动设备。 |
| **创建闪存启动**          | 准备一块 USB 磁盘作为 Unraid 闪存启动设备。             |
| **显示网络状态**          | 显示接口、IP 地址和路由。                           |
| **重试网络（DHCP）**      | 启动网络接口并重试 DHCP。                          |
| **连接 Wi-Fi + DHCP** | 当支持 Wi-Fi 时，连接检测到的无线接口。                  |
| **命令行**             | 打开命令行以进行高级故障排查。                          |
| **调整持久化空间大小**       | 当映像支持时，调整安装程序持久化区域的大小。                   |
| **关机** 和 **重启**     | 关闭或重新启动目标机器。                             |

如果没有可用的图形菜单，安装程序会使用文本提示。

## 创建闪存启动设备

当目标机器将从 USB 闪存驱动器启动 Unraid 时，请使用此路径。

1. 选择 **下载 ZIP** 并选择一个 Unraid 版本。若捆绑安装程序已经包含所需的 ZIP，则跳过此步骤。
2. 选择 **创建闪存启动**。
3. 选择目标 USB 磁盘。请选择整个磁盘，而不是分区。
4. 阅读警告并确认该磁盘可以被擦除。
5. 等待安装程序创建一个标记为 `UNRAID` 的 FAT32 分区，复制 Unraid 文件，并使设备可启动。
6. 重新启动目标并选择新的闪存启动设备。

有关 USB 启动和许可方面的指导，请参阅[创建 Unraid USB 驱动器](./create-your-bootable-media.mdx)。

## 创建内部启动设备

当目标机器应从内部存储启动 Unraid 时，请使用此路径。此路径适用于直接服务器安装以及远程或虚拟化环境。

1. 选择 **下载 ZIP** 并选择一个 Unraid 版本。若捆绑安装程序已经包含所需的 ZIP，则跳过此步骤。
2. 如果默认大小不合适，请选择 **设置内部启动大小**。
3. 选择 **创建内部启动**。
4. 选择一块或两块磁盘。选择两块磁盘可创建一组镜像启动设备。
5. 选择启动池大小。使用 **专用** 可将磁盘用作专用启动设备，或者选择固定或自定义大小。
6. 输入启动池名称。名称必须以小写字母开头，并且可以包含小写字母、数字、`-` 和 `_`。
7. 验证所选磁盘并确认破坏性操作。
8. 等待安装程序创建分区布局、复制 Unraid 文件、验证文件并写入启动配置。
9. 重新启动目标并选择新的内部启动设备。

For internal boot questions, see the [Internal Boot FAQ (7.3+)](./internal-boot-faq.mdx).

安装程序会拒绝覆盖正在运行安装程序的设备或当前根磁盘。它仍会擦除你选择的任何其他磁盘。

## 故障排除

### 安装程序提示需要 ZIP

先选择 **下载 ZIP**。如果下载失败，请选择 **显示网络状态**，然后选择 **重试网络（DHCP）**。当目标无法下载 OS ZIP 时，请使用捆绑安装程序。

### 安装程序找不到发布版本

检查目标是否具有可用的 IP 地址和默认路由。重新尝试网络设置，然后再次选择 **下载 ZIP**。

### 未列出目标磁盘

确认磁盘已连接并可供目标机器使用。对于虚拟机，请将磁盘直通到虚拟机。请选择整个磁盘，例如 `/dev/sdb` 或 `/dev/nvme1n1`，而不是分区。

### 安装程序拒绝使用磁盘

安装程序会拒绝覆盖正在运行安装程序的设备或当前根磁盘。请从其他设备启动安装程序，并选择预定的目标磁盘。

### 目标在安装后无法启动

打开目标固件或虚拟机启动设置。将新的闪存或内部启动设备移到启动顺序的顶部，然后重新启动目标。

## 继续设置

在 Unraid 从新的启动设备启动后，继续执行[部署并配置 Unraid OS](./deploy-and-configure-unraid-os.mdx)。

有关源代码和当前发布资源，请参阅[Unraid Installer 仓库](https://github.com/unraid/bootable-unraid-installer)。
