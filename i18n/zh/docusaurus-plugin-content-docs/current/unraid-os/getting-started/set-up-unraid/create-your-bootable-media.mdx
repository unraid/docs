# 创建 Unraid USB 驱动器

Unraid OS 可以从 USB 闪存盘启动，或者在 Unraid 7.3 及更高版本中，从受支持的内部启动设备启动。本页说明如何为新服务器创建 USB 驱动器。您可以继续使用该 USB 驱动器进行闪存启动，或者在引导设置过程中选择内部启动之前，用它来启动服务器。更多信息请参阅 [内部启动常见问题 (7.3+)](./internal-boot-faq.mdx)。

对于 USB 启动，请使用具有唯一 %%GUID|guid%% 的高质量 USB 闪存盘，容量大小不限。该 %%GUID|guid%% 用于识别 USB 设备以进行许可。

:::tip[Choosing 可靠的启动介质]

对于 USB 启动，请选择具有唯一 %%GUID|guid%% 的高质量 USB 闪存盘。有关可靠介质和假冒驱动器的指导，请参阅手动安装部分中的[选择启动设备](#choosing-a-usb-flash-drive)。

如果您计划使用内部启动，仍需要此 USB 驱动器来启动新服务器。首次启动后，引导设置向导可让您选择闪存启动或内部启动。

:::

## 自动安装方法 {/* #automated-install-method */}

Unraid USB Creator 会准备驱动器，下载或使用所选的 Unraid OS 镜像，并将镜像写入 USB 驱动器。此方法适用于大多数新安装。

:::caution[Writing 擦除 USB 驱动器]

**WRITE** 操作会擦除所选的 USB 驱动器。开始之前请断开其他可移动驱动器。如果您要替换现有的 Unraid 启动设备，请先[备份它](../../system-administration/secure-your-server/secure-your-boot-drive.mdx)。

:::

### 下载 USB Creator

为您的计算机下载并安装 USB Creator：

- [Windows](https://releases.unraid.net/dl/stable/usb-creator.exe)
- [macOS](https://releases.unraid.net/dl/stable/usb-creator.dmg)
- [Linux](https://releases.unraid.net/dl/stable/usb-creator.appimage)

将 USB 驱动器插入您的计算机。关闭任何已打开该驱动器的应用程序。

### 选择语言

1. 打开 USB Creator。
2. 选择您的语言。
3. 选择 **下一步**。

  ![USB Creator 语言
  选择](/img/unraid-os/getting-started/create-unraid-usb/01-00-language-selection.png)
</div>

### 选择一个 Unraid OS 版本

1. 选择要安装的 Unraid OS 版本。
2. 选择 **下一步**。

对于生产服务器，请选择最新的稳定版。仅在测试该映像时才使用开发版映像。

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator 操作系统
  选择](/img/unraid-os/getting-started/create-unraid-usb/02-01-os-selection.png)
</div>

### 选择 USB 驱动器

1. 选择您要准备的 USB 驱动器。
2. 检查驱动器名称、大小和 %%GUID|guid%%。
3. 保持 **排除系统驱动器** 处于选中状态。
4. 选择 **下一步**。

%%GUID|guid%% 必须是唯一的，驱动器才能与 Unraid 许可证配合使用。不要选择包含您想保留的数据的驱动器。

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator 存储设备
  选择](/img/unraid-os/getting-started/create-unraid-usb/03-02-storage-selection.png)
</div>

### 配置新服务器（可选）

**自定义** 部分允许您在首次启动前设置以下选项：

- **服务器名称** 设置 Unraid 在您的网络上使用的名称。
- **Wi-Fi** 会存储使用无线连接的服务器的 Wi-Fi 网络设置。
- **网络** 设置为使用 DHCP 自动获取地址或静态 IP 地址。

如果您想在首次启动后配置服务器，可跳过这些部分。如果您配置了 Wi-Fi，请将 USB 驱动器视为包含 Wi-Fi 密码，直到服务器首次启动。

### 查看并写入映像

1. 在摘要中检查操作系统和存储设备。
2. 确保存储设备是您想要擦除的 USB 驱动器。
3. 选择 **写入**。

USB Creator 会将所选映像写入驱动器。

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator 写入
  摘要](/img/unraid-os/getting-started/create-unraid-usb/04-03-write-summary.png)
</div>

### 完成 USB 设置

写入完成后：

1. 检查完成屏幕上显示的选项。
2. 选择 **完成**。
3. 仅在 USB Creator 弹出后再移除 USB 驱动器。

UEFI 系统可以无需额外步骤即可从该驱动器启动。对于较旧的仅 BIOS 系统，请从 USB 驱动器根目录运行启动脚本：

- **Windows：** 右键单击 `make_bootable.bat`，然后选择 **以管理员身份运行**。
- **macOS：** 双击 `make_bootable_mac`，并在提示时输入您的管理员密码。
- **Linux：** 卸载 USB 驱动器。然后运行 `sudo bash ./make_bootable_linux`。

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator 写入
  完成](/img/unraid-os/getting-started/create-unraid-usb/05-04-write-complete.png)
</div>

### 从新的 USB 驱动器启动服务器

1. 将准备好的 USB 驱动器插入服务器。
2. 打开服务器的 BIOS 或 UEFI 设置。
3. 将 USB 驱动器设置为首选启动设备。
4. 保存 BIOS 设置并重启服务器。

在 Unraid 7.3 及更高版本中，当 Unraid 首次启动时，引导设置向导会让您选择启动方式：

- **闪存启动** 会将 Unraid 保留在 USB 驱动器上。
- **内部启动** 会将 Unraid 移动到一个受支持的内部启动设备，或两个镜像的内部启动设备上。

有关内部启动的详细信息，请参阅 [引导设置](./deploy-and-configure-unraid-os.mdx#onboarding) 部分和 [内部启动常见问题 (7.3+)](./internal-boot-faq.mdx)。

Unraid OS 启动后，请继续阅读 [Deploy and configure Unraid OS](./deploy-and-configure-unraid-os.mdx)。

## 故障排除

### USB 驱动器未出现

1. 断开 USB 驱动器。
2. 关闭 USB Creator。
3. 将 USB 驱动器直接连接到电脑。
4. 再次打开 USB Creator。

在此流程中，Unraid USB Creator 只会列出 USB 存储设备。打开 USB Creator 之前，请确保您的电脑已检测到该驱动器。

### 服务器无法从 USB 驱动器启动

1. 打开 BIOS 或 UEFI 设置。
2. 确保 USB 驱动器是首选启动设备。
3. 对于仅 BIOS 系统，请运行 [完成 USB 设置](#finish-the-usb-setup) 中所述的平台专用 `make_bootable` 脚本。
4. 保存设置并重新启动服务器。

如果你选择了内部启动并且在引导完成后服务器无法启动，请将所选的内部启动设备移到 BIOS/UEFI 启动顺序的最前面。如果服务器仍然无法启动，请使用 [手动安装方法](#manual-install-method) 再次准备 USB 驱动器。

### USB 驱动器无法注册许可证

USB 启动和 USB 许可都需要唯一的 %%GUID|guid%%。如果该驱动器没有唯一的 %%GUID|guid%%，请使用其他 USB 闪存驱动器。如果你使用基于 TPM 许可的内部启动，请参阅 [内部启动常见问题（7.3+）](./internal-boot-faq.mdx#internal-boot-flash-license)。

## 手动安装方法 {/* #manual-install-method */}

手动安装方法适用于 USB Creator 不可用或与你的硬件不兼容的情况。此方法可让你自行控制格式化和设置过程。

### 选择启动设备 {/* #choosing-a-usb-flash-drive */}

<FlashDriveGuidance />

### 准备你的 USB 设备 {/* #prepare-your-usb-device */}

1. 插入你要准备为启动设备的 USB 驱动器。
2. 格式化为 FAT32（**不是** ex-FAT 或 NTFS）。
3. 将卷标设置为 `UNRAID` （大小写敏感，全大写）。

:::important

在 Windows 上，内置格式化工具无法将大于 32 GB 的驱动器格式化为 FAT32。它们默认使用 exFAT。对于更大的驱动器，请使用支持 FAT32 的工具，例如 [Rufus](https://rufus.ie/en/)。

:::

### 下载并提取

1. 前往 [Unraid 下载存档](../../download_list.mdx) 并下载您选择版本的 ZIP 文件。
2. 将 ZIP 内容提取到 USB 设备。
3. 确认文件已复制。

### 使 USB 设备可启动

:::note

此部分仅在启用 Legacy 启动时需要。如果设置为 UEFI 启动，则不需要运行这些脚本。

:::

运行适合您操作系统的脚本：

运行适合您操作系统的脚本：

- 右键单击 `make_bootable` 并选择 **以管理员身份运行**。

**Mac：**

- 双击 `make_bootable_mac` 并输入您的管理员密码。

**Linux：**

- 将 `make_bootable_linux` 复制到您的硬盘。
- 卸载 USB 驱动器。
- 在终端中运行：

  ```bash
  sudo bash ./make_bootable_linux
  ```

:::note

在此过程中，USB 驱动器可能会暂时消失并重新出现几次。这是正常现象。

:::
