# 版本 7.3.2-rc.1 2026-07-02

Unraid OS 7.3.2-rc.1 刷新了 Linux 内核、Docker、Unraid API 以及一系列基础软件包，并对核心网络、Web、存储和加密组件进行了安全相关更新。此版本还包括 ZFS 和 QEMU 更新，以及存储、Docker 和系统改进。

## 升级

如需分步说明，请参阅[更新 Unraid](/unraid-os/updating-unraid/)。有关您的[许可证](/unraid-os/troubleshooting/licensing-faq/)的问题？

## 已知问题

- 此版本没有记录新的特定于发行版的已知问题。

- 此版本包含操作系统所使用的核心服务和库的软件包更新，包括 Docker、OpenSSH 支持库以及证书和网络组件。

## 相较于 [Unraid OS 7.3.1](/unraid-os/release-notes/7.3.1/) 的变更

### 安全

- 安全性：为安全修复更新了 bind、dnsmasq、libarchive、libidn、net-tools、nginx、openssl、shadow、sqlite 和 xorg-server。dnsmasq、nginx、openssl、net-tools 和 sqlite 包含所列 CVE 覆盖。
- 修复：CVE-2026-3838。

### 容器 / Docker

- 改进：将 Docker 更新至 29.5.3-1_LT。
- 修复：在 Docker 29 升级后，VLAN Docker 网络现在能更可靠地恢复网关和默认路由处理，因此受影响的容器可以重新获得出站连接和跨 VLAN 连接。

### 存储

- 改进：将 ZFS 更新至 2.4.3_6.18.37_Unraid-1_LT。
- 修复：在某些镜像启动池配置中，启动池设备移除现在可以再次正常工作，不再因 GUI 错误而失败。
- 修复：在某些端口交换场景中，更换缺失的启动池设备不再会遗留过时的缺失镜像成员。
- 修复：在特定的 `sda` 命名边缘情况下，格式化或擦除池不再会导致 GUI 崩溃。
- 修复：修正了仪表板上混合容量设备的 Btrfs RAID1 池大小和使用情况报告。

### WebGUI / 系统

- 改进：将 dynamix.unraid.net 更新至 4.35.1。
- 改进：刷新了基础系统软件包，包括 bash、ca-certificates、curl、git、pkgtools、rsync、util-linux 和其他核心组件。
- 修复：System Devices 中的控制器视图现在会显示正确的驱动器，而不是有时包含无关设备。
- 修复：mDNS 服务发现可以在临时网络丢失后更可靠地恢复。

### 网络 / 硬件

- 改进：更新了 cifs-utils、iproute2、libnvme 和 wireless-regdb。
- 新增：添加了 libcbor、libfido2 和 libmaxminddb。
- 改进：除非安装了必需的插件，否则 Intel iGPU SR-IOV 控件现在会隐藏，从而避免无法应用的设置。

### 虚拟化

- 改进：将 QEMU 更新至 10.2.3-1_SBo_LT。
- 改进：System Devices 中 Intel Arc GPU 的 PCI 链路速度报告更加准确，这有助于检查直通硬件。
- 改进：VM Network Source 选择器现在更宽，并且排序更自然，使较长或带编号的网络名称更易于查看。
- 修复：VM 上下文菜单在页面底部附近打开时现在会保持可见，而不是部分渲染到屏幕外。
- 修复：VM 使用情况报告现在更符合实际来宾 CPU 活动，而不是在无关文件传输期间显示夸大的使用率。
- 修复：在启用 PCI 选项时，已从 VM 设置中移除过时的重启警告。

### Unraid API

- 将 Unraid API 更新至 dynamix.unraid.net 4.35.1。

### Linux kernel

- Linux 内核：更新至 6.18.37-Unraid。
