# 版本 7.3.2 2026-07-08

Unraid OS 7.3.2 是一个安全和错误修复版本，包含 Linux 内核 6.18.38、Docker VLAN 网络修复、存储和启动池修复、虚拟化 UI 修复、Unraid API 4.35.1 以及若干基础软件包更新。

推荐所有用户使用。

## 升级

如需分步说明，请参阅[更新 Unraid](\<https://unraid-os/updating-unraid/>)。有关您的[许可证](\<https://../../unraid-os/troubleshooting/licensing-faq.mdx#license-types--features>)的问题？

## 已知问题

- 未发现新的本版本特定已知问题。有关从早期版本继承的问题，请参阅 [Unraid OS 7.3.1](\<../7.3.1/>) 发行说明。
- 对于使用 Intel Arc A 系列显卡的用户，在将显卡直通给虚拟机启动时，可能会出现黑屏；当前调查显示 Q35 模型可能是潜在原因。建议将虚拟机更改为 i440fx。您需要删除模板并重新创建，因为这无法在 UI 中更改。[https://forums.unraid.net/topic/198866-linux-vm-with-gpu-passthrough-broke-after-upgrading-to-73/page/2/#findComment-1630857](\<https://forums.unraid.net/topic/198866-linux-vm-with-gpu-passthrough-broke-after-upgrading-to-73/page/2/#findComment-1630857>) 调查将继续，直到找到修复方案。

## 相较于 Unraid OS 7.3.1 的变更

### 安全

- 安全：修复了 WebGUI `update.php` 的路径遍历命令执行漏洞，CVE-2026-3838。
- 安全：包含基础软件包安全修复，涉及多个组件的 CVE 覆盖；软件包级别的 CVE 详情列在基础发行版更新中。

### 容器 / Docker

- 修复：Docker VLAN 自动网络现在可以回退到已配置的 Docker 网关，从而使容器保持出站连接。
- 改进：通过将同步 I/O 保持在 Docker 选项卡渲染路径之外，提高了 Docker 选项卡加载性能，基于来自 [TSpader ](\<https://github.com/tspader>) 的社区贡献（感谢！）

### 存储

- 修复：在受影响的替换场景中，启动池替换不再留下过时的缺失镜像成员。
- 修复：移除启动池设备时不再触发可能导致操作失败的回归问题。
- 修复：对名称与启动设备重叠的池设备进行格式化时，不再触发错误的无效目标断言。
- 修复：现已更正 Btrfs RAID1 池的仪表板缓存池大小和使用情况报告。

### WebGUI / 系统

- 新增：为使用 LED 和 LCD 状态的面板指示插件添加了监视器状态输出。
- 修复：关机和重启时保存 syslog 现在会在写入 syslog 文件之前创建 `/boot/logs`。
- 修复：系统设备控制器列表在受影响的情况下不再包含无关设备。
- 修复：带闪存许可的内部引导现在能更好地处理临时性的 USB 许可证设备重置。

### 网络 / 硬件

- 修复：Avahi/mDNS 更新现在可在临时网络丢失后重新启动守护进程。
- 修复：现已更正 Intel GPU PCI 速度报告。
- 改进：仅在安装了支持插件时才显示 Intel iGPU SR-IOV 控件。

### 虚拟化

- 修复：VM CPU 使用率不再报告由无关宿主机任务导致的高占用。
- 修复：现已更正 VM 右键菜单位置。
- 改进：VM Network Source 下拉项已排序，并且控件更宽，便于浏览。
- 修复：在启用 VM PCI 选项时，移除了过时的 VM 重启横幅消息。

### Unraid API

- 将 Unraid API 更新到 [dynamix.unraid.net 4.35.1](\<https://github.com/unraid/api/releases/tag/v4.35.1>)。

### Linux kernel

- Linux 内核：更新到 6.18.38-Unraid。
  CONFIG_USB_AUTOSUSPEND_DELAY=-1
