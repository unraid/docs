# 版本 7.3.3-rc.1 2026-09-03

Unraid OS 7.3.3-rc.1 是一个候选发布更新，重点在于安全修复、Linux 6.18.47 内核、Docker 和 API 更新、可配置的电源按钮控制、扩展的硬件和 Hyper-V 支持，以及更新的基础软件包。由于此版本包含安全修复，建议升级。

## 升级

有关分步说明，请参阅[更新 Unraid](/unraid-os/updating-unraid/)。有关您的[许可证](/unraid-os/troubleshooting/licensing-faq/)的问题？请查看[许可证常见问题解答](/unraid-os/troubleshooting/licensing-faq/)。

## 与 Unraid OS 7.3.2 相比的变更

### 安全

- 安全性：已使用上游安全修复和 CVE 修复更新系统组件。

### 容器 / Docker

- 修复：在移除或更新无图标的 Docker 容器时，阻止删除共享的后备图标，并避免缺失后备图标导致重复的失败请求。

### WebGUI / 系统

- 新增：在 设置 > 电源选项 下添加了可配置的物理电源按钮操作：关机、重启和不执行任何操作。

### 网络 / 硬件

- 新增：为额外的 Intel 无线、MediaTek 蓝牙和 Realtek RTW88 无线硬件添加了内核模块和固件。

### 虚拟化

- 新增：为 Hyper-V 图形、ballooning、存储、键盘、VMBus、utility 和 VSOCK 组件添加了内核支持。

### Unraid API

- 更新 [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.3 - 查看更改。

### Linux kernel

- Linux 内核：更新至 6.18.47-Unraid。
