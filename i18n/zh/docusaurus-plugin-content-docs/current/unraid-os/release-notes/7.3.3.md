# 版本 7.3.3-rc.2 2026-09-24

Unraid OS 7.3.3-rc.2 包含安全修复，将 Linux 内核更新至 6.18.52，新增可配置的电源按钮操作和硬件支持，并修复 Docker、文件管理器和 WebGUI 问题。

我们预计此版本将在下周（9 月 27 日当周）进入稳定版。

## 升级

有关分步说明，请参阅[更新 Unraid](/unraid-os/updating-unraid/)。有关您的[许可证](/unraid-os/troubleshooting/licensing-faq/)的问题？请查看[许可证常见问题解答](/unraid-os/troubleshooting/licensing-faq/)。

## 已知问题

未列出新的本版本特定已知问题。有关此前记录的问题，请参阅 [Unraid OS 7.3.2 发布说明](/unraid-os/release-notes/7.3.2/)。

## 回滚

有关回滚指南和兼容性限制，请参阅 [Unraid OS 7.3.2 发布说明](/unraid-os/release-notes/7.3.2/)。

## 相较于 [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) 的变更

### 安全

- 强化了 root 密码设置，在 OpenTerminal 请求输入到达特权命令之前对其进行了验证，并防止 VM Manager 中由访客提供的接口名称被解释为 HTML。
- 已更新带有安全修复的基础发行版软件包；下面相应的软件包更新中列出了 CVE 注释。

### 容器 / Docker

- 修复：当移除或更新不含图标的容器时，Docker Manager 不再删除共享默认图标。

### 存储

- 修复：文件管理器的复制和移动操作可能因符号链接深度错误而失败。
- 修复：防止并发文件锁请求耗尽 FUSE 工作线程池时出现 shfs 死锁。
- 修复：防止 shfs 断言失败导致 `/mnt/user` 变得不可用。

### WebGUI / 系统

- 新增：可在 设置 > 电源选项 下配置物理电源按钮，以执行关机、重启或不执行任何操作。
- 修复：更正了已停止阵列的使用率显示，并在阵列停止时恢复了已挂载启动设备的已用/可用统计信息。

### 网络 / 硬件

- 新增：为更多 Intel、MediaTek 和 Realtek 无线硬件添加了内核驱动和固件。

### 虚拟化

- 新增：为 Hyper-V 图形、ballooning、存储、键盘、VMBus、utility 和 VSOCK 组件添加了内核支持。

### Unraid API

- 更新 [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.4 - 参见更改。

### Linux kernel

- Linux 内核：更新至 `6.18.52-Unraid`。
