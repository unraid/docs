# 版本 7.4.0-beta.1 2026-08-14

Unraid OS 7.4.0-beta.1 是一个 beta 发行版，包含核心软件包的安全更新、Linux 内核 6.18.44、Docker 和 WebGUI 改进、扩展的容器网络和内存控制、新的任务管理和电源按钮设置，以及新增的 Realtek RTW88 无线硬件支持。

## 升级

有关分步说明，请参阅[更新 Unraid](/unraid-os/updating-unraid/)。有关您的[许可证](/unraid-os/troubleshooting/licensing-faq/)的问题？请查看[许可证常见问题解答](/unraid-os/troubleshooting/licensing-faq/)。

## 已知问题

- 没有记录新的、特定于此版本的已知问题。有关之前记录的问题，请参阅 [Unraid OS 7.3.2 发行说明](/unraid-os/release-notes/7.3.2/)。

## 相较于 [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) 的变更

### 安全

- 安全：核心软件包更新包含 bind、libXfont2、libarchive、libssh、openssh、p11-kit、php、samba、wpa_supplicant 和 xorg-server 的安全修复。
- 安全：通知集成现在对公共 API 使用经证书验证的请求。

### 容器 / Docker

- 新增：Docker 容器模板支持多个自定义网络，在重新创建或更新容器时会保留额外的网络连接。
- 新增：Docker 添加/编辑表单现在会显示容器图标 URL 的实时预览，并在 URL 为空或无效时提供回退显示。
- 新增：高级视图现在为 Docker 容器显示内存限制字段。

### 存储

- 修复：在加密阵列密码字段中按 Enter 键时，现在会在密码验证成功后启动阵列。
- 修复：文件管理器会在 `/mnt/user/\<share>` 视图中保留独占共享，而不是切换到底层磁盘或池路径。

### WebGUI / 系统

- 新增：来自插件、Docker 和虚拟机的后台操作可以排队并从共享任务托盘中管理，且可在任意浏览器标签页中召回前台。
- 新增：启动设备页面支持直接下载备份或将其保存到服务器，并带有进度跟踪。
- 新增：可将物理电源按钮行为配置为关机、重启或不执行任何操作。请前往 设置 → 电源选项 进行配置。
- 改进：前台任务面板现在会随浏览器视口缩放，同时保留已保存的宽度和移动端行为。
- 改进：如果许可证在磁盘上不可用持续一分钟，许可证检查现在会重试，这允许启动盘暂时掉线
- 改进：统一的页眉现在负责页眉布局和阵列使用情况显示，从而解决移动端页眉重叠问题。
- 修复：已安装插件页面会独立检查更新，因此缓慢或无法访问的插件不会让整个页面一直等待。
- 修复：插件更新验证失败现在会保持可见并附带说明，而不是静默地将插件报告为已是最新，包括由 root 文件系统已满导致的失败。
- 修复：当错误消息包含 shell 字符时，插件管理器的 post-hook 清理现在会运行。

### 网络 / 硬件

- 新增：为 Realtek RTW88 8812A、8814A 和 8821A 无线适配器添加了内核模块和固件。

### 虚拟化

- 修复：当 QEMU 位置查找没有输出时，虚拟机启动不再记录 PHP 弃用警告。

### Unraid API

- 更新 [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.1 - [查看更改](\<https://github.com/unraid/api/releases>)。

### Linux kernel

- Linux 内核：更新至 6.18.44-Unraid。
