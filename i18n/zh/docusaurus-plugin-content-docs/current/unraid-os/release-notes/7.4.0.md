# 版本 7.4.0-beta.2 2026-09-03

Unraid OS 7.4.0-beta.2 新增 Docker 多网络和内存控制、共享后台任务管理、启动设备备份改进、可配置的电源按钮行为、**mover 进度跟踪**以及扩展的硬件和 Hyper-V 支持。同时还改进了临时许可证检查，将 Linux 内核更新到 6.18.47-Unraid、将 Unraid API 更新到 4.37.3，并包含核心软件包安全更新（与 7.3.3-rc.1 相同的核心软件包更新）

## 7.4.0-beta.1 的修复 / 功能

- 新增：现在可用搬移器进度和状态跟踪。由于已知问题，请前往 ***设置 → 计划程序 → 搬移器设置***，将 **搬移器进度** 设为 **已禁用**，然后选择 **应用**。接着将 **搬移器进度** 设为 **已启用**，再选择一次 **应用**。
- 修复：当安装 Dynamix System Buttons 插件时，Power Options 会同时保留 Power Mode 和 Power Button 选项卡。
- 修复：Power Options 不再在裸机服务器上显示虚拟化警告。

## 相较于 [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) 的变更

### 安全

- 安全性：核心组件包含针对已报告 CVE 和其他安全修复的更新。
- 安全性：通知集成现在会验证公共 API 证书，而不是绕过证书验证。

### 容器 / Docker

- 新增：Docker 容器模板支持多个自定义网络，在重新创建或更新容器时会保留额外的网络连接。
- 新增：Docker 添加/编辑表单现在会为容器图标 URL 显示实时预览，并在 URL 为空或无效时提供回退显示。
- 新增：高级视图中为 Docker 容器显示了内存限制字段。

### 存储

- 新增：现在可用搬移器进度和状态跟踪。由于已知问题，请前往 ***设置 → 计划程序 → 搬移器设置***，将 **搬移器进度** 设为 **已禁用**，然后选择 **应用**。接着将 **搬移器进度** 设为 **已启用**，再选择一次 **应用**。
- 新增：当 SES 不可用时，驱动器位置支持可使用支持 SGPIO/IBPI 的控制器。
- 修复：已停止的阵列现在显示离线和文件系统状态文本，而不是 100% 利用率。
- 修复：在加密阵列密码短语字段中按 Enter 现在会在密码短语验证成功后启动阵列。

### WebGUI / 系统

- 新增：来自插件、Docker 和虚拟机的后台操作可以排队并从共享任务托盘中管理，且可在任意浏览器标签页中召回前台。
- 新增：启动设备备份作为后台任务运行，可选择压缩方式、实时进度，并在完成后自动下载。
- 新增：可在“设置 → 电源设置 → 电源按钮 → **物理电源按钮**”下配置物理电源按钮，支持关机、重启和不执行任何操作。
- 改进：前台任务面板现在会随浏览器视口缩放，同时保留已保存的宽度和移动端行为。
- 改进：许可证检查现在会重试，以处理临时可用性和网络状况。
- 修复：当安装 Dynamix System Buttons 插件时，Power Options 会同时保留 Power Mode 和 Power Button 选项卡。
- 修复：Power Options 不再在裸机服务器上显示虚拟化警告。
- 修复：已安装插件页面会独立检查更新，因此缓慢或无法访问的插件不会让整个页面一直等待。
- 修复：插件更新验证失败现在会显示说明，而不是静默地将插件报告为已是最新版本。
- 修复：当错误消息包含 shell 字符时，插件管理器的 post-hook 清理现在会运行。

### 网络 / 硬件

- 新增：添加了适用于 Realtek RTW88 8812A、8814A 和 8821A 无线适配器的内核模块和固件，以及适用于 RTW89 8851BU 和 8852BU USB 适配器的内核模块。
- 新增：增加了对更多 PlayStation、Nintendo、Steam 和 Logitech 控制器的支持，以及更多音频编解码器。
- 改进：网络默认设置现在遵循 Fedora 的 `/etc/sysctl.conf` 基线，包括 CUBIC TCP 拥塞控制和将 `fq_codel` 作为默认数据包调度器。

### 虚拟化

- 新增：添加了 Hyper-V 虚拟化的内核支持，包括 Hyper-V 存储、balloon、键盘和 VMBus 模块。
- 修复：当 QEMU 位置查找没有输出时，虚拟机启动不再记录 PHP 弃用警告。

### Unraid API

- 更新 [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.3 - 查看更改。

### Linux kernel

- Linux 内核：更新至 6.18.47-Unraid。
