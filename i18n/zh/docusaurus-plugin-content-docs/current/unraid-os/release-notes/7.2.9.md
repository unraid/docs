# 版本 7.2.9 2026-10-23

此维护版本包含 PHP 安全修复、Unraid API 从 4.36.1 更新到 4.37.7，以及针对 [eMudhra 证书泄露报告](<https://unit42.paloaltonetworks.com/emudhra-certificate-compromise/>)中提及的受影响 CA 证书的更新。内核版本与 7.2.8 保持不变。**我们建议升级到最新稳定版 Unraid OS 7.3.x**，以获得更新的内核和更广泛的软件包安全更新。

## 升级 {/* #upgrading */}

有关分步说明，请参阅[更新 Unraid](/unraid-os/updating-unraid/)。有关您的[许可证](/unraid-os/troubleshooting/licensing-faq/)的问题？请查看[许可证常见问题解答](/unraid-os/troubleshooting/licensing-faq/)。

## 已知问题 {/* #known-issues */}

GUI 模式下的 Firefox 尚未针对受影响的 CA 证书进行修补。请勿将此浏览器用于 WebGUI 设置以外的任何用途。

有关可能仍然适用的其他问题，请参阅 [Unraid OS 7.2.8 发行说明](/unraid-os/release-notes/7.2.8/)。

未记录特定于本版本的回滚警告或兼容性限制。

## 相较于 [Unraid OS 7.2.8](/unraid-os/release-notes/7.2.8/) 的变更

### 安全

- 安全性：已更新 PHP 以修复多个 CVE。
- 安全性：已处理 [Unit 42 报告](<https://unit42.paloaltonetworks.com/emudhra-certificate-compromise/>)中提到的受影响 CA 证书。

### Unraid API 4.37.7

从 4.36.1 更新至 4.37.7。已将 API 内置的 Node.js 运行时更新到 22.23.4——这解决了 Node 证书泄露问题。参见 [完整 API 比较](<https://github.com/unraid/api/compare/v4.36.1...v4.37.7>)。

### 安全公告：其他潜在漏洞

**我们建议升级到最新稳定版 Unraid OS 7.3.x**，以获得更新的内核和更广泛的软件包安全更新。仅升级到 7.2.9 **不应被理解为** 已解决所有潜在发现。

Unraid OS 7.2.9 是一个有针对性的维护版本，包含 PHP 安全修复、CA 证书更新，以及 Unraid API 修复和安全加固。它**不**包含更新版本中提供的更广泛发行版软件包或内核安全更新。

截至 2026 年 10 月 23 日，上游软件包公告识别出 115 个与所含软件包版本相关的潜在 CVE。其中 112 个潜在 CVE 按以下类别列出：

- \*\*网络传输和 DNS — 42：\*\*curl（30）和 BIND（12）。
- \*\*加密和安全连接 — 25：\*\*OpenSSL（23）、libssh（1）和 p11-kit（1）。
- \*\*图形组件 — 29：\*\*xorg-server（11）、libXi（8）、libX11（4）、libXfont2（2）、libXtst（2）、libXpm（1）和 libXrender（1）。
- \*\*文件共享 — 6：\*\*Samba（6）。
- \*\*其他库和系统实用程序 — 10：\*\*libpcap（5）、util-linux（4）和 libpng（1）。

其他安全公告涵盖 libarchive、libxml2、OpenSSH、PCRE2、rsync、wpa_supplicant 和 xz，但未列出具体的 CVE 标识符。独立的漏洞数据库检查识别出 55 个潜在的软件包 CVE，可能与上述 115 个重叠；这些总数不能相加。

更新的上游内核版本也包含本 7.2.9 中未包含的安全修复。
