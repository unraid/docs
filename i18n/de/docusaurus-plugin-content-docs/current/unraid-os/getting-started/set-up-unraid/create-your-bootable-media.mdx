# Erstellen Sie ein Unraid-USB-Laufwerk.

Unraid OS kann von einem USB-Flash-Laufwerk oder, in Unraid 7.3 und später, von einem unterstützten internen Startlaufwerk booten. Diese Seite erklärt, wie Sie ein USB-Laufwerk für einen neuen Server erstellen. Sie können das USB-Laufwerk weiterhin für den Flash-Start verwenden oder damit den Server starten, bevor Sie während der Ersteinrichtung den internen Start auswählen. Weitere Informationen finden Sie in den [FAQ zum internen Start (7.3+)](./internal-boot-faq.mdx).

Verwenden Sie für den USB-Start ein hochwertiges USB-Flash-Laufwerk beliebiger Größe mit einer eindeutigen %%GUID|guid%%. Die %%GUID|guid%% identifiziert das USB-Gerät für die Lizenzierung.

:::tip[Choosing zuverl�e4ssige Boot-Medien]

Wählen Sie für den USB-Start ein hochwertiges USB-Flash-Laufwerk mit einer eindeutigen %%GUID|guid%%. Hinweise zu zuverlässigen Medien und gefälschten Laufwerken finden Sie im Abschnitt zur manuellen Installation unter [Auswahl eines Boot-Laufwerks](#choosing-a-usb-flash-drive).

Wenn Sie den internen Start verwenden möchten, benötigen Sie dieses USB-Laufwerk dennoch, um einen neuen Server zu starten. Nach dem ersten Start können Sie im Einrichtungsassistenten zwischen Flash-Start und internem Start wählen.

:::

## Automatisierte Installationsmethode {/* #automated-install-method */}

Der Unraid USB Creator bereitet das Laufwerk vor, lädt das ausgewählte Unraid OS-Image herunter oder verwendet es und schreibt das Image auf das USB-Laufwerk. Verwenden Sie diese Methode für die meisten neuen Installationen.

:::caution[Writing das USB-Laufwerk wird gelöscht]

Die Aktion **WRITE** löscht das ausgewählte USB-Laufwerk. Trennen Sie vor dem Start andere Wechseldatenträger. Wenn Sie ein vorhandenes Unraid-Boot-Gerät ersetzen, [sichern Sie es zuerst](../../system-administration/secure-your-server/secure-your-boot-drive.mdx).

:::

### USB Creator herunterladen

Laden Sie den USB Creator für Ihren Computer herunter und installieren Sie ihn:

- [Windows](https://releases.unraid.net/dl/stable/usb-creator.exe)
- [macOS](https://releases.unraid.net/dl/stable/usb-creator.dmg)
- [Linux](https://releases.unraid.net/dl/stable/usb-creator.appimage)

Stecken Sie das USB-Laufwerk in Ihren Computer. Schließen Sie alle Anwendungen, die auf das Laufwerk zugreifen.

### Sprache auswählen

1. Öffnen Sie den USB Creator.
2. Wählen Sie Ihre Sprache aus.
3. Wählen Sie **WEITER**.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator-Sprachauswahl](/img/unraid-os/getting-started/create-unraid-usb/01-00-language-selection.png)
</div>

### Wählen Sie eine Unraid OS-Version aus

1. Wählen Sie die zu installierende Unraid OS-Version aus.
2. Wählen Sie **WEITER**.

Wählen Sie für einen Produktionsserver die neueste stabile Version aus. Verwenden Sie ein Entwicklungsimage nur, wenn Sie dieses Image testen.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Auswahl des Betriebssystems im USB Creator](/img/unraid-os/getting-started/create-unraid-usb/02-01-os-selection.png)
</div>

### Wählen Sie das USB-Laufwerk aus

1. Wählen Sie das USB-Laufwerk aus, das Sie vorbereiten möchten.
2. Überprüfen Sie den Laufwerksnamen, die Größe und die %%GUID|guid%%.
3. Lassen Sie **Systemlaufwerke ausschließen** ausgewählt.
4. Wählen Sie **WEITER**.

Die %%GUID|guid%% muss eindeutig sein, damit das Laufwerk mit der Unraid-Lizenzierung funktioniert. Wählen Sie kein Laufwerk aus, dessen Daten Sie behalten möchten.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Auswahl des Speichergeräts im USB Creator](/img/unraid-os/getting-started/create-unraid-usb/03-02-storage-selection.png)
</div>

### Konfigurieren Sie den neuen Server (optional)

Im Abschnitt **Anpassung** können Sie vor dem ersten Start diese Optionen festlegen:

- **Servername** legt den Namen fest, den Unraid in Ihrem Netzwerk verwendet.
- **Wi-Fi** speichert die WLAN-Netzwerkeinstellungen für einen Server, der eine drahtlose Verbindung verwendet.
- **Netzwerk** legt die automatische Adressierung mit DHCP oder eine statische IP-Adresse fest.

Überspringen Sie diese Abschnitte, wenn Sie den Server nach dem ersten Start konfigurieren möchten. Wenn Sie Wi-Fi konfigurieren, behandeln Sie den USB-Stick so, als enthielte er das Wi-Fi-Passwort, bis der Server zum ersten Mal startet.

### Image überprüfen und schreiben

1. Überprüfen Sie in der Zusammenfassung das Betriebssystem und das Speichergerät.
2. Stellen Sie sicher, dass das Speichergerät das USB-Laufwerk ist, das Sie löschen möchten.
3. Wählen Sie **SCHREIBEN**.

Der USB Creator schreibt das ausgewählte Image auf das Laufwerk.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Zusammenfassung des Schreibvorgangs im USB Creator](/img/unraid-os/getting-started/create-unraid-usb/04-03-write-summary.png)
</div>

### USB-Setup abschließen

Wenn der Schreibvorgang abgeschlossen ist:

1. Überprüfen Sie die auf dem Abschlussbildschirm angezeigten Auswahlmöglichkeiten.
2. Wählen Sie **FERTIGSTELLEN**.
3. Entfernen Sie das USB-Laufwerk erst, nachdem der USB Creator es ausgeworfen hat.

UEFI-Systeme können ohne zusätzlichen Schritt von dem Laufwerk booten. Führen Sie bei einem älteren BIOS-only-System das Bootskript vom Stammverzeichnis des USB-Laufwerks aus:

- **Windows:** Klicken Sie mit der rechten Maustaste auf `make_bootable.bat` und wählen Sie **Als Administrator ausführen**.
- **macOS:** Doppelklicken Sie auf `make_bootable_mac` und geben Sie bei Aufforderung Ihr Administrator-Passwort ein.
- **Linux:** Hängen Sie das USB-Laufwerk aus. Führen Sie dann `sudo bash ./make_bootable_linux` aus.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Schreibabschluss im USB Creator](/img/unraid-os/getting-started/create-unraid-usb/05-04-write-complete.png)
</div>

### Starten Sie den Server von dem neuen USB-Laufwerk

1. Stecken Sie das vorbereitete USB-Laufwerk in den Server ein.
2. Öffnen Sie die BIOS- oder UEFI-Einstellungen des Servers.
3. Setzen Sie das USB-Laufwerk als erstes Bootgerät.
4. Speichern Sie die BIOS-Einstellungen und starten Sie den Server neu.

Unter Unraid 7.3 und später können Sie beim ersten Start von Unraid im Einrichtungsassistenten die Startmethode auswählen:

- **Flash-Start** belässt Unraid auf dem USB-Laufwerk.
- **Interner Start** verschiebt Unraid auf ein unterstütztes internes Startlaufwerk oder auf zwei gespiegelte interne Startlaufwerke.

Weitere Informationen zum internen Start finden Sie im Abschnitt [Ersteinrichtung](./deploy-and-configure-unraid-os.mdx#onboarding) und in den [FAQ zum internen Start (7.3+)](./internal-boot-faq.mdx).

Nachdem Unraid OS gestartet ist, fahren Sie mit [Unraid OS bereitstellen und konfigurieren](./deploy-and-configure-unraid-os.mdx) fort.

## Fehlerbehebung

### Das USB-Laufwerk wird nicht angezeigt

1. Trennen Sie das USB-Laufwerk.
2. Schließen Sie den USB Creator.
3. Schließen Sie das USB-Laufwerk direkt an den Computer an.
4. Öffnen Sie den USB Creator erneut.

Der Unraid USB Creator listet für diesen Workflow nur USB-Speichergeräte auf. Stellen Sie sicher, dass Ihr Computer das Laufwerk erkennt, bevor Sie den USB Creator öffnen.

### Der Server bootet nicht vom USB-Laufwerk

1. Öffnen Sie die BIOS- oder UEFI-Einstellungen.
2. Stellen Sie sicher, dass das USB-Laufwerk das erste Bootgerät ist.
3. Führen Sie bei einem BIOS-only-System das plattformspezifische Skript `make_bootable` aus, das unter [USB-Setup abschließen](#finish-the-usb-setup) beschrieben ist.
4. Speichern Sie die Einstellungen und starten Sie den Server neu.

Wenn Sie den internen Boot ausgewählt haben und der Server nach dem Onboarding nicht startet, verschieben Sie das ausgewählte interne Boot-Gerät an den Anfang der BIOS-/UEFI-Bootreihenfolge. Wenn der Server immer noch nicht startet, verwenden Sie die [Manuelle Installationsmethode](#manual-install-method), um den USB-Stick erneut vorzubereiten.

### Das USB-Laufwerk kann keine Lizenz registrieren

USB-Boot und USB-Lizenzierung erfordern eine eindeutige %%GUID|guid%%. Wenn das Laufwerk keine eindeutige %%GUID|guid%% hat, verwenden Sie einen anderen USB-Flash-Speicher. Wenn Sie den internen Boot mit TPM-basierter Lizenzierung verwenden, siehe die [FAQ zum internen Boot (7.3+)](./internal-boot-faq.mdx#internal-boot-flash-license).

## Manuelle Installationsmethode {/* #manual-install-method */}

Die manuelle Installationsmethode ist für Situationen gedacht, in denen der USB Creator nicht verfügbar oder mit Ihrer Hardware inkompatibel ist. Diese Methode gibt Ihnen die Kontrolle über die Formatierung und den Einrichtungsprozess.

### Auswahl eines Boot-Geräts {/* #choosing-a-usb-flash-drive */}

<FlashDriveGuidance />

### Bereiten Sie Ihr USB-Gerät vor {/* #prepare-your-usb-device */}

1. Schließen Sie das USB-Laufwerk an, das Sie als Boot-Gerät vorbereiten.
2. Formatieren Sie es auf FAT32 (**nicht** ex-FAT oder NTFS).
3. Setzen Sie das Volume-Label auf `UNRAID` (großgeschrieben, genau so).

:::important

Unter Windows können die integrierten Formatierungswerkzeuge Laufwerke mit mehr als 32 GB nicht als FAT32 formatieren. Sie verwenden standardmäßig exFAT. Für ein größeres Laufwerk verwenden Sie ein FAT32-fähiges Tool wie [Rufus](https://rufus.ie/en/).

:::

### Herunterladen und entpacken

1. Gehen Sie zum [Unraid Download-Archiv](../../download_list.mdx) und laden Sie die ZIP-Datei Ihrer gewählten Version herunter.
2. Entpacken Sie den Inhalt der ZIP-Datei auf das USB-Gerät.
3. Bestätigen Sie, dass die Dateien kopiert wurden.

### Machen Sie das USB-Gerät bootfähig

:::note

Dieser Abschnitt ist nur erforderlich, um das Legacy-Boot zu aktivieren. Wenn Sie für den UEFI-Boot einrichten, ist es nicht erforderlich, diese Skripte auszuführen.

:::

**Windows 7 oder höher:**

**Windows 7 oder höher:**

- Rechtsklicken Sie auf `make_bootable` und wählen Sie **Als Administrator ausführen**.

**Mac:**

- Doppelklicken Sie auf `make_bootable_mac` und geben Sie Ihr Admin-Passwort ein.

**Linux:**

- Kopieren Sie `make_bootable_linux` auf Ihre Festplatte.
- Hängen Sie das USB-Laufwerk aus.
- Führen Sie im Terminal aus:

  ```bash
  sudo bash ./make_bootable_linux
  ```

:::note

Das USB-Laufwerk kann während dieses Vorgangs kurzzeitig verschwinden und einige Male wieder erscheinen. Das ist normal.

:::
