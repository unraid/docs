# Unraid Installer verwenden

Der Unraid Installer startet auf dem Zielrechner und bereitet ein Gerät für eine Unraid-Installation vor. Er kann ein USB-Flash-Startgerät oder ein internes Startgerät erstellen.

Verwenden Sie dieses Tool, wenn Sie direkt am Zielrechner oder über eine Remote- bzw. virtuelle Konsole arbeiten. Für die meisten Benutzer, die auf einem Laptop oder Desktop einen USB-Stick erstellen, verwenden Sie stattdessen den [Unraid USB Creator](https://unraid.net/download).

:::note[Unraid 7.3 und höher]

Der Unraid Installer unterstützt den internen Boot-Workflow, der in Unraid 7.3 eingeführt wurde.

:::

## Wann der Unraid Installer verwendet werden sollte

Wählen Sie das Tool, das zu Ihrem Installationspfad passt:

| Werkzeug           | Verwenden Sie es, wenn                                                                                                                                   | Wo es ausgeführt wird            |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| Unraid USB Creator | Sie möchten ein USB-Laufwerk von einem Laptop oder Desktop-Computer vorbereiten.                                                                         | Ihr Laptop oder Desktop-Computer |
| Unraid Installer   | Sie möchten das Startmedium auf dem Zielgerät vorbereiten, den internen Boot verwenden oder in einer Remote- oder virtualisierten Umgebung installieren. | Das Zielgerät                    |

Der USB Creator benötigt kein Display auf dem Server, während er das
USB-Laufwerk vorbereitet. Der Unraid Installer benötigt Display- oder
Konsolenzugriff auf das Zielgerät, da Sie den Installer dort starten und
verwenden müssen.

## Bevor Sie beginnen

Bereiten Sie diese Dinge vor:

1. Ein Zielgerät mit Display- oder Konsolenzugriff.
2. Ein Installer-Asset aus der [neuesten stabilen Unraid Installer-Version](https://github.com/unraid/bootable-unraid-installer/releases/latest).
3. Ein USB-Laufwerk oder virtuelle Medien für den Installer.
4. Ein Ziellaufwerk, das Sie löschen können.
5. Netzwerkzugriff, wenn Sie den Online-Installer verwenden und während der
   Installation das Unraid OS ZIP herunterladen müssen.

Sichern Sie alle Daten, die Sie benötigen, bevor Sie ein Ziellaufwerk auswählen.

:::caution[The installer löscht ausgewählte Laufwerke]

Die Aktionen **Create Flash Boot** und **Create Internal Boot** löschen das
ausgewählte Ziel-Laufwerk bzw. die ausgewählten Ziel-Laufwerke. Lesen Sie den
Laufwerksnamen und die Größe, bevor Sie den Vorgang bestätigen.

:::

## Wählen Sie ein Installer-Asset aus

Die Release-Seite stellt Assets für ISO- und USB-Boot-Pfade bereit:

| Asset                                                          | Verwenden Sie es, wenn                                                                                                                    | Netzwerkanforderung                                                               |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `unraid-installer-\<version>-online.iso`      | Sie starten den Installer über virtuelle Medien oder eine Remote-Konsole.                                                                 | Das Zielgerät muss den Release-Dienst erreichen, wenn es das OS ZIP herunterlädt. |
| `unraid-installer-\<version>-online.img.zip`  | Sie schreiben das Installer-Image auf ein USB-Laufwerk. Extrahieren Sie die ZIP-Datei, bevor Sie die IMG-Datei schreiben.                 | Das Zielgerät muss den Release-Dienst erreichen, wenn es das OS ZIP herunterlädt. |
| `unraid-installer-\<version>-bundled.img.zip` | Sie möchten, dass die Installationsmedien das OS ZIP bereits enthalten. Extrahieren Sie die ZIP-Datei, bevor Sie die IMG-Datei schreiben. | Das OS ZIP befindet sich bereits auf den Installationsmedien.                     |

Verwenden Sie den Online-Installer für einen kleineren Download, wenn das Zielgerät
Netzwerkzugriff hat. Verwenden Sie den gebündelten Installer, wenn das Zielgerät
während der Installation das OS ZIP nicht herunterladen kann.

Die Release-Seite stellt außerdem Prüfsummendateien für die herunterladbaren Assets bereit. Verwenden Sie sie, wenn Ihr Download- oder Imaging-Tool die Prüfsummenprüfung unterstützt.

## Starten Sie den Installer

1. Laden Sie ein Installer-Asset aus der [neuesten stabilen Version](https://github.com/unraid/bootable-unraid-installer/releases/latest) herunter.
2. Extrahieren Sie eine IMG-ZIP-Datei, wenn Sie eine heruntergeladen haben.
3. Starten Sie das Zielgerät vom Installer aus:
   - Hängen Sie eine ISO über virtuelle Medien oder eine virtuelle Maschinenkonsole ein.
   - Schreiben Sie eine IMG-Datei mit einem Imaging-Tool wie Rufus
     oder Balena Etcher auf ein USB-Laufwerk.
4. Wählen Sie im Boot-Menü des Zielgeräts das Installationsgerät aus.
5. Warten Sie auf das Menü **Unraid ISO Installer**.

:::caution[Writing eine IMG-Datei löscht das USB-Laufwerk]

Wählen Sie das gesamte USB-Gerät aus, nicht eine Partition. Trennen Sie andere
Wechsellaufwerke, bevor Sie das Installer-Image schreiben.

:::

## Verwenden Sie das Installer-Menü

Das Installer-Menü bietet diese Aktionen:

| Menüaktion                             | Beschreibung                                                                                                                          |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **ZIP herunterladen**                  | Laden Sie ein Unraid OS ZIP herunter und speichern Sie es für die Boot-Aktionen.                                                      |
| **Größe des internen Boots festlegen** | Legen Sie die Größe des internen Boot-Pools fest, bevor Sie ein internes Boot-Gerät erstellen.                                        |
| **Internes Boot erstellen**            | Bereiten Sie ein oder zwei interne Laufwerke für den Unraid-Boot vor. Zwei Laufwerke erstellen ein gespiegeltes Set von Boot-Geräten. |
| **Flash-Boot erstellen**               | Bereiten Sie ein USB-Laufwerk als Unraid-Flash-Boot-Gerät vor.                                                                        |
| **Netzwerkstatus anzeigen**            | Schnittstellen, IP-Adressen und Routen anzeigen.                                                                                      |
| **Netzwerk erneut versuchen (DHCP)**   | Netzwerkschnittstellen aktivieren und DHCP erneut versuchen.                                                                          |
| **WLAN + DHCP verbinden**              | Eine erkannte drahtlose Schnittstelle verbinden, wenn WLAN-Unterstützung verfügbar ist.                                               |
| **Shell**                              | Eine Shell für erweiterte Fehlerbehebung öffnen.                                                                                      |
| **Persistenzgröße ändern**             | Den Persistenzbereich des Installers vergrößern oder verkleinern, wenn das Image dies unterstützt.                                    |
| **Herunterfahren** und **Neustarten**  | Das Zielgerät herunterfahren oder neu starten.                                                                                        |

Wenn kein grafisches Menü verfügbar ist, verwendet der Installer eine Texteingabeaufforderung.

## Ein Flash-Boot-Gerät erstellen

Verwenden Sie diesen Weg, wenn das Zielgerät Unraid von einem USB-Flash-Laufwerk booten soll.

1. Wählen Sie **ZIP herunterladen** und wählen Sie eine Unraid-Version aus. Überspringen Sie diesen Schritt, wenn ein
   gebündelter Installer das erforderliche ZIP bereits enthält.
2. Wählen Sie **Flash-Boot erstellen**.
3. Wählen Sie das Ziel-USB-Laufwerk aus. Wählen Sie das gesamte Laufwerk, nicht eine Partition.
4. Lesen Sie die Warnung und bestätigen Sie, dass das Laufwerk gelöscht werden kann.
5. Warten Sie, bis der Installer eine FAT32-Partition mit der Bezeichnung `UNRAID` erstellt,
   die Unraid-Dateien kopiert und das Gerät bootfähig macht.
6. Starten Sie das Zielgerät neu und wählen Sie das neue Flash-Boot-Gerät aus.

Hinweise zum USB-Boot und zur Lizenzierung finden Sie unter [Create an Unraid USB drive](./create-your-bootable-media.mdx).

## Ein internes Boot-Gerät erstellen

Verwenden Sie diesen Weg, wenn das Zielgerät Unraid aus internem Speicher booten soll.
Dieser Weg ist nützlich für direkte Serverinstallationen sowie für entfernte oder virtualisierte
Umgebungen.

1. Wählen Sie **ZIP herunterladen** und wählen Sie eine Unraid-Version aus. Überspringen Sie diesen Schritt, wenn ein
   gebündelter Installer das erforderliche ZIP bereits enthält.
2. Wählen Sie **Größe des internen Boots festlegen**, wenn die Standardgröße nicht geeignet ist.
3. Wählen Sie **Internes Boot erstellen**.
4. Wählen Sie ein Laufwerk oder zwei Laufwerke aus. Wählen Sie zwei Laufwerke, um ein gespiegeltes
   Set von Boot-Geräten zu erstellen.
5. Wählen Sie die Größe des Boot-Pools. Verwenden Sie **Dedicated**, um das Laufwerk als dediziertes
   Boot-Gerät zu verwenden, oder wählen Sie eine feste oder benutzerdefinierte Größe.
6. Geben Sie einen Namen für den Boot-Pool ein. Der Name muss mit einem Kleinbuchstaben beginnen und darf
   Kleinbuchstaben, Zahlen, `-` und `_` enthalten.
7. Überprüfen Sie die ausgewählten Laufwerke und bestätigen Sie die destruktive Aktion.
8. Warten Sie, während der Installer das Partitionslayout erstellt, die Unraid-
   Dateien kopiert, die Dateien validiert und die Boot-Konfiguration schreibt.
9. Starten Sie das Zielgerät neu und wählen Sie das neue interne Boot-Gerät aus.

For internal boot questions, see the [Internal Boot FAQ (7.3+)](./internal-boot-faq.mdx).

Der Installer weigert sich, das Gerät zu überschreiben, auf dem der Installer ausgeführt wird, oder
das aktive Root-Laufwerk. Andere Laufwerke, die Sie auswählen, werden dennoch gelöscht.

## Fehlerbehebung

### Der Installer sagt, dass eine ZIP-Datei erforderlich ist

Wählen Sie zuerst **ZIP herunterladen**. Wenn der Download fehlschlägt, wählen Sie **Netzwerkstatus anzeigen** und anschließend **Netzwerk erneut versuchen (DHCP)**. Verwenden Sie einen gebündelten Installer, wenn das Zielgerät das OS ZIP nicht herunterladen kann.

### Der Installer kann keine Version finden

Prüfen Sie, ob das Zielgerät eine verwendbare IP-Adresse und Standardroute hat. Wiederholen Sie die
Netzwerkeinrichtung und wählen Sie dann erneut **ZIP herunterladen**.

### Das Ziellaufwerk ist nicht aufgeführt

Stellen Sie sicher, dass das Laufwerk mit dem Zielgerät verbunden und dort verfügbar ist. Bei einer
virtuellen Maschine geben Sie das Laufwerk an die virtuelle Maschine durch. Wählen Sie das gesamte
Laufwerk, etwa `/dev/sdb` oder `/dev/nvme1n1`, nicht eine Partition.

### Der Installer weigert sich, ein Laufwerk zu verwenden

Der Installer weigert sich, das Gerät zu überschreiben, auf dem der Installer ausgeführt wird, oder
das aktive Root-Laufwerk. Starten Sie den Installer von einem anderen Gerät und wählen Sie das
gedachte Ziellaufwerk aus.

### Das Zielgerät bootet nach der Installation nicht

Öffnen Sie die Boot-Einstellungen der Firmware oder der virtuellen Maschine. Verschieben Sie das neue Flash- oder
interne Boot-Gerät an den Anfang der Boot-Reihenfolge und starten Sie dann das Zielgerät neu.

## Einrichtung fortsetzen

Nachdem Unraid vom neuen Boot-Gerät gestartet ist, fahren Sie mit [Unraid OS bereitstellen und konfigurieren](./deploy-and-configure-unraid-os.mdx) fort.

Für den Quellcode und die aktuellen Release-Assets siehe das [Unraid Installer-Repository](https://github.com/unraid/bootable-unraid-installer).
