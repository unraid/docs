# Version 7.4.0-beta.2 2026-09-03

Unraid OS 7.4.0-beta.2 fügt Docker-Multi-Netzwerk- und Speichersteuerungen, gemeinsam genutzte Hintergrundaufgabenverwaltung, Verbesserungen bei Boot-Geräte-Backups, konfigurierbares Verhalten der Ein-/Aus-Taste, **Mover-Fortschrittsverfolgung** sowie erweiterten Hardware- und Hyper-V-Support hinzu. Außerdem verbessert es die vorübergehende Lizenzprüfung, aktualisiert den Linux-Kernel auf 6.18.47-Unraid und die Unraid-API auf 4.37.3 und enthält Sicherheitsupdates für Kernpakete (dieselben Updates für Kernpakete wie in 7.3.3-rc.1)

## Fehlerbehebungen / Funktionen aus 7.4.0-beta.1

- Neu: Die Fortschritts- und Statusverfolgung für Mover ist jetzt verfügbar. Aufgrund eines bekannten Problems gehen Sie zu ***Einstellungen → Zeitplaner → Mover-Einstellungen***, setzen Sie **Mover-Fortschritt** auf **Deaktiviert** und wählen Sie **Anwenden**. Setzen Sie dann **Mover-Fortschritt** auf **Aktiviert** und wählen Sie erneut **Anwenden**.
- Behebung: Power Options behält sowohl die Registerkarte „Power Mode“ als auch die Registerkarte „Power Button“ bei, wenn das Dynamix System Buttons-Plugin installiert ist.
- Behebung: Power Options zeigt die Virtualisierungswarnung auf Bare-Metal-Servern nicht mehr an.

## Änderungen vs. [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Sicherheit

- Sicherheit: Kernkomponenten enthalten Aktualisierungen, die gemeldete CVEs und weitere Sicherheitskorrekturen adressieren.
- Sicherheit: Benachrichtigungsintegrationen überprüfen jetzt das öffentliche API-Zertifikat, anstatt die Zertifikatsvalidierung zu umgehen.

### Container / Docker

- Neu: Docker-Container-Vorlagen unterstützen mehrere benutzerdefinierte Netzwerke, wobei zusätzliche Netzwerkverbindungen beim Neuerstellen oder Aktualisieren von Containern beibehalten werden.
- Neu: Die Docker-Formulare zum Hinzufügen/Bearbeiten zeigen eine Live-Vorschau für die Container-Icon-URL mit einem Fallback, wenn die URL leer oder ungültig ist.
- Neu: Die erweiterte Ansicht stellt ein Feld für das Speicherlimit für Docker-Container bereit.

### Speicher

- Neu: Die Fortschritts- und Statusverfolgung für Mover ist jetzt verfügbar. Aufgrund eines bekannten Problems gehen Sie zu ***Einstellungen → Zeitplaner → Mover-Einstellungen***, setzen Sie **Mover-Fortschritt** auf **Deaktiviert** und wählen Sie **Anwenden**. Setzen Sie dann **Mover-Fortschritt** auf **Aktiviert** und wählen Sie erneut **Anwenden**.
- Neu: Die Unterstützung für Laufwerkspositionen kann SGPIO/IBPI-fähige Controller verwenden, wenn SES nicht verfügbar ist.
- Fix: Ein gestopptes Array zeigt jetzt Offline- und Dateisystem-Statustext anstelle von 100 % Auslastung an.
- Fix: Das Drücken von Enter in Passphrase-Feldern für verschlüsselte Arrays startet das Array jetzt, wenn die Passphrase-Validierung erfolgreich ist.

### WebGUI / System

- Neu: Hintergrundoperationen von Plugins, Docker und virtuellen Maschinen können in einer gemeinsamen Aufgabenablage in die Warteschlange gestellt und verwaltet werden, mit Vorholfunktion aus jedem Browser-Tab.
- Neu: Sicherungen des Boot-Geräts werden als Hintergrundaufgaben mit auswählbarer Komprimierung, Live-Fortschritt und automatischem Download nach Abschluss ausgeführt.
- Neu: Konfigurieren Sie die physische Power-Taste unter Einstellungen → Power-Einstellungen → Power-Taste → **Physische Power-Taste** mit den Aktionen Herunterfahren, Neustarten und Nichts tun.
- Verbesserung: Vordergrund-Aufgabenblätter skalieren jetzt mit dem Browser-Viewport und behalten dabei das gespeicherte Breitenverhalten und das Mobilverhalten bei.
- Verbesserung: Lizenzprüfungen versuchen es jetzt erneut, um vorübergehende Verfügbarkeits- und Netzwerkbedingungen zu handhaben.
- Behebung: Power Options behält sowohl die Registerkarte „Power Mode“ als auch die Registerkarte „Power Button“ bei, wenn das Dynamix System Buttons-Plugin installiert ist.
- Behebung: Power Options zeigt die Virtualisierungswarnung auf Bare-Metal-Servern nicht mehr an.
- Fix: Die Seite für installierte Plugins prüft Updates unabhängig, sodass ein langsames oder nicht erreichbares Plugin nicht die gesamte Seite warten lässt.
- Fix: Fehler bei der Validierung von Plugin-Updates bleiben mit einer Erklärung sichtbar, anstatt das Plugin stillschweigend als auf dem neuesten Stand zu melden.
- Fix: Die Bereinigung des Post-Hooks des Plugin-Managers wird jetzt ausgeführt, wenn Fehlermeldungen Shell-Zeichen enthalten.

### Netzwerk / Hardware

- Neu: Kernelmodule und Firmware für die drahtlosen Adapter Realtek RTW88 8812A, 8814A und 8821A wurden hinzugefügt, ebenso Kernelmodule für die USB-Adapter RTW89 8851BU und 8852BU.
- Neu: Unterstützung für zusätzliche PlayStation-, Nintendo-, Steam- und Logitech-Controller sowie zusätzliche Audio-Codecs wurde hinzugefügt.
- Verbesserung: Die Netzwerk-Standards folgen jetzt der `/etc/sysctl.conf`-Basis von Fedora, einschließlich CUBIC-TCP-Staukontrolle und `fq_codel` als Standard-Paketplaner.

### Virtualisierung

- Neu: Kernelunterstützung für die Hyper-V-Virtualisierung wurde hinzugefügt, einschließlich der Hyper-V-Module für Storage, Balloon, Tastatur und VMBus.
- Fix: Der Start der VM protokolliert jetzt keine PHP-Verwarnung wegen Veraltungsmehrung mehr, wenn die QEMU-Pfadabfrage keine Ausgabe liefert.

### Unraid API

- Aktualisierung [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.3 - siehe Änderungen.

### Linux-Kernel

- Linux-Kernel: Update auf 6.18.47-Unraid.
