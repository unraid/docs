# Version 7.4.0-beta.1 2026-08-14

Unraid OS 7.4.0-beta.1 ist eine Beta-Version mit Sicherheitsupdates für Kernpakete, Linux-Kernel 6.18.44, Verbesserungen an Docker und WebGUI, erweiterten Container-Netzwerk- und Speichersteuerungen, neuen Aufgabenverwaltungs- und Netzschalter-Einstellungen sowie hinzugefügter Unterstützung für Realtek-RTW88-Wireless-Hardware.

## Upgrade

Eine schrittweise Anleitung finden Sie unter [Updating Unraid](/unraid-os/updating-unraid/). Fragen zu Ihrer Lizenz? Lesen Sie die [License FAQ](/unraid-os/troubleshooting/licensing-faq/).

## Bekannte Probleme

- Es sind keine neuen versionsspezifischen bekannten Probleme dokumentiert. Für zuvor dokumentierte Probleme siehe die [Unraid OS 7.3.2 release notes](/unraid-os/release-notes/7.3.2/).

## Änderungen vs. [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Sicherheit

- Sicherheit: Kernpaket-Updates enthalten Sicherheitskorrekturen für bind, libXfont2, libarchive, libssh, openssh, p11-kit, php, samba, wpa_supplicant und xorg-server.
- Sicherheit: Benachrichtigungsintegrationen verwenden jetzt zertifikatsverifizierte Anfragen für die öffentliche API.

### Container / Docker

- Neu: Docker-Container-Vorlagen unterstützen mehrere benutzerdefinierte Netzwerke, wobei zusätzliche Netzwerkverbindungen beim Neuerstellen oder Aktualisieren von Containern beibehalten werden.
- Neu: Die Docker-Formulare Zum Hinzufügen/Bearbeiten zeigen jetzt eine Live-Vorschau für die URL des Container-Icons an, mit einem Fallback, wenn die URL leer oder ungültig ist.
- Neu: In der erweiterten Ansicht wird jetzt ein Feld für das Speicherlimit für Docker-Container angezeigt.

### Speicher

- Fix: Das Drücken von Eingabe in verschlüsselten Array-Passphrase-Feldern startet jetzt das Array, wenn die Passphrase-Validierung erfolgreich ist.
- Fix: Der Dateimanager behält exklusive Freigaben in der Ansicht `/mnt/user/\<share>` bei, statt zum zugrunde liegenden Disk- oder Pool-Pfad zu wechseln.

### WebGUI / System

- Neu: Hintergrundoperationen von Plugins, Docker und virtuellen Maschinen können in einer gemeinsamen Aufgabenablage in die Warteschlange gestellt und verwaltet werden, mit Vorholfunktion aus jedem Browser-Tab.
- Neu: Die Seite für das Boot-Medium unterstützt das direkte Herunterladen eines Backups oder das Speichern auf dem Server, mit Fortschrittsanzeige.
- Neu: Das Verhalten der physischen Powertaste kann für Herunterfahren, Neustart oder Nichts tun konfiguriert werden. Gehen Sie zu Einstellungen → Energieoptionen, um dies zu konfigurieren.
- Verbesserung: Vordergrund-Aufgabenblätter skalieren jetzt mit dem Browser-Viewport und behalten dabei das gespeicherte Breitenverhalten und das Mobilverhalten bei.
- Verbesserung: Lizenzprüfungen werden jetzt erneut versucht, wenn die Lizenz eine Minute lang nicht auf dem Laufwerk verfügbar ist; dies ermöglicht vorübergehende Ausfälle des Boot-Laufwerks
- Verbesserung: Der konsolidierte Kopfbereich verwaltet jetzt das Kopfbereich-Layout und die Anzeige der Array-Nutzung und behebt Überlappungen im mobilen Kopfbereich.
- Fix: Die Seite für installierte Plugins prüft Updates unabhängig, sodass ein langsames oder nicht erreichbares Plugin nicht die gesamte Seite warten lässt.
- Fix: Fehlgeschlagene Validierungen von Plugin-Updates bleiben jetzt mit einer Erklärung sichtbar, statt das Plugin stillschweigend als aktuell zu melden, einschließlich Fehlern, die durch ein volles Root-Dateisystem verursacht werden.
- Fix: Die Bereinigung des Post-Hooks des Plugin-Managers wird jetzt ausgeführt, wenn Fehlermeldungen Shell-Zeichen enthalten.

### Netzwerk / Hardware

- Neu: Kernelmodule und Firmware für drahtlose Adapter von Realtek RTW88 8812A, 8814A und 8821A hinzugefügt.

### Virtualisierung

- Fix: Der Start der VM protokolliert jetzt keine PHP-Verwarnung wegen Veraltungsmehrung mehr, wenn die QEMU-Pfadabfrage keine Ausgabe liefert.

### Unraid API

- Aktualisiere [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.1 - [Änderungen ansehen](\<https://github.com/unraid/api/releases>).

### Linux-Kernel

- Linux-Kernel: Update auf 6.18.44-Unraid.
