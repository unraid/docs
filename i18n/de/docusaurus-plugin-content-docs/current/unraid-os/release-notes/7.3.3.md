# Version 7.3.3-rc.1 2026-09-03

Unraid OS 7.3.3-rc.1 ist ein Release-Candidate-Update mit Fokus auf Sicherheitskorrekturen, den Linux-Kernel 6.18.47, Docker- und API-Updates, konfigurierbare Aktionen der Einschalttaste, erweiterte Unterstützung für Hardware sowie Hyper-V und aktualisierte Basispakete. Da dieses Release Sicherheitskorrekturen enthält, wird ein Upgrade empfohlen.

## Upgrade

Eine schrittweise Anleitung finden Sie unter [Updating Unraid](/unraid-os/updating-unraid/). Fragen zu Ihrer Lizenz? Lesen Sie die [License FAQ](/unraid-os/troubleshooting/licensing-faq/).

## Bekannte Probleme

- Es sind keine neuen release-spezifischen bekannten Probleme aufgeführt. Siehe die [Release Notes zu Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) für zuvor dokumentierte Probleme.

## Rückschritte

- Lesen Sie die [Release Notes zu Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) für Hinweise zum Rollback und zu Kompatibilitätseinschränkungen.

## Changes vs. Unraid OS 7.3.2

### Sicherheit

- Security: Updated system components with upstream security fixes and CVE remediations.

### Container / Docker

- Fix: Prevented removal of the shared fallback icon when an icon-less Docker container is removed or updated, and stopped missing fallback icons from causing repeated failed requests.

### WebGUI / System

- New: Added configurable physical power-button actions under Settings > Power Options: Shut down, Reboot, and Do nothing.

### Netzwerk / Hardware

- New: Added kernel modules and firmware for additional Intel wireless, MediaTek Bluetooth, and Realtek RTW88 wireless hardware.

### Virtualisierung

- New: Added kernel support for Hyper-V graphics, ballooning, storage, keyboard, VMBus, utility, and VSOCK components.

### Unraid API

- Update [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.3 - see changes.

### Linux-Kernel

- Linux kernel: update to 6.18.47-Unraid.
