# Version 7.3.3-rc.2 2026-09-24

Unraid OS 7.3.3-rc.2 enthält Sicherheitskorrekturen, aktualisiert den Linux-Kernel auf 6.18.52, fügt konfigurierbare Aktionen für die Einschalttaste und Hardwareunterstützung hinzu und behebt Probleme mit Docker, dem Dateimanager und der WebGUI.

Wir erwarten, dass diese Version nächste Woche (in der Woche vom 27. September) in den Stable-Status übergeht.

## Upgrade

Eine schrittweise Anleitung finden Sie unter [Updating Unraid](/unraid-os/updating-unraid/). Fragen zu Ihrer Lizenz? Lesen Sie die [License FAQ](/unraid-os/troubleshooting/licensing-faq/).

## Bekannte Probleme

Es sind keine neuen versionsspezifischen bekannten Probleme aufgeführt. Siehe die [Release Notes zu Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) für zuvor dokumentierte Probleme.

## Rückschritte

Hinweise zum Rollback und zu Kompatibilitätseinschränkungen finden Sie in den [Release Notes zu Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/).

## Änderungen vs. [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Sicherheit

- Die Einrichtung des Root-Passworts wurde gehärtet, OpenTerminal-Anfrageeingaben wurden vor der Übergabe an privilegierte Befehle validiert, und vom Gast bereitgestellte Schnittstellennamen werden im VM-Manager nicht mehr als HTML interpretiert.
- Basis-Distro-Pakete mit Sicherheitskorrekturen aktualisiert; CVE-Hinweise sind bei den entsprechenden Paketaktualisierungen unten aufgeführt.

### Container / Docker

- Fix: Der Docker-Manager entfernt das gemeinsame Standardsymbol nicht mehr, wenn ein Container ohne Symbol entfernt oder aktualisiert wird.

### Speicher

- Fix: Kopier- und Verschiebevorgänge im Dateimanager konnten aufgrund eines Symlink-Tiefenfehlers fehlschlagen.
- Fix: shfs-Deadlocks wurden verhindert, wenn gleichzeitige Datei-Lock-Anfragen den FUSE-Worker-Pool erschöpfen.
- Fix: Ein shfs-Assertion-Fehler wurde verhindert, der dazu führen konnte, dass `/mnt/user` nicht verfügbar wurde.

### WebGUI / System

- Neu: Konfigurieren Sie die physische Einschalttaste unter Einstellungen > Energieoptionen so, dass das System heruntergefahren, neu gestartet oder keine Aktion ausgeführt wird.
- Fix: Die Auslastungsanzeige des gestoppten Arrays wurde korrigiert und die Statistiken für verwendet/frei für ein eingehängtes Boot-Gerät wurden wiederhergestellt, wenn das Array gestoppt ist.

### Netzwerk / Hardware

- Neu: Kernel-Treiber und Firmware für zusätzliche drahtlose Intel-, MediaTek- und Realtek-Hardware hinzugefügt.

### Virtualisierung

- Neu: Kernelunterstützung für Hyper-V-Komponenten für Grafik, Ballooning, Speicher, Tastatur, VMBus, Utility und VSOCK hinzugefügt.

### Unraid API

- Aktualisiere [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.4 - siehe Änderungen.

### Linux-Kernel

- Linux-Kernel: Update auf 6.18.52-Unraid.
