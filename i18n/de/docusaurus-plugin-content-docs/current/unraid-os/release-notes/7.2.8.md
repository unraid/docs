# Version 7.2.8-rc.1 2026-07-23

Unraid OS 7.2.8-rc.1 ist eine Wartungsversion des Release Candidates, die sich auf sicherheitsrelevante Basis-Paketaktualisierungen, Linux-Kernel 6.12.96-Unraid, Unraid API 4.36.1, Docker, ZFS und eine erweiterte Intel-Wireless-Firmware-Abdeckung konzentriert.

## Upgrade

Für schrittweise Anweisungen siehe [Unraid aktualisieren](/unraid-os/system-administration/maintain-and-update/upgrading-unraid/). Fragen zu Ihrer [Lizenz](/unraid-os/troubleshooting/licensing-faq/)?

## Bekannte Probleme

- Es wurden keine neuen versionsspezifischen bekannten Probleme identifiziert. Weitere bekannte Probleme finden Sie in den Release Notes zu Unraid OS 7.2.7.

## Anmerkungen

- Kernel-gekoppelte ZFS-Module haben die Kompatibilitätsprüfungen für 6.12.96-Unraid bestanden.

## Rückschritte

- Keine neuen Rollback-Warnungen. Lesen Sie die Rollback-Hinweise für Unraid OS 7.2.7, bevor Sie ein Downgrade durchführen.

## Änderungen gegenüber Unraid OS 7.2.7

### Sicherheit

- Sicherheit: Enthält sicherheitsrelevante Aktualisierungen über Basispaket-Binärpakete hinweg. Detaillierte CVE-Anmerkungen zu den Paketen sind unter "Aktualisierungen der Basis-Distribution" aufgeführt.
- Sicherheit: Eine Schwachstelle zur Befehlsausführung durch Pfadtraversierung in der WebGUI `update.php`, CVE-2026-3838, wurde behoben.

### Netzwerk / Hardware

- Neu: 304 Intel iwlwifi-Firmwaredateien hinzugefügt.

## Docker

- Docker-VLAN-Autonetze können auf das konfigurierte Docker-Gateway zurückfallen, damit Container die ausgehende Konnektivität behalten.

### Linux-Kernel

- Linux-Kernel: Aktualisierung auf 6.12.96-Unraid.
