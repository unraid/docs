# Version 7.3.2-rc.1 2026-07-02

Unraid OS 7.3.2-rc.1 aktualisiert den Linux-Kernel, Docker, die Unraid API und eine breite Palette an Basis-Paketen, mit sicherheitsrelevanten Aktualisierungen für zentrale Netzwerk-, Web-, Speicher- und Verschlüsselungskomponenten. Diese Veröffentlichung umfasst außerdem Aktualisierungen für ZFS und QEMU sowie Verbesserungen bei Speicher, Docker und dem System.

## Upgrade

Für schrittweise Anweisungen siehe [Unraid aktualisieren](/unraid-os/system-administration/maintain-and-update/upgrading-unraid/). Fragen zu Ihrer [Lizenz](/unraid-os/troubleshooting/licensing-faq/)?

## Bekannte Probleme

- Für diese Version sind keine neuen versionsspezifischen bekannten Probleme dokumentiert.

## Anmerkungen

- Die Veröffentlichung umfasst Paketaktualisierungen für Kernservices und Bibliotheken, die vom Betriebssystem verwendet werden, darunter Docker, OpenSSH-Unterstützungsbibliotheken sowie Zertifikats- und Netzwerkkomponenten.

## Rückschritte

- Lesen Sie die Hinweise zum Rollback für [Unraid OS 7.3.1](/unraid-os/release-notes/7.3.1/) vor dem Downgrade von dieser Veröffentlichung.
- Diese Veröffentlichung aktualisiert den Kernel, ZFS, Docker und die Unraid API. Überprüfen Sie vor dem Rollback die Kompatibilität.

## BRECHENDE ÄNDERUNGEN

- Für diese Veröffentlichung sind keine Breaking Changes dokumentiert.

## Änderungen gegenüber [Unraid OS 7.3.1](/unraid-os/release-notes/7.3.1/)

### Sicherheit

- Sicherheit: bind, dnsmasq, libarchive, libidn, net-tools, nginx, openssl, shadow, sqlite und xorg-server wurden für Sicherheitskorrekturen aktualisiert. dnsmasq, nginx, openssl, net-tools und sqlite enthalten aufgeführte CVE-Abdeckung.
- Fix: CVE-2026-3838.

### Container / Docker

- Verbesserung: Docker auf 29.5.3-1_LT aktualisiert.
- Fix: VLAN-Docker-Netzwerke stellen das Gateway- und Standardrouten-Handling nach dem Docker-29-Upgrade jetzt zuverlässiger wieder her, sodass betroffene Container ihre ausgehende Verbindung und Inter-VLAN-Konnektivität wiedererlangen können.

### Speicher

- Verbesserung: ZFS auf 2.4.3_6.18.37_Unraid-1_LT aktualisiert.
- Fix: Das Entfernen eines Boot-Pool-Geräts funktioniert wieder korrekt, statt in manchen gespiegelt konfigurierten Boot-Pool-Setups mit einem GUI-Fehler zu scheitern.
- Fix: Beim Ersetzen eines fehlenden Boot-Pool-Geräts bleibt in manchen Port-Tausch-Szenarien kein veraltetes fehlendes Mirror-Mitglied mehr zurück.
- Fix: Das Formatieren oder Löschen eines Pools führt die GUI in einem bestimmten `sda`-Benennungs-Sonderfall nicht mehr zum Absturz.
- Fix: Korrigierte Btrfs-RAID1-Poolgrößen- und Belegungsanzeige im Dashboard für Geräte mit unterschiedlichen Größen.

### WebGUI / System

- Verbesserung: dynamix.unraid.net auf 4.35.1 aktualisiert.
- Verbesserung: Basissystempakete einschließlich bash, ca-certificates, curl, git, pkgtools, rsync, util-linux und anderer Kernkomponenten aktualisiert.
- Fix: Die Controller-Ansichten in System Devices zeigen jetzt die richtigen Laufwerke an, statt manchmal nicht zugehörige Geräte einzuschließen.
- Fix: Die mDNS-Dienstsuche kann sich nach einem vorübergehenden Netzwerkausfall zuverlässiger wieder erholen.

### Netzwerk / Hardware

- Verbesserung: cifs-utils, iproute2, libnvme und wireless-regdb aktualisiert.
- Neu: libcbor, libfido2 und libmaxminddb hinzugefügt.
- Verbesserung: Intel-iGPU-SR-IOV-Steuerelemente werden jetzt ausgeblendet, sofern das erforderliche Plugin nicht installiert ist, wodurch nicht anwendbare Einstellungen vermieden werden.

### Virtualisierung

- Verbesserung: QEMU auf 10.2.3-1_SBo_LT aktualisiert.
- Verbesserung: genauere Meldung der PCI-Link-Geschwindigkeit für Intel-Arc-GPUs in System Devices, was beim Prüfen von Passthrough-Hardware hilft.
- Verbesserung: Der VM-Netzwerkquellen-Auswahlschalter ist jetzt breiter und natürlicher sortiert, sodass lange oder nummerierte Netzwerknamen leichter zu überblicken sind.
- Fix: VM-Kontextmenüs bleiben jetzt sichtbar, wenn sie nahe am unteren Rand der Seite geöffnet werden, statt teilweise außerhalb des Bildschirms gerendert zu werden.
- Fix: Die VM-Auslastungsanzeige stimmt besser mit der tatsächlichen CPU-Aktivität des Gasts überein, statt bei nicht zusammenhängenden Dateiübertragungen eine überhöhte Auslastung anzuzeigen.
- Fix: Eine veraltete Neustartwarnung wurde aus den VM-Einstellungen entfernt, wenn PCI-Optionen aktiviert sind.

### Unraid API

- Unraid API auf dynamix.unraid.net 4.35.1 aktualisieren.

### Linux-Kernel

- Linux-Kernel: auf 6.18.37-Unraid aktualisiert.
