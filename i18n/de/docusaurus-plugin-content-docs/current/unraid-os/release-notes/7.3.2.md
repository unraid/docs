# Version 7.3.2 2026-07-08

Unraid OS 7.3.2 ist eine Sicherheits- und Bugfix-Version einschließlich Linux-Kernel 6.18.38, Korrekturen für Docker-VLAN-Netzwerke, Speicher- und Boot-Pool-Korrekturen, Korrekturen an der Virtualisierungsoberfläche, Unraid API 4.35.1 und mehreren Aktualisierungen von Basispaketen.

Empfohlen für alle Benutzer.

## Upgrade

Für Schritt-für-Schritt-Anleitungen siehe [Unraid aktualisieren](\<https:///unraid-os/updating-unraid/>). Fragen zu Ihrer [Lizenz](\<../../unraid-os/troubleshooting/licensing-faq.mdx#license-types--features>)?

## Änderungen gegenüber Unraid OS 7.3.1

### Sicherheit

- Sicherheit: Eine Schwachstelle zur Befehlsausführung durch Pfadtraversierung in der WebGUI `update.php`, CVE-2026-3838, wurde behoben.
- Sicherheit: Enthält Sicherheitskorrekturen für Basispakete mit CVE-Abdeckung für mehrere Komponenten; Details zu den CVEs auf Paketebene sind in den Basis-Distribution-Updates aufgeführt.

### Container / Docker

- Fix: Docker-VLAN-Auto-Netzwerke können auf das konfigurierte Docker-Gateway zurückfallen, sodass Container die ausgehende Konnektivität behalten.
- Verbesserung: Die Ladeleistung des Docker-Tabs wurde verbessert, indem synchrones I/O aus dem Render-Pfad des Docker-Tabs herausgehalten wird, basierend auf einem Community-Beitrag von [TSpader ](\<https://github.com/tspader>) (vielen Dank!)

### Speicher

- Fix: Beim Ersetzen des Boot-Pools bleibt im betroffenen Ersatzfall kein veraltetes fehlendes Mirror-Mitglied mehr zurück.
- Fix: Das Entfernen eines Boot-Pool-Geräts löst nicht mehr die Regression aus, die den Vorgang fehlschlagen lassen konnte.
- Fix: Beim Formatieren eines Pool-Geräts, dessen Name sich mit dem eines Boot-Geräts überschneidet, wird keine falsche Assertion wegen eines ungültigen Ziels mehr ausgelöst.
- Fix: Die Anzeige von Cache-Pool-Größe und -Auslastung im Dashboard wurde für Btrfs-RAID1-Pools korrigiert.

### WebGUI / System

- Neu: Es wurde eine Monitorstatus-Ausgabe für Plugins zur Panel-Anzeige hinzugefügt, die LED- und LCD-Status verwenden.
- Fix: Beim Speichern des Syslogs beim Herunterfahren und Neustart wird nun `/boot/logs` erstellt, bevor Syslog-Dateien geschrieben werden.
- Fix: Die Auflistungen der Controller unter Systemgeräte enthalten in betroffenen Fällen keine nicht zusammenhängenden Geräte mehr.
- Fix: Internes Booten mit Flash-Lizenzierung behandelt vorübergehende Zurücksetzungen des USB-Lizenzgeräts besser.

### Netzwerk / Hardware

- Fix: Das Avahi/mDNS-Update kann den Daemon nach einem vorübergehenden Netzwerkverlust wieder starten.
- Fix: Die PCI-Geschwindigkeitsanzeige für Intel-GPUs wurde korrigiert.
- Verbesserung: Steuerungen für Intel-iGPU-SR-IOV werden nur angezeigt, wenn das unterstützende Plugin installiert ist.

### Virtualisierung

- Fix: Die VM-CPU-Auslastung meldet nicht mehr eine hohe Auslastung, die durch nicht zusammenhängende Host-Aufgaben verursacht wurde.
- Fix: Die Positionierung des Kontextmenüs der VM wurde korrigiert.
- Verbesserung: Die Einträge des Dropdowns "VM Network Source" sind sortiert, und das Steuerelement ist breiter, um das Durchsehen zu erleichtern.
- Fix: Eine veraltete Meldung im Neustart-Banner der VM wurde entfernt, wenn VM-PCI-Optionen aktiviert sind.

### Unraid API

- Aktualisiere die Unraid-API auf [dynamix.unraid.net 4.35.1](\<https://github.com/unraid/api/releases/tag/v4.35.1>).

### Linux-Kernel

- Linux-Kernel: Aktualisierung auf 6.18.38-Unraid.
  CONFIG_USB_AUTOSUSPEND_DELAY=-1
