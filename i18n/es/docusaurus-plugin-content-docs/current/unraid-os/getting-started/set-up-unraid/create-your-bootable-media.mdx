# Crear una unidad USB de Unraid

Unraid OS puede arrancar desde una unidad flash USB o, en Unraid 7.3 y posteriores, desde un dispositivo de arranque interno compatible. Esta página explica cómo crear una unidad USB para un servidor nuevo. Puedes seguir usando la unidad USB para el arranque desde flash, o usarla para iniciar el servidor antes de seleccionar el arranque interno durante la incorporación. Consulta las [Preguntas frecuentes sobre arranque interno (7.3+)](./internal-boot-faq.mdx) para obtener más información.

Para el arranque USB, utiliza una unidad flash USB de alta calidad de cualquier tamaño con un %%GUID|guid%% único. El %%GUID|guid%% identifica el dispositivo USB para la licencia.

:::tip[Choosing medio de arranque confiable]

Para el arranque USB, elige una unidad flash USB de calidad con un %%GUID|guid%% único. Consulta [Cómo elegir un dispositivo de arranque](#choosing-a-usb-flash-drive) en la sección de instalación manual para obtener orientación sobre medios fiables y unidades falsificadas.

Si planeas usar el arranque interno, aun así necesitas esta unidad USB para iniciar un servidor nuevo. Después del primer arranque, el asistente de incorporación te permite elegir entre arranque desde flash o arranque interno.

:::

## Método de instalación automática {/* #automated-install-method */}

El Unraid USB Creator prepara la unidad, descarga o usa la imagen de Unraid OS seleccionada y escribe la imagen en la unidad USB. Use este método para la mayoría de las instalaciones nuevas.

:::caution[Writing borra la unidad USB]

La acción **WRITE** borra la unidad USB seleccionada. Desconecte otras unidades extraíbles antes de empezar. Si está reemplazando un dispositivo de arranque de Unraid existente, [haga una copia de seguridad primero](../../system-administration/secure-your-server/secure-your-boot-drive.mdx).

:::

### Descargar el USB Creator

Descargue e instale el USB Creator para su ordenador:

- [Windows](https://releases.unraid.net/dl/stable/usb-creator.exe)
- [macOS](https://releases.unraid.net/dl/stable/usb-creator.dmg)
- [Linux](https://releases.unraid.net/dl/stable/usb-creator.appimage)

Inserta la unidad USB en tu ordenador. Cierra cualquier aplicación que tenga la unidad abierta.

### Seleccionar idioma

1. Abra el Creador de USB.
2. Seleccione su idioma.
3. Seleccione **NEXT**.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator language
  selection](/img/unraid-os/getting-started/create-unraid-usb/01-00-language-selection.png)
</div>

### Seleccionar una versión de Unraid OS

1. Seleccione la versión de Unraid OS que desea instalar.
2. Seleccione **NEXT**.

Para un servidor de producción, seleccione la versión estable más reciente. Use una imagen de desarrollo solo cuando esté probando esa imagen.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator operating system
  selection](/img/unraid-os/getting-started/create-unraid-usb/02-01-os-selection.png)
</div>

### Seleccione la unidad USB

1. Seleccione la unidad USB que desea preparar.
2. Compruebe el nombre de la unidad, el tamaño y el %%GUID|guid%%.
3. Mantenga seleccionada **Exclude system drives**.
4. Seleccione **NEXT**.

El %%GUID|guid%% debe ser único para que la unidad funcione con la licencia de Unraid. No seleccione una unidad que contenga datos que desee conservar.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator storage device
  selection](/img/unraid-os/getting-started/create-unraid-usb/03-02-storage-selection.png)
</div>

### Configurar el nuevo servidor (opcional)

La sección **Customisation** le permite configurar estas opciones antes del primer arranque:

- **Server name** establece el nombre que Unraid usa en su red.
- **Wi-Fi** guarda la configuración de la red Wi-Fi para un servidor que usa una conexión inalámbrica.
- **Network** establece el direccionamiento automático con DHCP o una dirección IP estática.

Omisita estas secciones si desea configurar el servidor después del primer arranque. Si configura Wi-Fi, trate la unidad USB como si contuviera la contraseña de Wi-Fi hasta que el servidor se inicie por primera vez.

### Revisar y escribir la imagen

1. Revise el sistema operativo y el dispositivo de almacenamiento en el resumen.
2. Asegúrese de que el dispositivo de almacenamiento sea la unidad USB que desea borrar.
3. Seleccione **WRITE**.

El Creador de USB escribe la imagen seleccionada en la unidad.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator write
  summary](/img/unraid-os/getting-started/create-unraid-usb/04-03-write-summary.png)
</div>

### Finalice la configuración de la USB

Cuando finalice la escritura:

1. Revise las opciones mostradas en la pantalla de finalización.
2. Seleccione **FINISH**.
3. Retire la unidad USB solo después de que el Creador de USB la expulse.

Los sistemas UEFI pueden arrancar desde la unidad sin ningún paso adicional. En un sistema antiguo solo BIOS, ejecute el script de arranque desde la raíz de la unidad USB:

- **Windows:** Haga clic derecho en `make_bootable.bat` y seleccione **Ejecutar como administrador**.
- **macOS:** Haga doble clic en `make_bootable_mac` e introduzca su contraseña de administrador cuando se le solicite.
- **Linux:** Desmonte la unidad USB. Luego ejecute `sudo bash ./make_bootable_linux`.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![USB Creator write
  complete](/img/unraid-os/getting-started/create-unraid-usb/05-04-write-complete.png)
</div>

### Arranque el servidor desde la nueva unidad USB

1. Inserte la unidad USB preparada en el servidor.
2. Abra la configuración BIOS o UEFI del servidor.
3. Configure la unidad USB como el primer dispositivo de arranque.
4. Guarda la configuración de la BIOS y reinicia el servidor.

En Unraid 7.3 y posteriores, cuando Unraid se inicia por primera vez, el asistente de incorporación te permite elegir el método de arranque:

- **Arranque desde flash** mantiene Unraid en la unidad USB.
- **Arranque interno** mueve Unraid a un dispositivo de arranque interno compatible o a dos dispositivos de arranque internos espejados.

Para obtener detalles sobre el arranque interno, consulta la sección [Incorporación](./deploy-and-configure-unraid-os.mdx#onboarding) y las [Preguntas frecuentes sobre arranque interno (7.3+)](./internal-boot-faq.mdx).

Después de que se inicie Unraid OS, continúe con [Implementar y configurar Unraid OS](./deploy-and-configure-unraid-os.mdx).

## Solución de problemas

### La unidad USB no aparece

1. Desconecte la unidad USB.
2. Cierre el Creador de USB.
3. Conecte la unidad USB directamente a la computadora.
4. Abra de nuevo el Creador de USB.

El Creador de USB de Unraid solo enumera dispositivos de almacenamiento USB para este flujo de trabajo. Asegúrese de que su computadora detecte la unidad antes de abrir el Creador de USB.

### El servidor no arranca desde la unidad USB

1. Abra la configuración BIOS o UEFI.
2. Asegúrese de que la unidad USB sea el primer dispositivo de arranque.
3. Para un sistema solo BIOS, ejecute el script `make_bootable` específico de la plataforma descrito en [Finalizar la configuración de la USB](#finish-the-usb-setup).
4. Guarde la configuración y reinicie el servidor.

Si elegiste el arranque interno y el servidor no arranca después de la configuración inicial, mueve el dispositivo de arranque interno seleccionado al principio del orden de arranque de la BIOS/UEFI. Si el servidor sigue sin arrancar, usa el [método de instalación manual](#manual-install-method) para preparar de nuevo la unidad USB.

### La unidad USB no puede registrar una licencia

El arranque por USB y la licencia USB requieren un %%GUID|guid%% único. Si la unidad no tiene un %%GUID|guid%% único, usa otra unidad flash USB. Si usas el arranque interno con licencias basadas en TPM, consulta las [Preguntas frecuentes sobre arranque interno (7.3+)](./internal-boot-faq.mdx#internal-boot-flash-license).

## Método de instalación manual {/* #manual-install-method */}

El método de instalación manual es para situaciones en las que el USB Creator no está disponible o es incompatible con tu hardware. Este método te da control sobre el proceso de formateo y configuración.

### Elegir un dispositivo de arranque {/* #choosing-a-usb-flash-drive */}

<FlashDriveGuidance />

### Prepara tu dispositivo USB {/* #prepare-your-usb-device */}

1. Conecta la unidad USB que estás preparando como dispositivo de arranque.
2. Formatearlo a FAT32 (**no** ex-FAT o NTFS).
3. Establece la etiqueta de volumen a `UNRAID` (sensible a mayúsculas, todo en mayúsculas).

:::important

En Windows, las herramientas de formateo integradas no pueden formatear unidades de más de 32 GB como FAT32. De forma predeterminada usan exFAT. Para una unidad más grande, utiliza una herramienta compatible con FAT32 como [Rufus](https://rufus.ie/en/).

:::

### Descargar y extraer

1. Ve al [Archivo de Descargas de Unraid](../../download_list.mdx) y descarga el archivo ZIP de la versión elegida.
2. Extrae el contenido del ZIP al dispositivo USB.
3. Confirma que los archivos han sido copiados.

### Haz el dispositivo USB arrancable

:::note

Esta sección solo es necesaria para habilitar el arranque heredado. Si estás configurando para el arranque UEFI, no es necesario ejecutar estos scripts.

:::

**Windows 7 o posterior:**

**Windows 7 o posterior:**

- Haga clic derecho en `make_bootable` y seleccione **Ejecutar como administrador**.

**Mac:**

- Haga doble clic en `make_bootable_mac` e ingrese su contraseña de administrador.

**Linux:**

- Copie `make_bootable_linux` a su disco duro.
- Desmonta la unidad USB.
- En la terminal, ejecute:

  ```bash
  sudo bash ./make_bootable_linux
  ```

:::note

La unidad USB puede desaparecer y reaparecer brevemente varias veces durante este proceso. Esto es normal.

:::
