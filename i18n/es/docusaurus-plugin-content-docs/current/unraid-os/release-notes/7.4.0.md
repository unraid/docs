# Versión 7.4.0-beta.2 2026-09-03

Unraid OS 7.4.0-beta.2 agrega soporte para varias redes de Docker y controles de memoria, administración compartida de tareas en segundo plano, mejoras en la copia de seguridad del dispositivo de arranque, comportamiento configurable del botón de encendido, **seguimiento del progreso de mover**, y compatibilidad ampliada con hardware e Hyper-V. También mejora la comprobación transitoria de licencias, actualiza el kernel de Linux a 6.18.47-Unraid y la API de Unraid a 4.37.3, e incluye actualizaciones de seguridad de paquetes principales (las mismas actualizaciones de los paquetes principales que en 7.3.3-rc.1)

## Correcciones / funciones de 7.4.0-beta.1

- Nuevo: ahora está disponible el seguimiento del progreso y el estado de Mover. Debido a un problema conocido, vaya a ***Ajustes → Programador → Ajustes de Mover***, establezca **Progreso de Mover** en **Deshabilitado** y seleccione **Aplicar**. Luego establezca **Progreso de Mover** en **Habilitado** y seleccione **Aplicar** de nuevo.
- Corrección: Opciones de energía conserva las pestañas Modo de energía y Botón de encendido cuando está instalado el complemento Dynamix System Buttons.
- Corrección: Opciones de energía ya no muestra la advertencia de virtualización en servidores bare metal.

## Cambios frente a [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Seguridad

- Seguridad: los componentes principales incluyen actualizaciones que corrigen CVE notificadas y otras correcciones de seguridad.
- Seguridad: las integraciones de notificaciones ahora verifican el certificado de la API pública en lugar de omitir la validación de certificados.

### Contenedores / Docker

- Nuevo: Las plantillas de contenedores de Docker admiten varias redes personalizadas, y los adjuntos de red adicionales se conservan cuando los contenedores se recrean o actualizan.
- Nuevo: los formularios de añadir/editar Docker muestran una vista previa en vivo de la URL del icono del contenedor, con un valor de reserva cuando la URL está vacía o es inválida.
- Nuevo: la Vista avanzada muestra un campo de límite de memoria para los contenedores Docker.

### Almacenamiento

- Nuevo: ahora está disponible el seguimiento del progreso y el estado de Mover. Debido a un problema conocido, vaya a ***Ajustes → Programador → Ajustes de Mover***, establezca **Progreso de Mover** en **Deshabilitado** y seleccione **Aplicar**. Luego establezca **Progreso de Mover** en **Habilitado** y seleccione **Aplicar** de nuevo.
- Nuevo: la compatibilidad con la ubicación de las unidades puede usar controladores compatibles con SGPIO/IBPI cuando SES no está disponible.
- Corrección: una matriz detenida ahora muestra el estado sin conexión y el texto del sistema de archivos en lugar de una utilización del 100%.
- Corrección: al pulsar Entrar en los campos de frase de contraseña de la matriz cifrada ahora se inicia la matriz cuando la validación de la frase de contraseña se realiza correctamente.

### WebGUI / Sistema

- Nuevo: Las operaciones en segundo plano de plugins, Docker y máquinas virtuales pueden ponerse en cola y gestionarse desde una bandeja de tareas compartida, con recuperación en primer plano desde cualquier pestaña del navegador.
- Nuevo: las copias de seguridad del dispositivo de arranque se ejecutan como tareas en segundo plano con compresión seleccionable, progreso en vivo y descarga automática al completarse.
- Nuevo: configure el botón físico de encendido en Ajustes → Ajustes de energía → Botón de encendido → **Botón físico de encendido**, con las acciones Apagar, Reiniciar y No hacer nada.
- Mejora: Las hojas de tareas en primer plano ahora se adaptan al área visible del navegador manteniendo el ancho guardado y el comportamiento móvil.
- Mejora: las comprobaciones de la licencia ahora reintentan para gestionar la disponibilidad transitoria y las condiciones de red.
- Corrección: Opciones de energía conserva las pestañas Modo de energía y Botón de encendido cuando está instalado el complemento Dynamix System Buttons.
- Corrección: Opciones de energía ya no muestra la advertencia de virtualización en servidores bare metal.
- Corrección: La página de plugins instalados ahora comprueba las actualizaciones de forma independiente, de modo que un plugin lento o inaccesible no hace que toda la página espere.
- Corrección: los fallos de validación de actualización de complementos siguen siendo visibles con una explicación, en lugar de informar silenciosamente de que el complemento está actualizado.
- Corrección: La limpieza posterior al hook de post del Gestor de plugins ahora se ejecuta cuando los mensajes de error contienen caracteres de la shell.

### Red / Hardware

- Nuevo: se añadieron módulos del kernel y firmware para los adaptadores inalámbricos Realtek RTW88 8812A, 8814A y 8821A, además de módulos del kernel para los adaptadores USB RTW89 8851BU y 8852BU.
- Nuevo: se añadió compatibilidad con controladores adicionales de PlayStation, Nintendo, Steam y Logitech, junto con códecs de audio adicionales.
- Mejora: los valores predeterminados de red ahora siguen la base de `/etc/sysctl.conf` de Fedora, incluido el control de congestión TCP CUBIC y `fq_codel` como programador de paquetes predeterminado.

### Virtualización

- Nuevo: se añadió compatibilidad del kernel con la virtualización Hyper-V, incluidos los módulos de almacenamiento, balloon, teclado y VMBus de Hyper-V.
- Corrección: El inicio de la VM ya no registra una advertencia de obsolescencia de PHP cuando la búsqueda de ubicación de QEMU no produce salida.

### API de Unraid

- Actualiza [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.3 - ver cambios.

### Núcleo de Linux

- Kernel de Linux: actualización a 6.18.47-Unraid.
