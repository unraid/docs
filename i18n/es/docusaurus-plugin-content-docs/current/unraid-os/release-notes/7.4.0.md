# Versión 7.4.0-beta.1 2026-08-14

Unraid OS 7.4.0-beta.1 es una versión beta con actualizaciones de seguridad en los paquetes principales, el kernel de Linux 6.18.44, mejoras de Docker y WebGUI, controles ampliados de red de contenedores y de memoria, nuevas opciones de gestión de tareas y del botón de encendido, y compatibilidad añadida con hardware inalámbrico Realtek RTW88.

## Actualización

Para instrucciones paso a paso, consulta [Actualización de Unraid](/unraid-os/updating-unraid/). ¿Tienes preguntas sobre tu licencia? Revisa las [Preguntas frecuentes sobre la licencia](/unraid-os/troubleshooting/licensing-faq/).

## Problemas conocidos

- No se documentan nuevos problemas conocidos específicos de esta versión. Para los problemas documentados anteriormente, consulte las [notas de la versión de Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/).

## Cambios frente a [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Seguridad

- Seguridad: Las actualizaciones de paquetes principales incluyen correcciones de seguridad para bind, libXfont2, libarchive, libssh, openssh, p11-kit, php, samba, wpa_supplicant y xorg-server.
- Seguridad: Las integraciones de notificaciones ahora usan solicitudes verificadas por certificado para la API pública.

### Contenedores / Docker

- Nuevo: Las plantillas de contenedores de Docker admiten varias redes personalizadas, y los adjuntos de red adicionales se conservan cuando los contenedores se recrean o actualizan.
- Nuevo: Los formularios de Añadir/Editar de Docker ahora muestran una vista previa en vivo de la URL del icono del contenedor, con un valor de reserva cuando la URL está vacía o es inválida.
- Nuevo: La Vista avanzada ahora muestra un campo de límite de memoria para los contenedores de Docker.

### Almacenamiento

- Corrección: Al pulsar Intro en los campos de frase de contraseña del array cifrado ahora se inicia el array cuando la validación de la frase de contraseña tiene éxito.
- Corrección: El Gestor de archivos mantiene los recursos compartidos exclusivos en la vista `/mnt/user/\<share>` en lugar de cambiar a la ruta subyacente del disco o del pool.

### WebGUI / Sistema

- Nuevo: Las operaciones en segundo plano de plugins, Docker y máquinas virtuales pueden ponerse en cola y gestionarse desde una bandeja de tareas compartida, con recuperación en primer plano desde cualquier pestaña del navegador.
- Nuevo: La página del dispositivo de arranque ahora permite descargar una copia de seguridad directamente o guardarla en el servidor, con seguimiento del progreso.
- Nuevo: El comportamiento del botón físico de encendido se puede configurar para Apagar, Reiniciar o No hacer nada. Vaya a Ajustes → Opciones de energía para configurarlo.
- Mejora: Las hojas de tareas en primer plano ahora se adaptan al área visible del navegador manteniendo el ancho guardado y el comportamiento móvil.
- Mejora: Las comprobaciones de licencia ahora reintentan si la licencia no está disponible en el disco durante un minuto; esto permite desconexiones transitorias de la unidad de arranque
- Mejora: El encabezado consolidado ahora gestiona el diseño del encabezado y la visualización del uso del array, solucionando el solapamiento del encabezado en móviles.
- Corrección: La página de plugins instalados ahora comprueba las actualizaciones de forma independiente, de modo que un plugin lento o inaccesible no hace que toda la página espere.
- Corrección: Los fallos de validación de actualización de plugins ahora permanecen visibles con una explicación en lugar de informar silenciosamente de que el plugin está actualizado, incluidos los fallos causados por un sistema de archivos raíz lleno.
- Corrección: La limpieza posterior al hook de post del Gestor de plugins ahora se ejecuta cuando los mensajes de error contienen caracteres de la shell.

### Red / Hardware

- Nuevo: Se han añadido módulos del kernel y firmware para adaptadores inalámbricos Realtek RTW88 8812A, 8814A y 8821A.

### Virtualización

- Corrección: El inicio de la VM ya no registra una advertencia de obsolescencia de PHP cuando la búsqueda de ubicación de QEMU no produce salida.

### API de Unraid

- Actualiza [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.1 - [ver cambios](\<https://github.com/unraid/api/releases>).

### Núcleo de Linux

- Núcleo de Linux: actualización a 6.18.44-Unraid.
