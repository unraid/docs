# Versión 7.2.9 2026-10-23

Esta versión de mantenimiento incluye correcciones de seguridad de PHP, una actualización de la API de Unraid de 4.36.1 a 4.37.7 y actualizaciones que abordan los certificados CA comprometidos mencionados en el [informe de compromiso de certificados de eMudhra](<https://unit42.paloaltonetworks.com/emudhra-certificate-compromise/>). La versión del kernel no ha cambiado desde 7.2.8. **Recomendamos actualizar a la versión estable más reciente de Unraid OS 7.3.x** por su kernel más nuevo y sus actualizaciones de seguridad de paquetes más amplias.

## Actualización

Para instrucciones paso a paso, consulta [Actualización de Unraid](/unraid-os/updating-unraid/). ¿Tienes preguntas sobre tu licencia? Revisa las [Preguntas frecuentes sobre la licencia](/unraid-os/troubleshooting/licensing-faq/).

## Problemas conocidos

Firefox en modo GUI no ha recibido parches contra los certificados CA comprometidos. No utilice este navegador para nada que no sea la configuración de WebGUI.

Consulte las [notas de la versión de Unraid OS 7.2.8](/unraid-os/release-notes/7.2.8/) para conocer otros problemas que puedan seguir aplicándose.

## Deshacer cambios

No se documentan advertencias de reversión ni límites de compatibilidad específicos de esta versión.

## Cambios frente a [Unraid OS 7.2.8](/unraid-os/release-notes/7.2.8/)

### Seguridad

- Seguridad: se actualizó PHP para corregir múltiples CVE.
- Seguridad: se abordaron los certificados de CA comprometidos mencionados en el [informe de Unit 42](<https://unit42.paloaltonetworks.com/emudhra-certificate-compromise/>).

### Unraid API 4.37.7

Actualizado de 4.36.1 a 4.37.7. Se actualizó el entorno de ejecución Node.js incluido de la API a 22.23.4; esto resuelve el problema de compromiso de certificados de Node. Consulte la [comparación completa de la API](<https://github.com/unraid/api/compare/v4.36.1...v4.37.7>).

### Aviso de seguridad: vulnerabilidades potenciales adicionales

**Recomendamos actualizar a la última versión estable de Unraid OS 7.3.x** por su kernel más reciente y sus actualizaciones de seguridad de paquetes más amplias. Actualizar solo a 7.2.9 **no debe interpretarse** como una solución para todos los hallazgos potenciales.

Unraid OS 7.2.9 es una versión de mantenimiento específica que incluye correcciones de seguridad de PHP, actualizaciones de certificados CA y correcciones y refuerzo de seguridad de la API de Unraid. **No** incluye las actualizaciones de seguridad del kernel ni de los paquetes de la distribución más amplias que están disponibles en versiones más recientes.

A fecha de 23 de octubre de 2026, los avisos de paquetes upstream identifican 115 CVE potenciales asociados a las versiones de paquetes incluidas, agrupados de la siguiente manera:

- **Transferencias de red y DNS — 42:** curl (30) y BIND (12).
- **Cifrado y conexiones seguras — 25:** OpenSSL (23), libssh (1) y p11-kit (1).
- **Componentes gráficos — 29:** xorg-server (11), libXi (8), libX11 (4), libXfont2 (2), libXtst (2), libXpm (1) y libXrender (1).
- **Compartición de archivos — 6:** Samba (6).
- **Otras bibliotecas y utilidades del sistema — 10:** libpcap (5), util-linux (4) y libpng (1).

Avisos de seguridad adicionales cubren libarchive, libxml2, OpenSSH, PCRE2, rsync, wpa_supplicant y xz sin listar identificadores CVE específicos. Las comprobaciones separadas de bases de datos de vulnerabilidades identifican 55 CVE potenciales de paquetes que pueden solaparse con los 115 anteriores; estos totales no deben sumarse.

Las versiones más recientes del kernel upstream también contienen correcciones de seguridad que no se incluyen en 7.2.9.
