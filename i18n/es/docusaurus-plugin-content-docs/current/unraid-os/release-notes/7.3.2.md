# Versión 7.3.2 2026-07-08

Unraid OS 7.3.2 es una versión de seguridad y corrección de errores que incluye el kernel de Linux 6.18.38, correcciones de red Docker VLAN, correcciones de almacenamiento y del pool de arranque, correcciones de la interfaz de usuario de virtualización, Unraid API 4.35.1 y varias actualizaciones de paquetes base.

Recomendado para todos los usuarios.

## Actualización

Para obtener instrucciones paso a paso, consulte [Updating Unraid](\<https:///unraid-os/updating-unraid/>). ¿Tiene preguntas sobre su [licencia](\<../../unraid-os/troubleshooting/licensing-faq.mdx#license-types--features>)?

## Problemas conocidos

- No se registran problemas conocidos nuevos específicos de esta versión. Para los problemas heredados de versiones anteriores, consulte las notas de la versión de [Unraid OS 7.3.1](\<../7.3.1/>).

## Notas

## Cambios respecto a Unraid OS 7.3.1

### Seguridad

- Seguridad: Se corrigió una vulnerabilidad de ejecución de comandos por path traversal en `update.php` de WebGUI, CVE-2026-3838.
- Seguridad: Incluye correcciones de seguridad en paquetes base con cobertura de CVE para múltiples componentes; los detalles de CVE a nivel de paquete se enumeran en las actualizaciones de la distribución base.

### Contenedores / Docker

- Corrección: Las redes automáticas VLAN de Docker ahora pueden recurrir a la puerta de enlace de Docker configurada, de modo que los contenedores mantengan la conectividad de salida.
- Mejora: Se mejoró el rendimiento de carga de la pestaña Docker manteniendo la E/S sincrónica fuera de la ruta de renderizado de la pestaña Docker, a partir de una contribución de la comunidad de [TSpader ](\<https://github.com/tspader>) (¡gracias!).

### Almacenamiento

- Corrección: La sustitución del pool de arranque ya no deja un miembro de espejo ausente obsoleto en el caso de sustitución afectado.
- Corrección: Quitar un dispositivo del pool de arranque ya no desencadena la regresión que podía fallar la operación.
- Corrección: Formatear un dispositivo de pool cuyo nombre se superpone con un dispositivo de arranque ya no desencadena una afirmación de destino no válido falsa positiva.
- Corrección: El informe del tamaño y el uso del pool de caché del panel de control se corrige para los pools Btrfs RAID1.

### WebGUI / Sistema

- Nuevo: Se añadió salida de estado del monitor para los complementos de indicación del panel que usan estado LED y LCD.
- Corrección: El guardado de syslog al apagar y reiniciar ahora crea `/boot/logs` antes de escribir los archivos de syslog.
- Corrección: Los listados de controladores en System Devices ya no incluyen dispositivos no relacionados en los casos afectados.
- Corrección: Internal Boot con Flash Licensing gestiona mejor los restablecimientos transitorios del dispositivo de licencia USB.

### Red / Hardware

- Corrección: La actualización de Avahi/mDNS puede iniciar de nuevo el daemon después de una pérdida transitoria de la red.
- Corrección: Se corrige el informe de velocidad PCI de la GPU Intel.
- Mejora: Los controles SR-IOV de la iGPU Intel solo se muestran cuando está instalado el complemento de compatibilidad.

### Virtualización

- Corrección: El uso de CPU de la VM ya no informa un uso elevado causado por tareas no relacionadas del host.
- Corrección: Se corrige la posición del menú contextual de la VM.
- Mejora: Las entradas del desplegable Source de red de VM se ordenan y el control es más ancho para facilitar la revisión.
- Corrección: Se eliminó un mensaje obsoleto del banner de reinicio de la VM cuando las opciones PCI de la VM están habilitadas.

### API de Unraid

- Actualizar la API de Unraid a [dynamix.unraid.net 4.35.1](\<https://github.com/unraid/api/releases/tag/v4.35.1>).

### Núcleo de Linux

- Kernel de Linux: actualización a 6.18.38-Unraid.
  CONFIG_USB_AUTOSUSPEND_DELAY=-1
