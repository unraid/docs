# Versión 7.3.2-rc.1 2026-07-02

Unraid OS 7.3.2-rc.1 actualiza el kernel de Linux, Docker, la API de Unraid y un amplio conjunto de paquetes base, con actualizaciones relacionadas con la seguridad en los componentes principales de red, web, almacenamiento y cifrado. Esta versión también incluye actualizaciones de ZFS y QEMU, junto con mejoras en almacenamiento, Docker y el sistema.

## Actualización

Para instrucciones paso a paso, consulta [Actualización de Unraid](/unraid-os/system-administration/maintain-and-update/upgrading-unraid/). ¿Tienes preguntas sobre tu [licencia](/unraid-os/troubleshooting/licensing-faq/)?

## Problemas conocidos

- No se documentan problemas conocidos nuevos específicos de esta versión para esta publicación.

## Notas

- La versión incluye actualizaciones de paquetes para servicios y bibliotecas centrales utilizados por el sistema operativo, incluidos Docker, las bibliotecas de compatibilidad de OpenSSH y los componentes de certificados y red.

## Cambios frente a [Unraid OS 7.3.1](/unraid-os/release-notes/7.3.1/)

### Seguridad

- Seguridad: se actualizaron bind, dnsmasq, libarchive, libidn, net-tools, nginx, openssl, shadow, sqlite y xorg-server para correcciones de seguridad. dnsmasq, nginx, openssl, net-tools y sqlite incluyen cobertura de CVE enumeradas.
- Corrección: CVE-2026-3838.

### Contenedores / Docker

- Mejora: Docker se actualizó a 29.5.3-1_LT.
- Corrección: las redes VLAN de Docker ahora restauran el manejo de la puerta de enlace y de la ruta predeterminada de forma más fiable después de la actualización a Docker 29, por lo que los contenedores afectados pueden recuperar la conectividad de salida y entre VLAN.

### Almacenamiento

- Mejora: ZFS se actualizó a 2.4.3_6.18.37_Unraid-1_LT.
- Corrección: la eliminación de un dispositivo del grupo de arranque vuelve a funcionar correctamente en lugar de fallar con un error de la GUI en algunas configuraciones de grupo de arranque espejado.
- Corrección: al reemplazar un dispositivo faltante del grupo de arranque ya no queda un miembro de espejo faltante obsoleto en algunos escenarios de intercambio de puertos.
- Corrección: formatear o borrar un grupo ya no provoca que la GUI se bloquee en un caso límite específico de nomenclatura `sda`.
- Corrección: se corrigió el informe del tamaño y uso de grupos RAID1 de Btrfs en el panel para dispositivos de tamaños mixtos.

### WebGUI / Sistema

- Mejora: dynamix.unraid.net se actualizó a 4.35.1.
- Mejora: se actualizaron los paquetes base del sistema, incluyendo bash, ca-certificates, curl, git, pkgtools, rsync, util-linux y otros componentes principales.
- Corrección: las vistas de controladores en Dispositivos del sistema ahora muestran las unidades correctas en lugar de incluir a veces dispositivos no relacionados.
- Corrección: el descubrimiento de servicios mDNS puede recuperarse con mayor fiabilidad después de una pérdida temporal de red.

### Red / Hardware

- Mejora: se actualizaron cifs-utils, iproute2, libnvme y wireless-regdb.
- Nuevo: se agregaron libcbor, libfido2 y libmaxminddb.
- Mejora: los controles SR-IOV de la iGPU Intel ahora se ocultan a menos que el complemento requerido esté instalado, evitando ajustes que no se pueden aplicar.

### Virtualización

- Mejora: QEMU se actualizó a 10.2.3-1_SBo_LT.
- Mejora: un informe más preciso de la velocidad del enlace PCI para las GPU Intel Arc en Dispositivos del sistema, lo que ayuda al comprobar el hardware de passthrough.
- Mejora: el selector de origen de red de VM ahora es más ancho y está ordenado de forma más natural, lo que facilita revisar nombres de red largos o numerados.
- Corrección: los menús contextuales de VM ahora permanecen visibles cuando se abren cerca de la parte inferior de la página en lugar de mostrarse parcialmente fuera de la pantalla.
- Corrección: el informe de uso de VM coincide mejor con la actividad real de la CPU del invitado en lugar de mostrar un uso inflado durante transferencias de archivos no relacionadas.
- Corrección: se eliminó una advertencia de reinicio desactualizada de los ajustes de VM cuando las opciones PCI están habilitadas.

### API de Unraid

- Actualizar la API de Unraid a dynamix.unraid.net 4.35.1.

### Núcleo de Linux

- Núcleo de Linux: actualización a 6.18.37-Unraid.
