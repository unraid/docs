# Versión 7.3.3-rc.2 2026-09-24

Unraid OS 7.3.3-rc.2 incluye correcciones de seguridad, actualiza el kernel de Linux a 6.18.52, añade acciones configurables para el botón de encendido y compatibilidad de hardware, y corrige problemas de Docker, File Manager y WebGUI.

Esperamos que esta versión pase a estable la próxima semana (la semana del 27 de septiembre).

## Actualización

Para instrucciones paso a paso, consulta [Actualización de Unraid](/unraid-os/updating-unraid/). ¿Tienes preguntas sobre tu licencia? Revisa las [Preguntas frecuentes sobre la licencia](/unraid-os/troubleshooting/licensing-faq/).

## Problemas conocidos

No se enumeran nuevos problemas conocidos específicos de esta versión. Consulte las [notas de la versión de Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) para los problemas documentados previamente.

## Deshacer cambios

Para obtener orientación sobre la reversión y las limitaciones de compatibilidad, consulte las [notas de la versión de Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/).

## Cambios frente a [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Seguridad

- Se reforzó la configuración de la contraseña de root, se validaron las entradas de las solicitudes de OpenTerminal antes de que lleguen a comandos privilegiados y se evitó que los nombres de interfaz proporcionados por el invitado se interpretaran como HTML en VM Manager.
- Se actualizaron paquetes de la distribución base con correcciones de seguridad; las anotaciones de CVE se enumeran junto con las actualizaciones de paquetes correspondientes a continuación.

### Contenedores / Docker

- Corrección: Docker Manager ya no elimina el icono predeterminado compartido cuando se elimina o actualiza un contenedor sin icono.

### Almacenamiento

- Corrección: se corrigió un error por el que las operaciones de copiar y mover en File Manager podían fallar con un error de profundidad de enlace simbólico.
- Corrección: se evitaron bloqueos de shfs cuando solicitudes concurrentes de bloqueo de archivos agotan el grupo de trabajadores de FUSE.
- Corrección: se evitó un fallo de aserción de shfs que podía hacer que `/mnt/user` quedara no disponible.

### WebGUI / Sistema

- Nuevo: configure el botón físico de encendido en Configuración > Opciones de energía para apagar, reiniciar o no hacer nada.
- Corrección: se corrigió la visualización de utilización del array detenido y se restauraron las estadísticas de usado/libre para un Boot Device montado cuando el array está detenido.

### Red / Hardware

- Nuevo: se añadieron controladores del kernel y firmware para hardware inalámbrico adicional de Intel, MediaTek y Realtek.

### Virtualización

- Nuevo: se añadió compatibilidad del kernel para los componentes de Hyper-V de gráficos, ballooning, almacenamiento, teclado, VMBus, utilidad y VSOCK.

### API de Unraid

- Actualizar [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.4 - ver cambios.

### Núcleo de Linux

- Núcleo de Linux: actualización a `6.18.52-Unraid`.
