# Unraid インストーラーを使用する

Unraid インストーラーは対象マシンで起動し、Unraid のインストール用デバイスを準備します。USB フラッシュ起動デバイスまたは内部起動デバイスを作成できます。

対象マシンで直接作業する場合、またはリモートコンソールや仮想コンソール経由で作業する場合にこのツールを使用してください。ラップトップやデスクトップで USB ドライブを作成するほとんどのユーザーには、代わりに [Unraid USB Creator](https://unraid.net/download) を使用してください。

:::note[Unraid 7.3以降]

Unraid インストーラーは、Unraid 7.3 で導入された内部起動ワークフローをサポートしています。

:::

## Unraid インストーラーを使用するタイミング

インストールの手順に合ったツールを選択してください:

| ツール                | 使用する場合                                                              | 実行場所                |
| ------------------ | ------------------------------------------------------------------- | ------------------- |
| Unraid USB Creator | ラップトップまたはデスクトップから USB ドライブを準備したいとき。                                 | お使いのラップトップまたはデスクトップ |
| Unraid Installer   | ターゲットマシンでブートデバイスを準備したい場合、内部ブートを使用したい場合、またはリモート環境や仮想化環境にインストールしたい場合。 | ターゲットマシン            |

USB Creator は USB ドライブを準備している間、サーバーのディスプレイを必要としません。Unraid Installer を使用するには、そこでインストーラーを起動して使用する必要があるため、ターゲットマシンへのディスプレイまたはコンソールアクセスが必要です。

## 開始する前に

次の項目を用意してください:

1. ディスプレイまたはコンソールにアクセスできるターゲットマシン。
2. [最新の安定版 Unraid Installer リリース](https://github.com/unraid/bootable-unraid-installer/releases/latest) からのインストーラーアセット。
3. インストーラー用の USB ドライブまたは仮想メディア。
4. 消去可能なターゲットディスク。
5. オンラインインストーラーを使用し、インストール中に Unraid OS ZIP をダウンロードする必要がある場合はネットワークアクセス。

ターゲットディスクを選択する前に、必要なデータは必ずバックアップしてください。

:::caution[The インストーラーは選択したディスクを消去します

**Create Flash Boot** と **Create Internal Boot** の操作は、選択したターゲットディスクまたはディスクを消去します。操作を確定する前に、ディスク名とサイズを確認してください。

:::

## インストーラーアセットを選択する

リリースページには、ISO ブートパスと USB ブートパス用のアセットが用意されています:

| アセット                                                           | 使用する場合                                                                | ネットワーク要件                                           |
| -------------------------------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------- |
| `unraid-installer-\<version>-online.iso`      | 仮想メディアまたはリモートコンソール経由でインストーラーを起動します。                                   | OS ZIP をダウンロードするときに、ターゲットがリリースサービスへアクセスできる必要があります。 |
| `unraid-installer-\<version>-online.img.zip`  | インストーラーイメージを USB ドライブに書き込みます。IMG ファイルを書き込む前に ZIP を展開してください。           | OS ZIP をダウンロードするときに、ターゲットがリリースサービスへアクセスできる必要があります。 |
| `unraid-installer-\<version>-bundled.img.zip` | インストーラーメディアに OS ZIP をあらかじめ含めたい場合に使用します。IMG ファイルを書き込む前に ZIP を展開してください。 | OS ZIP はすでにインストーラーメディアに含まれています。                    |

ターゲットにネットワークアクセスがある場合は、オンラインインストーラーを使うとダウンロード量を抑えられます。インストール中にターゲットが OS ZIP をダウンロードできない場合は、バンドル版インストーラーを使用してください。

リリースページには、ダウンロード可能なアセット用のチェックサムファイルも用意されています。ダウンロードツールやイメージ書き込みツールがチェックサム検証をサポートしている場合は、それらを使用してください。

## インストーラーを起動する

1. [最新の安定版リリース](https://github.com/unraid/bootable-unraid-installer/releases/latest) からインストーラーアセットをダウンロードします。
2. IMG ZIP をダウンロードした場合は展開します。
3. ターゲットマシンをインストーラーから起動します:
   - ISO を仮想メディアまたは仮想マシンのコンソール経由で接続します。
   - Rufus や Balena Etcher などのディスクイメージ書き込みツールを使って、IMG ファイルを USB ドライブに書き込みます。
4. ターゲットマシンの起動メニューでインストーラーデバイスを選択します。
5. **Unraid ISO Installer** メニューが表示されるまで待ちます。

:::caution[Writing IMG ファイルは USB ドライブを消去します

パーティションではなく、USB デバイス全体を選択してください。インストーラーイメージを書き込む前に、ほかのリムーバブルドライブを取り外してください。

:::

## インストーラーメニューを使用する

インストーラーメニューでは次の操作を利用できます:

| メニュー操作                | 目的                                                                      |
| --------------------- | ----------------------------------------------------------------------- |
| **ZIP をダウンロード**       | Unraid OS ZIP をダウンロードし、ブート操作用に保存します。                                    |
| **内部ブートサイズを設定**       | 内部ブートデバイスを作成する前に、内部ブートプールのサイズを設定します。                                    |
| **内部ブートを作成**          | Unraid 起動用に 1 台または 2 台の内部ディスクを準備します。2 台にすると、ミラーリングされたブートデバイスセットが作成されます。 |
| **フラッシュブートを作成**       | 1 台の USB ディスクを Unraid フラッシュブートデバイスとして準備します。                             |
| **ネットワーク状態を表示**       | インターフェース、IP アドレス、ルートを表示します。                                             |
| **ネットワークを再試行 (DHCP)** | ネットワークインターフェースを起動し、DHCP を再試行します。                                        |
| **Wi-Fi に接続 + DHCP**  | Wi-Fi サポートが利用可能な場合、検出された無線インターフェースに接続します。                               |
| **シェル**               | 高度なトラブルシューティング用にシェルを開きます。                                               |
| **永続領域のサイズ変更**        | イメージが対応している場合、インストーラーの永続領域のサイズを変更します。                                   |
| **電源オフ** と **再起動**    | ターゲットマシンをシャットダウンまたは再起動します。                                              |

グラフィカルメニューが利用できない場合、インストーラーはテキストプロンプトを使用します。

## フラッシュブートデバイスを作成する

ターゲットマシンを USB フラッシュドライブから Unraid で起動する場合は、この手順を使用します。

1. **ZIP をダウンロード** を選択し、Unraid リリースを選択します。バンドル版インストーラーに必要な ZIP がすでに含まれている場合は、この手順を省略します。
2. **フラッシュブートを作成** を選択します。
3. ターゲットの USB ディスクを選択します。パーティションではなく、ディスク全体を選択してください。
4. 警告を読み、ディスクを消去してよいことを確認します。
5. インストーラーが `UNRAID` というラベルの FAT32 パーティションを作成し、Unraid ファイルをコピーして、デバイスをブート可能にするまで待ちます。
6. ターゲットを再起動し、新しいフラッシュブートデバイスを選択します。

USB ブートとライセンスに関するガイダンスについては、[Unraid USB ドライブを作成する](./create-your-bootable-media.mdx) を参照してください。

## 内部ブートデバイスを作成する

ターゲットマシンを内部ストレージから Unraid で起動する場合は、この手順を使用します。
この手順は、直接サーバーにインストールする場合や、リモート環境、仮想化環境で役立ちます。

1. **ZIP をダウンロード** を選択し、Unraid リリースを選択します。バンドル版インストーラーに必要な ZIP がすでに含まれている場合は、この手順を省略します。
2. 既定サイズが適切でない場合は、**内部ブートサイズを設定** を選択します。
3. **内部ブートを作成** を選択します。
4. 1 台または 2 台のディスクを選択します。2 台を選ぶと、ミラーリングされたブートデバイスセットが作成されます。
5. ブートプールのサイズを選択します。ディスクを専用のブートデバイスとして使用するには **Dedicated** を選択するか、固定サイズまたはカスタムサイズを選択します。
6. ブートプール名を入力します。名前は小文字で始める必要があり、小文字、数字、`-`、`_` を含めることができます。
7. 選択したディスクを確認し、破壊的な操作であることを承認します。
8. インストーラーがパーティション構成を作成し、Unraid ファイルをコピーし、ファイルを検証して、ブート構成を書き込むまで待ちます。
9. ターゲットを再起動し、新しい内部ブートデバイスを選択します。

内部ブートに関する質問は、[内部ブートFAQ (7.3+)](./internal-boot-faq.mdx) を参照してください。

インストーラーは、インストーラー自身が動作しているデバイス、またはアクティブなルートディスクの上書きを拒否します。それ以外に選択したディスクは消去されます。

## トラブルシューティング

### ZIP が必要だと表示される

まず **ZIP をダウンロード** を選択してください。ダウンロードに失敗した場合は、**ネットワーク状態を表示** を選択し、次に **ネットワークを再試行 (DHCP)** を選択します。ターゲットが OS ZIP をダウンロードできない場合は、バンドル版インストーラーを使用してください。

### インストーラーがリリースを見つけられない

ターゲットに使用可能な IP アドレスとデフォルトルートがあることを確認してください。ネットワーク設定をやり直してから、もう一度 **ZIP をダウンロード** を選択します。

### ターゲットディスクが表示されない

ディスクが接続されていて、ターゲットマシンから利用可能であることを確認してください。仮想マシンの場合は、そのディスクを仮想マシンにパススルーしてください。パーティションではなく、`/dev/sdb` や `/dev/nvme1n1` のようなディスク全体を選択します。

### インストーラーがディスクの使用を拒否する

インストーラーは、インストーラー自身が動作しているデバイス、またはアクティブなルートディスクの上書きを拒否します。別のデバイスからインストーラーを起動し、目的のターゲットディスクを選択してください。

### インストール後にターゲットが起動しない

ターゲットのファームウェアまたは仮想マシンの起動設定を開きます。新しいフラッシュブートデバイスまたは内部ブートデバイスを起動順序の先頭に移動し、ターゲットを再起動します。

## セットアップを続行する

Unraid が新しいブートデバイスから起動したら、[Unraid OS の展開と設定](./deploy-and-configure-unraid-os.mdx) を続けてください。

ソースコードと最新のリリースアセットについては、[Unraid Installer リポジトリ](https://github.com/unraid/bootable-unraid-installer) を参照してください。
