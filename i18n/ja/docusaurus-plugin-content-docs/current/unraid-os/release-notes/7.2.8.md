# バージョン 7.2.8-rc.1 2026-07-23

Unraid OS 7.2.8-rc.1 は、セキュリティ関連のベースパッケージ更新、Linux カーネル 6.12.96-Unraid、Unraid API 4.36.1、Docker、ZFS、および拡張された Intel ワイヤレスファームウェアの対応範囲に重点を置いたリリース候補のメンテナンスリリースです。

## アップグレード

手順については、[Unraid の更新](/unraid-os/updating-unraid/) をご覧ください。[ライセンス](/unraid-os/troubleshooting/licensing-faq/) に関するご質問がありますか?

## 既知の問題 {/* #known-issues */}

- このリリースで新たに判明した固有の既知の問題はありませんでした。以前の既知の問題については、Unraid OS 7.2.7 のリリースノートを参照してください。

## 注記

- カーネル連動の ZFS モジュールは、6.12.96-Unraid との互換性チェックに合格しました。

## ロールバック {/* #rolling-back */}

- ロールバックに関する新しい警告はありません。ダウングレードする前に、Unraid OS 7.2.7 のロールバック नोटを確認してください。

## Unraid OS 7.2.7 との変更点

### セキュリティ

- セキュリティ: ベースディストリビューションの各パッケージにセキュリティ関連の更新を含みます。詳細なパッケージの CVE 注記は「ベースディストリビューションの更新」に記載されています。
- セキュリティ: WebGUI の `update.php` パス・トラバーサルによるコマンド実行の脆弱性、CVE-2026-3838 を修正しました。

### ネットワーキング / ハードウェア

- 新規: Intel iwlwifi ファームウェアファイルを 304 個追加しました。

## Docker

- Docker の VLAN 自動ネットワークは、コンテナの外向き接続を維持するために、設定された Docker ゲートウェイへフォールバックできます。

### Linux カーネル

- Linux カーネル: 6.12.96-Unraid に更新。
