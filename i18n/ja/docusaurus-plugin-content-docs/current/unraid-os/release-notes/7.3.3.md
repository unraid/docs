# バージョン 7.3.3-rc.1 2026-09-03

Unraid OS 7.3.3-rc.1 は、セキュリティ修正、Linux 6.18.47 カーネル、Docker と API の更新、設定可能な電源ボタン制御、拡張されたハードウェアおよび Hyper-V サポート、ならびに更新されたベースパッケージに重点を置いたリリース候補更新です。このリリースにはセキュリティ修正が含まれているため、アップグレードを推奨します。

## アップグレード

手順については、[Unraid の更新](/unraid-os/updating-unraid/) をご覧ください。[ライセンス](/unraid-os/troubleshooting/licensing-faq/) に関するご質問がありますか? [ライセンス FAQ](/unraid-os/troubleshooting/licensing-faq/) をご確認ください。

## Unraid OS 7.3.2 との変更点

### セキュリティ

- セキュリティ: 上流のセキュリティ修正と CVE 修正を含むシステムコンポーネントを更新しました。

### コンテナ / Docker

- 修正: アイコンのない Docker コンテナの削除または更新時に共有フォールバックアイコンが削除されないようにし、フォールバックアイコンがない場合に同じ失敗リクエストが繰り返されないようにしました。

### WebGUI / システム

- 新規: 設定 > 電源オプションに、物理的な電源ボタンの動作を設定できる項目を追加しました: シャットダウン、再起動、何もしない。

### ネットワーキング / ハードウェア

- 新規: 追加の Intel ワイヤレス、MediaTek Bluetooth、Realtek RTW88 ワイヤレスハードウェア向けのカーネルモジュールとファームウェアを追加しました。

### 仮想化

- 新規: Hyper-V のグラフィックス、バルーニング、ストレージ、キーボード、VMBus、ユーティリティ、および VSOCK コンポーネントのカーネルサポートを追加しました。

### Unraid API

- [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.3 を更新 - 変更点を確認してください。

### Linux カーネル

- Linux カーネル: 6.18.47-Unraid に更新。
