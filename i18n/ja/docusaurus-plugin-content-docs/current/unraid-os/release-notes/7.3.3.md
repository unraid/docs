# バージョン 7.3.3-rc.2 2026-09-24

Unraid OS 7.3.3-rc.2 には、セキュリティ修正、Linux カーネル 6.18.52 への更新、設定可能な電源ボタン動作とハードウェアサポートの追加、ならびに Docker、ファイルマネージャー、および WebGUI の問題修正が含まれています。

このリリースは来週（9月27日の週）に stable へ移行する見込みです。

## アップグレード

手順については、[Unraid の更新](/unraid-os/updating-unraid/) をご覧ください。[ライセンス](/unraid-os/troubleshooting/licensing-faq/) に関するご質問がありますか? [ライセンス FAQ](/unraid-os/troubleshooting/licensing-faq/) をご確認ください。

## [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) との差分

### セキュリティ

- root パスワード設定を強化し、OpenTerminal のリクエスト入力が権限のあるコマンドに渡される前に検証し、VM Manager でゲストから提供されたインターフェース名が HTML として解釈されないようにしました。
- セキュリティ修正を含む base distro パッケージを更新しました。CVE の注記は、下の対応するパッケージ更新に記載されています。

### コンテナ / Docker

- 修正: Docker Manager は、アイコンのないコンテナが削除または更新されたときに、共有のデフォルトアイコンを削除しなくなりました。

### ストレージ

- 修正: ファイルマネージャーのコピーおよび移動操作が、シンボリックリンクの深さエラーで失敗することがありました。
- 修正: 同時ファイルロック要求によって FUSE ワーカープールが枯渇した際の shfs のデッドロックを防止しました。
- 修正: `/mnt/user` が利用できなくなる原因となる可能性があった shfs のアサーション失敗を防止しました。

### WebGUI / システム

- 新機能: 設定 > 電源オプション で物理電源ボタンを設定し、シャットダウン、再起動、または何もしないようにできます。
- 修正: アレイ停止時の停止中アレイの使用率表示を修正し、マウントされた Boot Device の使用量/空き容量統計を復元しました。

### ネットワーキング / ハードウェア

- 新機能: 追加の Intel、MediaTek、および Realtek のワイヤレスハードウェア向けのカーネルドライバーとファームウェアを追加しました。

### 仮想化

- 新規: Hyper-V のグラフィックス、バルーニング、ストレージ、キーボード、VMBus、ユーティリティ、および VSOCK コンポーネントのカーネルサポートを追加しました。

### Unraid API

- [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.4 を更新しました - 変更点を参照してください。

### Linux カーネル

- Linux カーネル: `6.18.52-Unraid` に更新。
