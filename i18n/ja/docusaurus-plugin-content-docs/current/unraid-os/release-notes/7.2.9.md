# バージョン 7.2.9 2026-10-23

このメンテナンスリリースには、PHP のセキュリティ修正、4.36.1 から 4.37.7 への Unraid API の更新、および [eMudhra 証明書侵害レポート](<https://unit42.paloaltonetworks.com/emudhra-certificate-compromise/>)で言及されている侵害済み CA 証明書に対処する更新が含まれています。カーネルのバージョンは 7.2.8 から変更されていません。**より新しいカーネルと、より広範なパッケージのセキュリティ更新が含まれる最新の安定版 Unraid OS 7.3.x リリースへの更新を推奨します。**。

## アップグレード {/* #upgrading */}

手順については、[Unraid の更新](/unraid-os/updating-unraid/) をご覧ください。[ライセンス](/unraid-os/troubleshooting/licensing-faq/) に関するご質問がありますか? [ライセンス FAQ](/unraid-os/troubleshooting/licensing-faq/) をご確認ください。

## 既知の問題 {/* #known-issues */}

GUI モードの Firefox は、侵害済み CA 証明書に対してパッチが適用されていません。このブラウザーは WebGUI のセットアップ以外には使用しないでください。

他にも適用される可能性のある問題については、[Unraid OS 7.2.8 リリースノート](/unraid-os/release-notes/7.2.8/) を参照してください。

## [Unraid OS 7.2.8](/unraid-os/release-notes/7.2.8/) との差分

### セキュリティ

- セキュリティ: 複数の CVE に対応するため PHP を更新しました。
- セキュリティ: [Unit 42 レポート](<https://unit42.paloaltonetworks.com/emudhra-certificate-compromise/>) で言及されている侵害済み CA 証明書に対処しました。

### Unraid API 4.37.7

4.36.1 から 4.37.7 に更新されました。API にバンドルされた Node.js ランタイムを 22.23.4 に更新しました。これにより Node の証明書侵害問題が解決されます。[完全な API 比較](<https://github.com/unraid/api/compare/v4.36.1...v4.37.7>) を参照してください。

### セキュリティ勧告: 追加の潜在的脆弱性

**最新の安定版 Unraid OS 7.3.x リリースへの更新を推奨します**。より新しいカーネルと、より広範なパッケージのセキュリティ更新が含まれているためです。7.2.9 への更新だけで、すべての潜在的な検出項目が解決されたと**解釈すべきではありません**。

Unraid OS 7.2.9 は、PHP のセキュリティ修正、CA 証明書の更新、および Unraid API の修正とセキュリティ強化を含む、対象を絞ったメンテナンスリリースです。新しいリリースで利用できる、より広範なディストリビューションパッケージやカーネルのセキュリティ更新は**含まれていません**。

2026年10月23日時点で、上流のパッケージアドバイザリでは、含まれるパッケージバージョンに関連する115件の潜在的なCVEが確認されています。次の分類には、そのうち112件の潜在的なCVEが含まれます。

- **ネットワーク転送と DNS — 42:** curl (30) と BIND (12)。
- **暗号化と安全な接続 — 25:** OpenSSL (23)、libssh (1)、p11-kit (1)。
- **グラフィカルコンポーネント — 29:** xorg-server (11)、libXi (8)、libX11 (4)、libXfont2 (2)、libXtst (2)、libXpm (1)、libXrender (1)。
- **ファイル共有 — 6:** Samba (6)。
- **その他のライブラリとシステムユーティリティ — 10:** libpcap (5)、util-linux (4)、libpng (1)。

追加のセキュリティ勧告では、libarchive、libxml2、OpenSSH、PCRE2、rsync、wpa_supplicant、xz が、特定の CVE 識別子を示さずに対象となっています。別の脆弱性データベースチェックでは、上記 115 件と重複する可能性のある 55 件の潜在的なパッケージ CVE が特定されています。これらの合計は加算しないでください。

より新しい上流カーネルのリリースには、7.2.9 に含まれていないセキュリティ修正も含まれています。
