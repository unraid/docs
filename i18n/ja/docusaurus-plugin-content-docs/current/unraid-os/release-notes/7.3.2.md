# バージョン 7.3.2 2026-07-08

Unraid OS 7.3.2 は、Linux カーネル 6.18.38、Docker の VLAN ネットワーク修正、ストレージおよびブートプールの修正、仮想化 UI の修正、Unraid API 4.35.1、そして複数のベースパッケージ更新を含む、セキュリティおよびバグ修正リリースです。

## Unraid OS 7.3.1 からの変更点

### セキュリティ

- セキュリティ: WebGUI の `update.php` パス・トラバーサルによるコマンド実行の脆弱性、CVE-2026-3838 を修正しました。
- セキュリティ: 複数コンポーネントに対する CVE 対応を含むベースパッケージのセキュリティ修正が含まれています。パッケージごとの CVE の詳細は「ベースディストリビューションの更新」に記載されています。

### コンテナ / Docker

- 修正: Docker VLAN 自動ネットワークが設定済みの Docker ゲートウェイへフォールバックできるようになり、コンテナの外向き接続が維持されます。
- 改善: コミュニティからの貢献である [TSpader ](\<https://github.com/tspader>)（ありがとうございます！）に基づき、Docker タブの描画経路から同期 I/O を外すことで、Docker タブの読み込み性能を改善しました。

### ストレージ

- 修正: ブートプールの置換時に、該当する置換ケースで古い欠落ミラー・メンバーが残らなくなりました。
- 修正: ブートプールデバイスの削除で、操作に失敗する可能性があった回帰が発生しなくなりました。
- 修正: 名前がブートデバイスと重複するプールデバイスをフォーマットしても、誤った無効ターゲットのアサーションが発生しなくなりました。
- 修正: Btrfs RAID1 プールのダッシュボードでのキャッシュプールサイズと使用量の表示が修正されました。

### WebGUI / システム

- 新規: LED および LCD の状態を使用するパネル表示プラグイン向けに、モニターステータス出力を追加しました。
- 修正: シャットダウンおよび再起動時の syslog 保存で、syslog ファイルを書き込む前に `/boot/logs` を作成するようになりました。
- 修正: システムデバイスのコントローラー一覧に、影響を受けるケースでも無関係なデバイスが含まれなくなりました。
- 修正: Flash ライセンスを使用する Internal Boot で、一時的な USB ライセンスデバイスのリセットをより適切に処理するようになりました。

### ネットワーキング / ハードウェア

- 修正: Avahi/mDNS の更新により、一時的なネットワーク喪失後にデーモンを再び開始できるようになりました。
- 修正: Intel GPU の PCI 速度表示が修正されました。
- 改善: Intel iGPU の SR-IOV コントロールは、対応プラグインがインストールされている場合にのみ表示されます。

### 仮想化

- 修正: VM の CPU 使用率が、無関係なホストタスクによって高く報告されなくなりました。
- 修正: VM のコンテキストメニューの位置が修正されました。
- 改善: VM Network Source のドロップダウン項目が並べ替えられ、見やすくするためにコントロールの幅が広くなりました。
- 修正: VM PCI オプションが有効な場合に表示されていた古い VM 再起動バナーのメッセージを削除しました。

### Unraid API

- Unraid API を [dynamix.unraid.net 4.35.1](\<https://github.com/unraid/api/releases/tag/v4.35.1>) に更新しました。

### Linux カーネル

- Linux カーネル: 6.18.38-Unraid に更新。
  CONFIG_USB_AUTOSUSPEND_DELAY=-1
