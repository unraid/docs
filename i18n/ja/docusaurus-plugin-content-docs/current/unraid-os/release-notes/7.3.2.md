# バージョン 7.3.2-rc.1 2026-07-02

Unraid OS 7.3.2-rc.1 では、Linux カーネル、Docker、Unraid API、および幅広い基本パッケージが更新され、コアのネットワーク、Web、ストレージ、暗号化コンポーネント全体にわたってセキュリティ関連の更新が行われています。このリリースには、ZFS と QEMU の更新に加え、ストレージ、Docker、システムの改善も含まれています。

## [Unraid OS 7.3.1](/unraid-os/release-notes/7.3.1/) との差分

### セキュリティ

- セキュリティ: セキュリティ修正のために bind、dnsmasq、libarchive、libidn、net-tools、nginx、openssl、shadow、sqlite、および xorg-server を更新しました。dnsmasq、nginx、openssl、net-tools、および sqlite には、記載された CVE 対応が含まれています。
- 修正: CVE-2026-3838。

### コンテナ / Docker

- 改善: Docker を 29.5.3-1_LT に更新しました。
- 修正: Docker 29 への更新後、VLAN Docker ネットワークでゲートウェイとデフォルトルートの処理がより確実に復元されるようになり、影響を受けたコンテナが外向き接続および VLAN 間接続を回復できるようになりました。

### ストレージ

- 改善: ZFS を 2.4.3_6.18.37_Unraid-1_LT に更新しました。
- 修正: いくつかのミラー構成の boot pool で GUI エラーにより失敗していた boot pool デバイスの削除が、再び正しく動作するようになりました。
- 修正: 一部のポート交換シナリオで、欠落した boot pool デバイスを置き換えた後に古い欠落ミラー メンバーが残ってしまう問題がなくなりました。
- 修正: 特定の `sda` 命名の境界ケースで、プールのフォーマットまたは消去を行うと GUI がクラッシュしていた問題を修正しました。
- 修正: サイズの異なるデバイスを含む場合のダッシュボード上の Btrfs RAID1 プールのサイズおよび使用量の表示を修正しました。

### WebGUI / システム

- 改善: dynamix.unraid.net を 4.35.1 に更新しました。
- 改善: bash、ca-certificates、curl、git、pkgtools、rsync、util-linux、およびその他のコア コンポーネントを含むベース システム パッケージを更新しました。
- 修正: System Devices のコントローラービューで、無関係なデバイスが含まれることがあった代わりに、正しいドライブが表示されるようになりました。
- 修正: mDNS サービス検出が、一時的なネットワーク喪失の後でもより確実に復旧できるようになりました。

### ネットワーキング / ハードウェア

- 改善: cifs-utils、iproute2、libnvme、および wireless-regdb を更新しました。
- 新規: libcbor、libfido2、libmaxminddb を追加しました。
- 改善: 必要なプラグインがインストールされている場合のみ Intel iGPU SR-IOV コントロールが表示されるようになり、適用できない設定を回避できます。

### 仮想化

- 改善: QEMU を 10.2.3-1_SBo_LT に更新しました。
- 改善: System Devices における Intel Arc GPU の PCI リンク速度表示がより正確になり、パススルー用ハードウェアの確認に役立ちます。
- 改善: VM Network Source セレクターがより広くなり、並び順もより自然になったため、長いネットワーク名や番号付きのネットワーク名を確認しやすくなりました。
- 修正: VM のコンテキストメニューがページ下部付近で開かれた場合でも、画面外に一部はみ出して描画されるのではなく、表示されたままになるようになりました。
- 修正: VM の使用率表示が、無関係なファイル転送中に誇張された使用率を示すのではなく、実際のゲスト CPU アクティビティにより一致するようになりました。
- 修正: PCI オプションが有効なときに、VM 設定から古い再起動警告を削除しました。

### Unraid API

- Unraid API を dynamix.unraid.net 4.35.1 に更新しました。

### Linux カーネル

- Linux カーネル: 6.18.37-Unraid に更新。
