# バージョン 7.4.0-beta.3 2026-09-24

Unraid OS 7.4.0-beta.3 は、セキュリティ更新と Linux カーネル 6.18.52 を含むベータリリースであり、Docker とストレージの改善、ハードウェアおよび Hyper-V サポートの拡張、共有タスクトレイを含む WebGUI の強化が追加されています。

## beta.3 の新機能

- 修正: Mover は、進行状況を有効にした移動中に、同じ共有内の別々のサブフォルダにあるファイルを含め、ハードリンクを保持するようになりました。
- 修正: `shfs` は、同時ファイルロック要求によってデッドロックしなくなり、また、`/mnt/user` を利用不可にする可能性のあった内部の unlink アサーションでクラッシュしなくなりました。
- このリリースには、パッケージの更新とセキュリティ修正が含まれています。

ベータテスターの皆さんには、このリリースに含まれるセキュリティ修正を受け取り、安定版公開前に変更内容の検証に協力していただくため、アップグレードすることを推奨します。

## [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) との差分

### セキュリティ

- ベースディストリビューションの更新により、報告された各種 CVE とその他のセキュリティ修正に対応しています。詳細は以下のパッケージ注記をご覧ください。
- OpenTerminal は、シェルコマンドで使用される前に要求入力を検証します。
- VM Manager は、ゲストエージェントから提供されたネットワークインターフェース名をアクティブな HTML ではなくテキストとして表示します。
- 診断データの匿名化では、公開 IPv6 アドレスと関連する診断出力が非表示になりました。

### コンテナ / Docker

- 新機能: Docker コンテナのテンプレートで複数のカスタムネットワークをサポートし、コンテナの再作成または更新時に追加のネットワーク接続が保持されます。
- 新機能: Docker の追加/編集フォームでコンテナアイコン URL のライブプレビューを表示し、URL が空または無効な場合はフォールバックします。
- 新機能: 詳細表示に Docker コンテナ用のメモリ制限フィールドが追加されました。
- 改善: Docker レジストリの更新チェックが OCI イメージの manifest と index を受け入れ、Unraid クライアントを識別するようになりました。
- 修正: フォールバック画像が利用できない場合でも、ダッシュボードの Docker アイコンのフォールバック処理が無限に再試行しなくなりました。

### ストレージ

- 新機能: Mover の進行状況とステータスの追跡が利用できるようになりました（ついに！）。
- 新機能: SES が利用できない場合でも、SGPIO/IBPI 対応コントローラーによるドライブ位置の識別をサポートします。
- 改善: 暗号化された array のパスフレーズ欄で Enter を押すと、パスフレーズが有効な場合に array が開始されます。
- 修正: Mover は、同じ share 内の別々のサブフォルダーにまたがる hard links を持つファイルを処理できるようになりました。
- 修正: 異なる pool またはドライブ間で user share を移動する際、転送に失敗しても元のファイルが密かに削除されなくなりました。
- 修正: 同時の file-lock 要求で FUSE ワーカープールが枯渇しても、`shfs` がデッドロックしなくなりました。
- 修正: `shfs` が、`/mnt/user` を利用不能にする可能性のあった内部 unlink アサーションでクラッシュしなくなりました。
- 修正: 停止中の array が 100% の使用率を表示しなくなり、代わりにオフライン状態と filesystem 状態を表示します。
- 修正: array 停止時に Boot Device の使用済み/空き統計が表示されます。

### WebGUI / システム

- 新機能: プラグイン、Docker、仮想マシンによるバックグラウンド操作を共有タスクトレイからキューに入れて管理でき、任意のブラウザータブから前面に呼び戻せます。
- 新機能: **Settings → Power Settings → Power Button → Physical power button** で物理電源ボタンを設定できます。
- 改善: フォアグラウンドの task sheet は、保存された幅とモバイル動作を維持しながら、ブラウザーの viewport に合わせて拡大縮小します。
- 改善: プラグインのインストール進行状況では、carriage-return による更新が 1 行にまとめられず、個別のライブ更新として表示されます。
- 改善: Installed Plugins ページは更新を個別に確認するため、遅いプラグインや到達不能なプラグインがあってもページ全体が待機し続けません。
- 改善: ライセンスチェックは、ネットワークやサービスの一時的な可用性問題に対応するため再試行します。
- 修正: プラグイン更新の検証失敗は、プラグインが最新であると黙って報告されるのではなく、説明付きで表示され続けます。
- 修正: エラーメッセージに shell 文字が含まれている場合でも、Plugin Manager のクリーンアップフックが実行されます。
- 修正: 非同期チェックの完了中も、Installed Plugins の更新優先の並び順は安定したままです。
- Fix: Power Options retains both the Power Mode and Power Button tabs when the Dynamix System Buttons plugin is installed.
- Fix: Power Options no longer shows the virtualization warning on bare-metal servers.

### ネットワーキング / ハードウェア

- 新機能: Realtek RTW88 8812A、8814A、8821A、RTW89 8851BU および 8852BU アダプターを含む、追加の Intel、MediaTek、Realtek ワイヤレスハードウェア向けのドライバーとファームウェアのサポートが追加されました。
- 新機能: 追加の PlayStation、Nintendo、Steam、Logitech のコントローラー、ハードウェアセンサー、および audio codec のサポートが追加されました。
- 新機能: Linux netconsole が、ネットワークベースの kernel クラッシュ診断用のオプションモジュールとして利用できるようになりました。
- 改善: ネットワークの既定値は Fedora の `/etc/sysctl.conf` ベースラインに合わせられており、この変更によって外部向けの問題は発生しない見込みです。

### 仮想化

- 新機能: storage、balloon、keyboard、および virtual-socket モジュールを含む、Hyper-V 仮想化向けの kernel サポートが追加されました。
- 修正: VM の起動時に、QEMU の場所検索で出力がない場合でも PHP の非推奨警告が記録されなくなりました。

### Linux カーネル

- Linux カーネル: `6.18.52-Unraid` に更新。
