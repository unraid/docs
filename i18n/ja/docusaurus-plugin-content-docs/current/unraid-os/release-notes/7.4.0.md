# バージョン 7.4.0-beta.2 2026-09-03

Unraid OS 7.4.0-beta.2 adds Docker multi-network and memory controls, shared background task management, boot-device backup improvements, configurable power-button behavior, **mover progress tracking**, and expanded hardware and Hyper-V support. It also improves transient license checking, updates the Linux kernel to 6.18.47-Unraid and the Unraid API to 4.37.3, and includes core package security updates (the same updates to core packages as 7.3.3-rc.1)

## Fixes / Features From 7.4.0-beta.1

- 新規: Mover の進捗とステータスの追跡が利用できるようになりました。既知の問題により、***設定 → スケジューラ → Mover 設定*** に移動し、**Mover 進捗** を **無効** に設定して **適用** を選択してください。その後、**Mover 進捗** を **有効** に設定し、もう一度 **適用** を選択してください。
- Fix: Power Options retains both the Power Mode and Power Button tabs when the Dynamix System Buttons plugin is installed.
- Fix: Power Options no longer shows the virtualization warning on bare-metal servers.

## [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) との差分

### セキュリティ

- セキュリティ: コアコンポーネントには、報告されたCVEおよびその他のセキュリティ修正に対応する更新が含まれています。
- セキュリティ: 通知連携は、証明書検証を回避するのではなく、公開API証明書を検証するようになりました。

### コンテナ / Docker

- 新機能: Docker コンテナテンプレートが複数のカスタムネットワークをサポートし、コンテナの再作成や更新時にも追加のネットワーク接続が保持されます。
- 新機能: Dockerの追加/編集フォームで、コンテナーアイコンURLのライブプレビューが表示され、URLが空または無効な場合は代替表示が行われます。
- 新機能: 詳細表示で、Dockerコンテナーのメモリ制限フィールドが表示されます。

### ストレージ

- 新規: Mover の進捗とステータスの追跡が利用できるようになりました。既知の問題により、***設定 → スケジューラ → Mover 設定*** に移動し、**Mover 進捗** を **無効** に設定して **適用** を選択してください。その後、**Mover 進捗** を **有効** に設定し、もう一度 **適用** を選択してください。
- 新機能: SESが利用できない場合、ドライブ位置のサポートはSGPIO/IBPI対応コントローラーを使用できます。
- 修正: 停止中のアレイでは、100%使用率ではなく、オフラインとファイルシステムのステータステキストが表示されるようになりました。
- 修正: 暗号化されたアレイのパスフレーズ欄でEnterキーを押すと、パスフレーズの検証が成功した場合にアレイが開始されるようになりました。

### WebGUI / システム

- 新機能: プラグイン、Docker、仮想マシンによるバックグラウンド操作を共有タスクトレイからキューに入れて管理でき、任意のブラウザータブから前面に呼び戻せます。
- 新機能: ブートデバイスのバックアップは、選択可能な圧縮、ライブ進行状況、完了時の自動ダウンロードを備えたバックグラウンドタスクとして実行されます。
- 新機能: 設定 → 電源設定 → 電源ボタン → **物理電源ボタン** で物理電源ボタンを設定でき、動作はシャットダウン、再起動、何もしないから選べます。
- 改善: 前面タスクシートが、保存済み幅とモバイルでの動作を維持しつつ、ブラウザーのビューポートに合わせて拡大縮小されるようになりました。
- 改善: ライセンスチェックは、一時的な可用性やネットワーク条件に対応するため、再試行するようになりました。
- Fix: Power Options retains both the Power Mode and Power Button tabs when the Dynamix System Buttons plugin is installed.
- Fix: Power Options no longer shows the virtualization warning on bare-metal servers.
- 修正: インストール済みプラグインページは更新を個別に確認するため、応答が遅いプラグインや到達不能なプラグインがあってもページ全体の待機が続かなくなりました。
- 修正: プラグイン更新の検証失敗は、プラグインが最新であると黙って報告されるのではなく、説明付きで表示されたままになります。
- 修正: プラグインマネージャーの post-hook クリーンアップは、エラーメッセージにシェル文字が含まれている場合にも実行されるようになりました。

### ネットワーキング / ハードウェア

- 新機能: Realtek RTW88 8812A、8814A、8821Aワイヤレスアダプター用のカーネルモジュールとファームウェア、およびRTW89 8851BUと8852BU USBアダプター用のカーネルモジュールが追加されました。
- 新機能: 追加のPlayStation、Nintendo、Steam、Logitechコントローラーに加え、追加のオーディオコーデックのサポートが追加されました。
- 改善: ネットワークの既定値は、CUBIC TCP輻輳制御と既定のパケットスケジューラーとしての`fq_codel`を含め、Fedoraの`/etc/sysctl.conf`ベースラインに従うようになりました。

### 仮想化

- 新機能: Hyper-Vストレージ、バルーン、キーボード、VMBusモジュールを含む、Hyper-V仮想化用のカーネルサポートが追加されました。
- 修正: VM の起動時に、QEMU の場所検索で出力がない場合でも PHP の非推奨警告が記録されなくなりました。

### Unraid API

- [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.3 を更新 - 変更点を確認してください。

### Linux カーネル

- Linux カーネル: 6.18.47-Unraid に更新。
