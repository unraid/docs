# バージョン 7.4.0-beta.1 2026-08-14

Unraid OS 7.4.0-beta.1 は、コアパッケージ全体のセキュリティ更新、Linux カーネル 6.18.44、Docker と WebGUI の改善、コンテナのネットワーキングとメモリ制御の拡張、新しいタスク管理と電源ボタン設定、そして Realtek RTW88 無線ハードウェアのサポート追加を含むベータ版です。

## アップグレード

手順については、[Unraid の更新](/unraid-os/updating-unraid/) をご覧ください。[ライセンス](/unraid-os/troubleshooting/licensing-faq/) に関するご質問がありますか? [ライセンス FAQ](/unraid-os/troubleshooting/licensing-faq/) をご確認ください。

## [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/) との差分

### セキュリティ

- セキュリティ: コアパッケージの更新には、bind、libXfont2、libarchive、libssh、openssh、p11-kit、php、samba、wpa_supplicant、および xorg-server のセキュリティ修正が含まれます。
- セキュリティ: 通知連携では、公開 API へのリクエストに証明書検証済みのリクエストを使用するようになりました。

### コンテナ / Docker

- 新機能: Docker コンテナテンプレートが複数のカスタムネットワークをサポートし、コンテナの再作成や更新時にも追加のネットワーク接続が保持されます。
- 新機能: Docker の追加/編集フォームで、コンテナアイコン URL のライブプレビューが表示されるようになり、URL が空または無効な場合は代替表示が行われます。
- 新機能: 詳細表示で Docker コンテナのメモリ制限フィールドが表示されるようになりました。

### ストレージ

- 修正: 暗号化された配列のパスフレーズ欄で Enter キーを押すと、パスフレーズの検証に成功した場合に配列が開始されるようになりました。
- 修正: ファイルマネージャーは、専有共有を基盤となるディスクまたはプールのパスに切り替えず、`/mnt/user/\<share>` ビューのまま保持します。

### WebGUI / システム

- 新機能: プラグイン、Docker、仮想マシンによるバックグラウンド操作を共有タスクトレイからキューに入れて管理でき、任意のブラウザータブから前面に呼び戻せます。
- 新機能: Boot Device ページで、バックアップを直接ダウンロードするか、サーバーに保存するかを選択でき、進行状況も追跡できます。
- 新機能: 物理的な電源ボタンの動作を、シャットダウン、再起動、または何もしないに設定できます。設定するには 設定 → 電源オプション に移動してください。
- 改善: 前面タスクシートが、保存済み幅とモバイルでの動作を維持しつつ、ブラウザーのビューポートに合わせて拡大縮小されるようになりました。
- 改善: ライセンスがディスク上で 1 分間利用できなくなった場合に再試行するようになり、一時的な起動ドライブの切断を許容できるようになりました
- 改善: 統合ヘッダーがヘッダーのレイアウトと配列使用量の表示を管理するようになり、モバイルでのヘッダー重なりに対処しました。
- 修正: インストール済みプラグインページは更新を個別に確認するため、応答が遅いプラグインや到達不能なプラグインがあってもページ全体の待機が続かなくなりました。
- 修正: プラグイン更新の検証失敗は、ルートファイルシステムの満杯による失敗を含め、プラグインが最新であると黙って報告する代わりに、説明付きで表示されたままになります。
- 修正: プラグインマネージャーの post-hook クリーンアップは、エラーメッセージにシェル文字が含まれている場合にも実行されるようになりました。

### ネットワーキング / ハードウェア

- 新機能: Realtek RTW88 8812A、8814A、および 8821A のワイヤレスアダプター向けに、カーネルモジュールとファームウェアを追加しました。

### 仮想化

- 修正: VM の起動時に、QEMU の場所検索で出力がない場合でも PHP の非推奨警告が記録されなくなりました。

### Unraid API

- [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.1 を更新 - [変更点を確認](\<https://github.com/unraid/api/releases>).

### Linux カーネル

- Linux カーネル: 6.18.44-Unraid に更新。
