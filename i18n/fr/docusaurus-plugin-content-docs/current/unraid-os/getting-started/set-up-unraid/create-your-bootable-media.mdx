# Créer une clé USB Unraid

Unraid OS peut démarrer à partir d’une clé USB ou, dans Unraid 7.3 et les versions ultérieures, à partir d’un périphérique de démarrage interne pris en charge. Cette page explique comment créer une clé USB pour un nouveau serveur. Vous pouvez continuer à utiliser la clé USB pour le démarrage sur clé, ou l’utiliser pour démarrer le serveur avant de choisir le démarrage interne lors de l’intégration. Consultez la [FAQ sur le démarrage interne (7.3+)](./internal-boot-faq.mdx) pour plus d’informations.

Pour le démarrage USB, utilisez une clé USB de qualité, de n’importe quelle capacité, avec un %%GUID|guid%% unique. Le %%GUID|guid%% identifie le périphérique USB pour la licence.

:::tip[Choosing support de démarrage fiable]

Pour le démarrage USB, choisissez une clé USB de qualité avec un %%GUID|guid%% unique. Consultez [Choisir un périphérique de démarrage](#choosing-a-usb-flash-drive) dans la section d’installation manuelle pour obtenir des conseils sur des supports fiables et les clés contrefaites.

Si vous prévoyez d’utiliser le démarrage interne, vous avez quand même besoin de cette clé USB pour démarrer un nouveau serveur. Après le premier démarrage, l’assistant d’intégration vous permet de choisir le démarrage sur clé ou le démarrage interne.

:::

## Méthode d'installation automatique {/* #automated-install-method */}

L'outil Unraid USB Creator prépare la clé, télécharge ou utilise l'image d'Unraid OS sélectionnée, puis écrit l'image sur la clé USB. Utilisez cette méthode pour la plupart des nouvelles installations.

:::caution[Writing efface la clé USB]

L'action **WRITE** efface la clé USB sélectionnée. Déconnectez les autres lecteurs amovibles avant de commencer. Si vous remplacez un périphérique de démarrage Unraid existant, [sauvegardez-le d'abord](../../system-administration/secure-your-server/secure-your-boot-drive.mdx).

:::

### Télécharger le créateur USB

Téléchargez et installez le créateur USB pour votre ordinateur :

- [Windows](https://releases.unraid.net/dl/stable/usb-creator.exe)
- [macOS](https://releases.unraid.net/dl/stable/usb-creator.dmg)
- [Linux](https://releases.unraid.net/dl/stable/usb-creator.appimage)

Insérez la clé USB dans votre ordinateur. Fermez toute application qui a la clé ouverte.

### Sélectionner la langue

1. Ouvrez le créateur USB.
2. Sélectionnez votre langue.
3. Sélectionnez **SUIVANT**.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Sélection de la langue dans le créateur USB](/img/unraid-os/getting-started/create-unraid-usb/01-00-language-selection.png)
</div>

### Sélectionnez une version d'Unraid OS

1. Sélectionnez la version d'Unraid OS à installer.
2. Sélectionnez **SUIVANT**.

Pour un serveur de production, sélectionnez la dernière version stable. N'utilisez une image de développement que lorsque vous testez cette image.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Sélection du système d'exploitation dans le créateur USB](/img/unraid-os/getting-started/create-unraid-usb/02-01-os-selection.png)
</div>

### Sélectionnez le lecteur USB

1. Sélectionnez le lecteur USB que vous souhaitez préparer.
2. Vérifiez le nom du lecteur, sa taille et son %%GUID|guid%%.
3. Laissez **Exclure les lecteurs système** sélectionné.
4. Sélectionnez **SUIVANT**.

Le %%GUID|guid%% doit être unique pour que le lecteur fonctionne avec la licence Unraid. Ne sélectionnez pas un lecteur contenant des données que vous souhaitez conserver.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Sélection du périphérique de stockage dans le créateur USB](/img/unraid-os/getting-started/create-unraid-usb/03-02-storage-selection.png)
</div>

### Configurer le nouveau serveur (facultatif)

La section **Personnalisation** vous permet de définir ces options avant le premier démarrage :

- **Nom du serveur** définit le nom qu'Unraid utilise sur votre réseau.
- **Wi-Fi** enregistre les paramètres du réseau Wi-Fi pour un serveur qui utilise une connexion sans fil.
- **Réseau** définit l'adressage automatique avec DHCP ou une adresse IP statique.

Ignorez ces sections si vous souhaitez configurer le serveur après le premier démarrage. Si vous configurez le Wi-Fi, considérez que la clé USB contient le mot de passe Wi-Fi jusqu'à ce que le serveur démarre pour la première fois.

### Vérifier et écrire l'image

1. Vérifiez le système d'exploitation et le périphérique de stockage dans le récapitulatif.
2. Assurez-vous que le périphérique de stockage est bien la clé USB que vous souhaitez effacer.
3. Sélectionnez **ÉCRIRE**.

Le créateur USB écrit l'image sélectionnée sur le lecteur.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Résumé d'écriture dans le créateur USB](/img/unraid-os/getting-started/create-unraid-usb/04-03-write-summary.png)
</div>

### Finaliser la configuration USB

Une fois l'écriture terminée :

1. Vérifiez les choix affichés sur l'écran de fin.
2. Sélectionnez **TERMINER**.
3. Retirez la clé USB uniquement après que le créateur USB l'a éjectée.

Les systèmes UEFI peuvent démarrer depuis le lecteur sans étape supplémentaire. Pour un ancien système BIOS uniquement, exécutez le script de démarrage depuis la racine de la clé USB :

- **Windows :** Cliquez avec le bouton droit sur `make_bootable.bat` et sélectionnez **Exécuter en tant qu'administrateur**.
- **macOS :** Double-cliquez sur `make_bootable_mac` et saisissez votre mot de passe administrateur lorsqu'il vous est demandé.
- **Linux :** Démontez la clé USB. Puis exécutez `sudo bash ./make_bootable_linux`.

<div style={{ margin: "auto", maxWidth: "680px" }}>
  ![Fin de l'écriture dans le créateur USB](/img/unraid-os/getting-started/create-unraid-usb/05-04-write-complete.png)
</div>

### Démarrez le serveur à partir de la nouvelle clé USB

1. Insérez la clé USB préparée dans le serveur.
2. Ouvrez les paramètres BIOS ou UEFI du serveur.
3. Définissez la clé USB comme premier périphérique de démarrage.
4. Enregistrez les paramètres du BIOS et redémarrez le serveur.

Sur Unraid 7.3 et les versions ultérieures, lorsque Unraid démarre pour la première fois, l’assistant d’intégration vous permet de choisir la méthode de démarrage :

- **Le démarrage sur clé** conserve Unraid sur la clé USB.
- **Le démarrage interne** déplace Unraid vers un périphérique de démarrage interne pris en charge ou vers deux périphériques de démarrage internes en miroir.

Pour plus de détails sur le démarrage interne, consultez la section [Intégration](./deploy-and-configure-unraid-os.mdx#onboarding) et la [FAQ sur le démarrage interne (7.3+)](./internal-boot-faq.mdx).

Après le démarrage d'Unraid OS, continuez avec [Déployer et configurer Unraid OS](./deploy-and-configure-unraid-os.mdx).

## Dépannage

### La clé USB n'apparaît pas

1. Déconnectez la clé USB.
2. Fermez le créateur USB.
3. Connectez la clé USB directement à l'ordinateur.
4. Rouvrez le créateur USB.

Le créateur USB d'Unraid n'affiche pour ce flux de travail que les périphériques de stockage USB. Assurez-vous que votre ordinateur détecte le lecteur avant d'ouvrir le créateur USB.

### Le serveur ne démarre pas depuis la clé USB

1. Ouvrez les paramètres BIOS ou UEFI.
2. Assurez-vous que la clé USB est le premier périphérique de démarrage.
3. Pour un système BIOS uniquement, exécutez le script `make_bootable` spécifique à la plate-forme décrit dans [Finaliser la configuration USB](#finish-the-usb-setup).
4. Enregistrez les paramètres et redémarrez le serveur.

Si vous avez choisi le démarrage interne et que le serveur ne démarre pas après l’assistant de configuration, placez le périphérique de démarrage interne sélectionné en tête de l’ordre de démarrage du BIOS/UEFI. Si le serveur ne démarre toujours pas, utilisez la [méthode d’installation manuelle](#manual-install-method) pour préparer à nouveau la clé USB.

### La clé USB ne peut pas enregistrer de licence

Le démarrage sur USB et la licence USB nécessitent un %%GUID|guid%% unique. Si le lecteur ne dispose pas d’un %%GUID|guid%% unique, utilisez une autre clé USB. Si vous utilisez le démarrage interne avec une licence basée sur le TPM, consultez la [FAQ sur le démarrage interne (7.3+)](./internal-boot-faq.mdx#internal-boot-flash-license).

## Méthode d'installation manuelle {/* #manual-install-method */}

La méthode d’installation manuelle est destinée aux situations où l’outil USB Creator n’est pas disponible ou est incompatible avec votre matériel. Cette méthode vous donne le contrôle du formatage et du processus de configuration.

### Choisir un périphérique de démarrage {/* #choosing-a-usb-flash-drive */}

<FlashDriveGuidance />

### Préparez votre périphérique USB {/* #prepare-your-usb-device */}

1. Branchez la clé USB que vous préparez comme périphérique de démarrage.
2. Formatez-le en FAT32 (**non** en ex-FAT ou NTFS).
3. Définissez le libellé du volume sur `UNRAID` (sensible à la casse, en majuscules).

:::important

Sous Windows, les outils de formatage intégrés ne peuvent pas formater les lecteurs de plus de 32 Go en FAT32. Ils utilisent exFAT par défaut. Pour un lecteur plus grand, utilisez un outil compatible FAT32 tel que [Rufus](https://rufus.ie/en/).

:::

### Téléchargez et extrayez

1. Allez dans l'[archive de téléchargement d'Unraid](../../download_list.mdx) et téléchargez le fichier ZIP de votre version choisie.
2. Extrayez le contenu du ZIP sur le périphérique USB.
3. Confirmez que les fichiers ont été copiés.

### Rendez le périphérique USB amorçable

:::note

Cette section est uniquement nécessaire pour activer le démarrage Legacy. Si vous configurez pour UEFI, il n'est pas nécessaire d'exécuter ces scripts.

:::

**Windows 7 ou version ultérieure :**

**Windows 7 ou version ultérieure :**

- Cliquez avec le bouton droit sur `make_bootable` et sélectionnez **Exécuter en tant qu'administrateur**.

**Mac :**

- Double-cliquez sur `make_bootable_mac` et entrez votre mot de passe administrateur.

**Linux :**

- Copiez `make_bootable_linux` sur votre disque dur.
- Démontage du lecteur USB.
- Dans le terminal, exécutez :

  ```bash
  sudo bash ./make_bootable_linux
  ```

:::note

La clé USB peut brièvement disparaître et réapparaître plusieurs fois au cours de ce processus. Cela est normal.

:::
