# Version 7.3.2 2026-07-08

Unraid OS 7.3.2 est une version de sécurité et de correction de bogues comprenant le noyau Linux 6.18.38, des correctifs de réseau Docker VLAN, des correctifs de stockage et de pool de démarrage, des correctifs de l'interface utilisateur de virtualisation, l'API Unraid 4.35.1 et plusieurs mises à jour de paquets de base.

Recommandé pour tous les utilisateurs.

## Mise à niveau

Pour des instructions étape par étape, consultez [Mise à jour d'Unraid](\<https://unraid-os/updating-unraid/>). Des questions sur votre [licence](\<https://../../unraid-os/troubleshooting/licensing-faq.mdx#license-types--features>) ?

## Problèmes connus

- Aucun nouveau problème connu spécifique à cette version n’est signalé. Pour les problèmes hérités des versions précédentes, consultez les notes de version de [Unraid OS 7.3.1](\<../7.3.1/>).
- Pour les utilisateurs disposant de cartes Intel Arc série A, des écrans noirs peuvent apparaître lors du démarrage d'une VM avec la carte en passthrough ; les investigations actuelles montrent que les modèles Q35 sont la cause potentielle. Il est recommandé de remplacer les VM par i440fx. Vous devrez supprimer le modèle et le recréer, car cela ne peut pas être modifié dans l'interface utilisateur. [https://forums.unraid.net/topic/198866-linux-vm-with-gpu-passthrough-broke-after-upgrading-to-73/page/2/#findComment-1630857](\<https://forums.unraid.net/topic/198866-linux-vm-with-gpu-passthrough-broke-after-upgrading-to-73/page/2/#findComment-1630857>) Les investigations se poursuivront jusqu'à ce qu'une solution soit trouvée.

## Modifications par rapport à Unraid OS 7.3.1

### Sécurité

- Sécurité : correction d’une vulnérabilité d’exécution de commandes par traversée de chemin dans le `update.php` de WebGUI, CVE-2026-3838.
- Sécurité : inclut des correctifs de sécurité pour les paquets de base avec prise en charge de CVE pour plusieurs composants ; les détails CVE au niveau des paquets sont listés dans les mises à jour de la distribution de base.

### Conteneurs / Docker

- Correctif : les auto-réseaux VLAN Docker peuvent désormais retomber sur la passerelle Docker configurée afin que les conteneurs conservent leur connectivité sortante.
- Amélioration : meilleures performances de chargement de l’onglet Docker en maintenant les E/S synchrones hors du chemin de rendu de l’onglet Docker, grâce à une contribution de la communauté de [TSpader ](\<https://github.com/tspader>) (merci !).

### Stockage

- Correctif : le remplacement du pool de démarrage ne laisse plus un membre miroir manquant obsolète dans le cas de remplacement concerné.
- Correctif : la suppression d’un périphérique du pool de démarrage ne déclenche plus la régression qui pouvait faire échouer l’opération.
- Correctif : le formatage d’un périphérique de pool dont le nom chevauche celui d’un périphérique de démarrage ne déclenche plus une fausse alerte d’assertion de cible invalide.
- Correctif : le signalement de la taille et de l’utilisation du cache du tableau de bord est corrigé pour les pools Btrfs RAID1.

### WebGUI / Système

- Nouveau : ajout d’une sortie d’état du moniteur pour les plugins d’indication de panneau qui utilisent l’état LED et LCD.
- Correctif : l’enregistrement du syslog à l’arrêt et au redémarrage crée désormais `/boot/logs` avant d’écrire les fichiers syslog.
- Correctif : les listes des périphériques contrôleurs dans System Devices n’incluent plus de périphériques sans rapport dans les cas concernés.
- Correctif : Internal Boot with Flash Licensing gère mieux les réinitialisations transitoires du périphérique de licence USB.

### Réseau / Matériel

- Correctif : la mise à jour Avahi/mDNS peut à nouveau démarrer le démon après une perte de réseau transitoire.
- Correctif : le signalement de la vitesse PCI du GPU Intel est corrigé.
- Amélioration : les contrôles SR-IOV de l’iGPU Intel ne sont affichés que lorsque le plugin de prise en charge est installé.

### Virtualisation

- Correctif : l’utilisation CPU de la VM n’affiche plus une utilisation élevée causée par des tâches hôte sans rapport.
- Correctif : le positionnement du menu contextuel de la VM est corrigé.
- Amélioration : les entrées du menu déroulant Source du réseau de la VM sont triées et le contrôle est plus large pour faciliter le repérage.
- Correctif : suppression d’un message de bannière de redémarrage de VM obsolète lorsque les options PCI de la VM sont activées.

### Unraid API

- Mettre à jour l’API Unraid vers [dynamix.unraid.net 4.35.1](\<https://github.com/unraid/api/releases/tag/v4.35.1>).

### Noyau Linux

- Noyau Linux : mise à jour vers 6.18.38-Unraid.
  CONFIG_USB_AUTOSUSPEND_DELAY=-1
