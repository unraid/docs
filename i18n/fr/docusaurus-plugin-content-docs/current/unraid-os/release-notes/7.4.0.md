# Version 7.4.0-beta.1 2026-08-14

Unraid OS 7.4.0-beta.1 est une version bêta avec des mises à jour de sécurité sur les packages principaux, le noyau Linux 6.18.44, des améliorations de Docker et de WebGUI, des contrôles étendus du réseau des conteneurs et de la mémoire, de nouveaux paramètres de gestion des tâches et du bouton d’alimentation, ainsi que la prise en charge ajoutée du matériel sans fil Realtek RTW88.

## Mise à niveau

Pour des instructions étape par étape, consultez [Mise à jour d'Unraid](/unraid-os/updating-unraid/). Des questions sur votre licence ? Consultez la [FAQ sur la licence](/unraid-os/troubleshooting/licensing-faq/).

## Changes vs. [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Sécurité

- Security: Core package updates include security fixes for bind, libXfont2, libarchive, libssh, openssh, p11-kit, php, samba, wpa_supplicant, and xorg-server.
- Security: Notification integrations now use certificate-verified requests for the public API.

### Conteneurs / Docker

- New: Docker container templates support multiple custom networks, with additional network attachments retained when containers are recreated or updated.
- New: Docker Add/Edit forms now show a live preview for the container icon URL, with a fallback when the URL is empty or invalid.
- New: Advanced View now exposes a Memory limit field for Docker containers.

### Stockage

- Fix: Pressing Enter in encrypted array passphrase fields now starts the array when the passphrase validation succeeds.
- Fix: File Manager keeps exclusive shares in the `/mnt/user/\<share>` view instead of switching to the underlying disk or pool path.

### WebGUI / Système

- New: Background operations from plugins, Docker, and virtual machines can be queued and managed from a shared task tray, with foreground recall from any browser tab.
- New: The Boot Device page supports downloading a backup directly or saving it to the server, with progress tracking.
- New: Physical power-button behavior can be configured for Shut down, Reboot, or Do nothing. Go to Settings → Power Options to configure this.
- Improvement: Foreground task sheets now scale with the browser viewport while retaining saved-width and mobile behavior.
- Improvement: License checks now retry if the license becomes unavailable on disk for a minute, this allows for transient boot drive drop outs
- Improvement: The consolidated header now manages header layout and array-usage display, addressing mobile header overlap.
- Fix: The Installed Plugins page checks updates independently so a slow or unreachable plugin does not keep the entire page waiting.
- Fix: Plugin update validation failures now remain visible with an explanation instead of silently reporting the plugin as up-to-date, including failures caused by a full root filesystem.
- Fix: Plugin Manager post-hook cleanup now runs when error messages contain shell characters.

### Réseau / Matériel

- New: Added kernel modules and firmware for Realtek RTW88 8812A, 8814A, and 8821A wireless adapters.

### Virtualisation

- Fix: VM startup no longer logs a PHP deprecation warning when the QEMU location lookup produces no output.

### Unraid API

- Update [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.1 - [see changes](\<https://github.com/unraid/api/releases>).

### Noyau Linux

- Linux kernel: update to 6.18.44-Unraid.
