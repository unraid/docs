# Version 7.4.0-beta.1 2026-08-14

Unraid OS 7.4.0-beta.1 est une version bêta avec des mises à jour de sécurité sur les packages principaux, le noyau Linux 6.18.44, des améliorations de Docker et de WebGUI, des contrôles étendus du réseau des conteneurs et de la mémoire, de nouveaux paramètres de gestion des tâches et du bouton d’alimentation, ainsi que la prise en charge ajoutée du matériel sans fil Realtek RTW88.

## Mise à niveau

Pour des instructions étape par étape, consultez [Mise à jour d'Unraid](/unraid-os/updating-unraid/). Des questions sur votre licence ? Consultez la [FAQ sur la licence](/unraid-os/troubleshooting/licensing-faq/).

## Problèmes connus

- Aucun problème connu spécifique à cette version n’est documenté. Pour les problèmes déjà documentés, consultez les [notes de version d’Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/).

## Modifications par rapport à [Unraid OS 7.3.2](/unraid-os/release-notes/7.3.2/)

### Sécurité

- Sécurité : les mises à jour des paquets de base incluent des correctifs de sécurité pour bind, libXfont2, libarchive, libssh, openssh, p11-kit, php, samba, wpa_supplicant et xorg-server.
- Sécurité : les intégrations de notifications utilisent désormais des requêtes vérifiées par certificat pour l’API publique.

### Conteneurs / Docker

- Nouveau : les modèles de conteneurs Docker prennent en charge plusieurs réseaux personnalisés, et les connexions réseau supplémentaires sont conservées lorsque les conteneurs sont recréés ou mis à jour.
- Nouveau : les formulaires Ajouter/Modifier de Docker affichent désormais un aperçu en direct de l’URL de l’icône du conteneur, avec une valeur de repli lorsque l’URL est vide ou invalide.
- Nouveau : la Vue avancée expose désormais un champ de limite de mémoire pour les conteneurs Docker.

### Stockage

- Correctif : appuyer sur Entrée dans les champs de phrase de passe du tableau chiffré démarre désormais le tableau lorsque la validation de la phrase de passe réussit.
- Correctif : le Gestionnaire de fichiers conserve les partages exclusifs dans la vue `/mnt/user/\<share>` au lieu de basculer vers le disque ou le chemin du pool sous-jacent.

### WebGUI / Système

- Nouveau : les opérations en arrière-plan provenant des plugins, de Docker et des machines virtuelles peuvent être mises en file d’attente et gérées depuis un tiroir de tâches partagé, avec rappel au premier plan depuis n’importe quel onglet du navigateur.
- Nouveau : la page du périphérique de démarrage prend en charge le téléchargement direct d’une sauvegarde ou son enregistrement sur le serveur, avec suivi de la progression.
- Nouveau : le comportement du bouton d’alimentation physique peut être configuré pour Éteindre, Redémarrer ou Ne rien faire. Accédez à Paramètres → Options d’alimentation pour le configurer.
- Amélioration : les feuilles de tâches au premier plan s’adaptent désormais à la zone d’affichage du navigateur tout en conservant la largeur enregistrée et le comportement mobile.
- Amélioration : les vérifications de licence réessaient désormais si la licence devient indisponible sur le disque pendant une minute, ce qui permet de gérer les déconnexions transitoires du périphérique de démarrage
- Amélioration : l’en-tête consolidé gère désormais la disposition de l’en-tête et l’affichage de l’utilisation du tableau, ce qui corrige le chevauchement de l’en-tête sur mobile.
- Correctif : la page des plugins installés vérifie désormais les mises à jour de manière indépendante, afin qu’un plugin lent ou inaccessible ne bloque pas toute la page.
- Correctif : les échecs de validation des mises à jour des plugins restent désormais visibles avec une explication au lieu d’indiquer silencieusement que le plugin est à jour, y compris les échecs causés par un système de fichiers racine plein.
- Correctif : le nettoyage du post-hook du gestionnaire de plugins s’exécute désormais lorsque les messages d’erreur contiennent des caractères de shell.

### Réseau / Matériel

- Nouveau : ajout des modules du noyau et du micrologiciel pour les adaptateurs sans fil Realtek RTW88 8812A, 8814A et 8821A.

### Virtualisation

- Correctif : le démarrage de la VM ne consigne plus d’avertissement d’obsolescence PHP lorsque la recherche de l’emplacement QEMU ne produit aucune sortie.

### Unraid API

- Mettre à jour [dynamix.unraid.net](\<https://github.com/unraid/api/releases>) 4.37.1 - [voir les changements](\<https://github.com/unraid/api/releases>).

### Noyau Linux

- Noyau Linux : mise à jour vers 6.18.44-Unraid.
