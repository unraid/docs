---
title: Move a license to a new server
description: Move an existing Unraid license to a new server from the Account app.
---

Use the Account app's license-move flow when you are replacing a server or moving your license to new hardware. The new server must be running and connected to your Unraid account before you begin.

## Before you start

- Boot the new server and connect it to your Unraid account.
- Sign in to the account that owns the license.
- If possible, keep the old server available so you can compare its license and server details.

The flow uses your signed-in account and its license records; you do not need to upload a license file as proof of ownership. The old licensing device remains active until you confirm the move. Review the source license, target server, and masked GUIDs carefully before you continue.

## Move the license

### Open the new server overview

After the new server connects, Account opens its server page with the server status and available setup actions.

![The Account app's new server overview with available setup actions](/img/unraid-account/move-license-to-new-server/01-new-server-overview.png)

### Find transfer in Available actions

On the new server's page, sign in to the account that owns the license. When the server is not assigned to one of that account's licenses, Account shows **Transfer from another server** at the bottom of the **Available actions** list. Select it to begin.

![The Account app's Available actions list with Transfer from another server at the bottom](/img/unraid-account/move-license-to-new-server/02-license-transfer-option.png)

### Open transfer from another server

The transfer card explains that a license assigned to another server is available. Select **Transfer from another server** to continue.

![The Account app's transfer card showing an available license move](/img/unraid-account/move-license-to-new-server/03-license-transfer-available.png)

### Choose a license to transfer

Choose the license you want to move from the account's available licenses, then select **Review move**.

![The Account app's license transfer card with a license selected and Review move available](/img/unraid-account/move-license-to-new-server/04-license-transfer-select.png)

### Review the source and destination

Check the license type and masked GUID under **License to move**. Then check the new server name and masked GUID under **New server**.

![The Account app's license move review showing the source license, new server, and masked GUIDs](/img/unraid-account/move-license-to-new-server/05-review-license-move.png)

### Acknowledge and move the license

Select the acknowledgement checkbox after you verify the source license and target server. The final action becomes available only after acknowledgement. Select **Move license to this server** to commit the transfer.

![The Account app's license move review after acknowledgement, with Move license to this server available](/img/unraid-account/move-license-to-new-server/06-acknowledge-license-move.png)

After confirmation, the old licensing device is retired and the license is delivered to the new server through the callback flow. If the server cannot receive the key automatically, use the manual key installation instructions in the [Licensing FAQ](/unraid-os/troubleshooting/licensing-faq/#manual-keyfile-install).

## If you selected the wrong server

Account checks the target context's shape and shows the server name and masked
GUID for review, but the current flow does not cryptographically prove that the
context came from the intended physical server. A future signed or one-time
target challenge can strengthen this check.

Do not confirm the move until the server name and masked GUID match the server you intend to use. The source remains active before confirmation, so you can select **Cancel** and start again. If you already confirmed the wrong target, contact [Unraid support](https://unraid.net/contact) before attempting another transfer.
