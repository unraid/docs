# Version 7.2.8 2026-07-29

Unraid OS 7.2.8 is a stable update focused on security remediation, a Linux kernel update to 6.12.98-Unraid, Unraid API updates, firmware additions, and broad base distro package updates.

We recommend upgrading from Unraid OS 7.2.7 to receive the included security fixes.

## Upgrading

For step-by-step instructions, see [Updating Unraid](/unraid-os/updating-unraid/). Questions about your license? Review the [License FAQ](/unraid-os/troubleshooting/licensing-faq/).

## Known issues

* No new release-specific known issues are documented. Review the Unraid OS 7.2.7 release notes for known issues that may still apply.

## Notes

* This release includes added Intel iwlwifi firmware files.

## Rolling back

* No new release-specific rollback warnings are documented. Review the Unraid OS 7.2.7 rollback notes before rolling back.

## Changes vs. Unraid OS 7.2.7

### Security

* Security: Includes security-related updates across base distro packages. Detailed package CVE annotations are listed under Base distro updates.
* Security: Fixed a WebGUI `update.php` path-traversal command execution vulnerability, CVE-2026-3838.
* Security: Addresses security findings in components that affected Unraid OS 7.2.7, including bind, curl, dnsmasq, iperf3, libXfont2, libevent, libgpg-error, libidn, libseccomp, libssh, nginx, OpenSSH, OpenSSL, p11-kit, rsync, Samba, shadow, sqlite, and xorg-server.
* Includes Kernel upgrade to 6.12.98-Unraid

### Networking / Hardware

* New: Added 304 Intel iwlwifi firmware files.

## Docker

* Docker VLAN auto-networks can fall back to the configured Docker gateway so containers keep outbound connectivity.

### Unraid API

* Update Unraid API to [dynamix.unraid.net](<https://dynamix.unraid.net>) 4.36.1 - see [changes](<https://github.com/unraid/api/releases>).
