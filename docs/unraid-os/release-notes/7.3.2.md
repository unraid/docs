# Version 7.3.2 2026-07-02

Unraid OS 7.3.2 updates the Linux kernel, Docker, ZFS, Unraid API, and a broad set of base packages. This release also includes security-related package updates for core services such as OpenSSL, nginx, dnsmasq, SQLite, and others.

We recommend updating as soon as practical, especially if you run exposed network services or depend on Docker, virtualization, or ZFS.

## Upgrading

For step-by-step instructions, see Updating Unraid. Questions about your license?

## Known issues

- No new release-specific known issues are listed for this release.

## Notes

- The Unraid API has been updated to dynamix.unraid.net 4.35.1.
- The kernel has been updated to 6.18.37-Unraid.
- ZFS has been updated to 2.4.3_6.18.37_Unraid-1_LT.

## Rolling back

- Rolling back to an earlier release may require matching kernel-coupled components, especially ZFS.
- If you rely on updated Docker, networking, or security packages in this release, review prior release notes before downgrading.

## BREAKING CHANGES

- None reported for this release.
