# Version 7.3.6 2026-11-20

This maintenance release includes bundled security fixes and restores Docker image update checks for registries such as `lscr.io`. Internal boot is now supported on more storage controllers, and a searchable time-zone picker makes it easier to find your location.

We recommend this update for everyone running 7.3.5.

Thanks to [rkozyak](<https://github.com/rkozyak>) for contributing the Docker image update-check fix, and to [arcanine](<https://product.unraid.net/p/7-4-0-docker-update-check-shows-not-available-for-all-lscr-io-images-auth-token-dropped-on-302-redirect-to-ghcr-io>) and [basketballguy59011](<https://product.unraid.net/p/docker-update-checker-fails-for-lscr-io-images-due-to-cross-domain-redirect-stripping-bearer-authentication>) for reporting the registry redirect issue. Thanks also to everyone who reported bugs.

## Upgrading

For step-by-step instructions, see [Updating Unraid](/unraid-os/updating-unraid/). Questions about your license? Review the [License FAQ](/unraid-os/troubleshooting/licensing-faq/).

If your server has previously shown different TPM GUIDs after cold and warm boots or a hardware change, make sure it shows the GUID that matches your license key for the first boot after upgrading. Upgrading with a mismatched GUID can tie your license to the wrong GUID. Check your current licensing identity under **Tools → Registration**. If your license then reports an invalid GUID, contact Unraid Support.

## Known Issues

* The Initio 162x SATA driver (`sata_inic162x`) is no longer included. Linux 6.18.64 removed it because of long-standing data corruption issues. Few Unraid users are expected to be affected. Disks connected through an Initio 162x controller may be unavailable after upgrading. [Linux stable removal commit](<https://github.com/gregkh/linux/commit/86d16cc6de7f01dd33d50ff49ec80c12a0ed8797>)
* Drivers for MegaRAID SAS (`megaraid_sas`), Marvell and NVIDIA SATA (`sata_mv`, `sata_nv`), 3ware (`3w_9xxx`, `3w_sas`), AACRAID (`aacraid`), HPSA (`hpsa`), Intel SCU (`isci`), MPI3MR (`mpi3mr`), and PM8001 (`pm80xx`) controllers are now built into the kernel. If you use custom `config/modprobe.d/*.conf` files to set parameters for these drivers, set those parameters using kernel command-line options instead. Use the form `module.parameter=value`. On systems that use Syslinux, add each option to the `append` line for your boot entry in **Main → Syslinux Configuration**. On internal-boot systems that use GRUB, go to ***Settings → Boot Parameters*** and switch to **Raw View**. Add each option to the end of the `linux` line for your boot entry. Select **Save Raw Config**, then reboot to apply the changes. [Unraid boot configuration](/unraid-os/troubleshooting/common-issues/boot-and-startup-failures/#understanding-the-boot-sequence) · [Linux parameter syntax](<https://www.kernel.org/doc/html/latest/admin-guide/kernel-parameters.html>)

For previously reported issues, see the [Unraid OS 7.3.5 release notes](/unraid-os/release-notes/7.3.5/).

## Rolling back

If you choose a time zone added in 7.3.6 and then roll back, your time zone may reset to Hawaii because the earlier release does not include it. Check **Settings → Date & Time** after rolling back. For earlier rollback guidance, see the [Unraid OS 7.3.5 release notes](/unraid-os/release-notes/7.3.5/).

## Changes vs. [Unraid OS 7.3.5](/unraid-os/release-notes/7.3.5/)

### Security

* To improve security, this update includes fixes in bundled packages, including Git, Kerberos, NGINX, OpenSSH, rclone, rsync, and graphics libraries. See Base distro updates for the complete package list.

### Containers / Docker

* Fix: Docker update checks no longer show “not available” for `lscr.io` images when the registry redirects the request. For redirected requests, credentials stay scoped to the registry that requests them.

### Storage

* Improvement: The storage drivers listed under **Known Issues** are built into the kernel to support internal boot from these controllers.

### WebGUI / System

* New: The time-zone list now includes all standard time zones and is searchable.

### Unraid API

* Updated to [Unraid API 4.37.12](<https://github.com/unraid/api/releases/tag/v4.37.12>).
* Fix: API keys created with permissions but no roles are now saved correctly.
* Security: The API now sanitizes fallback notification text.
* Security: Update checks now restrict requests to their intended scope.

Package and kernel updates compared with Unraid OS 7.3.5.

### Linux kernel

* Linux kernel: update to 6.18.64-Unraid.
