# Version 7.3.5 2026-11-09

This maintenance release updates several base packages to address CVEs, updates the Linux kernel to 6.18.60-Unraid, and adds support for the British Columbia timezone. We recommend upgrading to receive these security updates.

## Upgrading

For step-by-step instructions, see [Updating Unraid](/unraid-os/updating-unraid/). Questions about your license? Review the [License FAQ](/unraid-os/troubleshooting/licensing-faq/).

## Known issues

No new release-specific known issues are listed. See the [Unraid OS 7.3.4 release notes](/unraid-os/release-notes/7.3.4/) for the previous release's known issues.

## Rolling back

No release-specific rollback limitations are listed.
