# Version 7.3.3-rc.1 2026-09-03

Unraid OS 7.3.3 is a release-candidate update focused on security fixes, the Linux 6.18.47 kernel, Docker and API updates, configurable power-button controls, expanded hardware and Hyper-V support, and updated base packages. Because this release includes security fixes, upgrading is recommended.

## Upgrading

For step-by-step instructions, see [Updating Unraid](/unraid-os/updating-unraid/). Questions about your license? Review the [License FAQ](/unraid-os/troubleshooting/licensing-faq/).

## Known issues

* No new release-specific known issues are listed. Refer to the [Unraid OS 7.3.2 release notes](/unraid-os/release-notes/7.3.2/) for previously documented issues.

## Notes

* ZFS and SPL compatibility checks passed with the `6.18.47-Unraid` kernel.

## Rolling back

* Review the [Unraid OS 7.3.2 release notes](/unraid-os/release-notes/7.3.2/) for rollback guidance and compatibility limitations.

## Changes vs. Unraid OS 7.3.2

### Security

* Security: Updated system components with upstream security fixes and CVE remediations.

### Containers / Docker

* Fix: Prevented removal of the shared fallback icon when an icon-less Docker container is removed or updated, and stopped missing fallback icons from causing repeated failed requests.

### WebGUI / System

* New: Added configurable physical power-button actions under Settings > Power Options: Shut down, Reboot, and Do nothing.

### Networking / Hardware

* New: Added kernel modules and firmware for additional Intel wireless, MediaTek Bluetooth, and Realtek RTW88 wireless hardware.

### Virtualization

* New: Added kernel support for Hyper-V graphics, ballooning, storage, keyboard, VMBus, utility, and VSOCK components.

### Unraid API

* Update [dynamix.unraid.net](<https://github.com/unraid/api/releases>) 4.37.3 - see changes.

### Linux kernel

* Linux kernel: update to 6.18.47-Unraid.
